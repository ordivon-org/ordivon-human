
# 2. Candidate A — reference / interpretation repair

At first glance this seems like the most obvious practical hole:

```text
same message delivered
+ different referent/interpretation
→ coordination failure
```

But HOC6 already reconstructs exactly this layer.

It contains:

```text
CommonGroundEstimate
CriticalCommonGroundSet
MisunderstandingCase
RepairEpisode
RepairCapabilityProfile
partner-specific reference
shared-artifact / shared-interpretation separation
clarification / paraphrase / teach-back
```

with:

```text
MessageDelivered != CommunicationSuccess
SharedArtifact != SharedInterpretation
NoRepair != MutualUnderstanding
CommunicationRepair != TrustRepair
```

HF23 supplies the semantic/reference types; HOC6 supplies the practical relational repair process.

Therefore:

```text
ReferenceRepair
= HF23 typed reference/interpretation
+ HOC6 common-ground/misunderstanding/repair
```

No new owner remains.

---

# 3. Human–AI referential communication strengthens HOC6 ownership

Recent experiments make the distinction operationally sharper.

2025 work evaluating VLM common-ground construction in interactive referential games found that:

```text
task success
!= successful grounding
```

and:

```text
high image–utterance alignment
!= task success
```

while model interaction patterns diverged from Human dyads across multiple grounding metrics.

2026 ACL experiments with Human–Human, Human–AI, AI–Human and AI–AI director/matcher pairs likewise found that LVLMs did not generate/resolve referring expressions with Human-like interactive grounding across repeated rounds.

Thus:

```text
TaskCompletion
!= CommonGroundEstablished
```

and:

```text
FluentReferenceExpression
!= HumanLikeGroundingProcess
```

But this does not reveal a new Human family; it validates HOC6's existing common-ground/repair model plus HF23 reference semantics.

---

# 4. Overhearing is not common-ground participation

2025 work on LVLMs overhearing Human referential dialogue found that models did not consistently improve simply by observing repeated interactions between the same Human participants.

This yields a useful firewall:

```text
AccessToDialogueHistory
!= InteractiveGrounding
```

and:

```text
ObservedConvention
!= SuccessfullyAcquiredPartnerSpecificReferencePolicy
```

Again, this composes:

```text
HF23 symbolic/reference history
+ HOC6 common ground/partner-specific convention
+ HOC3 learning/transfer if acquisition is claimed
```

rather than creating one new HOC.

# 7. Current MT evidence confirms objective plurality

WMT 2025 work directly studies adequacy–fluency tradeoffs and shows that evaluation metrics can systematically favor one side of the tradeoff.

Therefore:

```text
TranslationQuality
!= OneScalarIndependentOfObjective
```

Likewise, 2025 discourse-aware translation work finds that context strategy changes performance on phenomena such as:

```text
formality
pronoun selection
lexical cohesion
```

So:

```text
SentenceLocalAdequacy
!= DiscourseAdequacyTotality
```

and:

```text
ContextFreeTranslation
!= ContextAppropriateTranslation
```

These are strong reasons to preserve a typed translation objective—not reasons to introduce a Human HOC.

---

# 8. Legal translation is a domain-specific pressure case

2025 Swiss legal-translation benchmarking uses laws, headnotes and press releases across multiple languages and Human expert validation.

The same system family can perform differently across document types, reinforcing:

```text
TranslationPerformance(DocumentTypeA)
!= TranslationPerformance(DocumentTypeB)
```

Legal force, jurisdictional terminology and access-to-justice consequences are downstream domain constraints.

Therefore:

```text
LegalTranslation
= HF23 translation semantics
+ HOC2 verification
+ HOC8 legal/linguistic competence
+ legal/institutional owner
```

not generic Human-language ownership.


# 21. Why `PARAPHRASE / TRANSLATE / SIMPLIFY` do not prove one new owner

Those actions are heterogeneous transformations over symbolic vehicles.

Their success criterion changes with the declared use question.

For example:

```text
translation for legal force
!= translation for conversational fluency

simplification for comprehension
!= simplification for machine translatability

paraphrase for common-ground repair
!= paraphrase for style

AAC prediction for speed
!= AAC prediction for authorship fidelity
```

So the shared layer is composition discipline, not one substantive Human mechanism.
