# 1. Direct reduction test

The central question is:

# 3. After reduction, what remains common?

Once target-specific content is removed, the Round-2 survivor leaves:

```text
1. declare exact experiential target;
2. distinguish phenomenon from report;
3. preserve first-person vs third-person evidence;
4. preserve proxy-report boundary;
5. record recall/elicitation horizon;
6. compare subjective and objective/structural evidence when useful;
7. preserve disagreement instead of forcing one truth source;
8. represent uncertainty and non-reportability;
9. update/expire evidence appropriately;
10. log measurement/intervention reflexivity;
11. collect only minimum necessary intimate data;
12. route the result to the actual domain owner.
```

This is valuable.

But it is not a stable operational family in the same sense as:

```text
Capability
Learning
Regulation
Execution
Coordination
Health
Knowledge
Habit
```

It is a **cross-cutting projection/evidence protocol**.

# 4. Why protocol != HOC family

A HOC family should own a recurring practical object and a characteristic intervention/routing grammar.

For the candidate:

```text
pain       → health action
fatigue    → regulation action
loneliness → relationship/social-support action
agency     → control/delegation/interface action
fear       → context-specific affect/safety action
life eval  → reflective/consumer/normative action
```

There is no domain-general:

```text
NextBestExperienceOperation
```

beyond:

```text
ask / clarify / measure / compare / route / no-op
```

Those are evidence and routing operations, not a substantive Human operational family.

Therefore:

```text
CommonEvidenceGrammar
!= CommonOperationalObject
```

This is the Round-3 decisive deletion.

# 6. Mixed / ambivalent experience attack

A one-dimensional experience model fails immediately.

Humans can report simultaneous positive and negative affect or qualitatively mixed emotional states.
Cross-cultural work also shows that patterns of mixed affect and discomfort can differ by cultural context and interpretation.

Therefore reject:

```text
ExperienceValence = one bipolar scalar
PositiveExperience = absence of negative experience
```

But this does not rescue a generic HOC.

HF21 already allows multidimensional affective episodes, and the projection protocol can preserve multiple declared target dimensions without aggregation.

Thus:

```text
MixedExperience
supports non-scalar representation
but does not establish independent HOC ownership.
```

---

# 7. Proxy / nonverbal / child attack

This test strongly validates the **protocol**, not the family.

Pediatric PROMIS and quality-of-life studies repeatedly find imperfect child–caregiver agreement, with larger disagreement on subjective domains such as anxiety, depression, pain/fatigue or psychosocial experience than on some more observable functional domains.

Therefore:

```text
ProxyReport != FirstPersonReport
ProxyReport != FirstPersonExperience
```

and:

```text
MoreObservableFunction
may have different cross-informant agreement
than private symptom/experience.
```

For nonverbal or constrained-report Humans:

```text
DirectReportUnavailable
```

must not become:

```text
ExperienceAbsent
```

HF2 already owns precisely this evidence asymmetry.

The required operational move is:

```text
label channel + ceiling + uncertainty
```

not create a generic experience state.

---

# 8. Measurement-reactivity attack

Experience sampling / ecological momentary assessment is attractive because it reduces long retrospective reconstruction.

But repeated probing can itself alter:

```text
attention to experience
reporting behavior
within-person variance
emotional awareness
possibly affect/regulation
```

and 2026 work continues to show that study duration and probe design can alter psychometric properties of self-reported momentary thought/affect measures.

Therefore:

```text
ExperienceMeasurement
may be ExperienceIntervention
```

This makes a permanent generic experience-monitoring layer especially risky.

It supports:

```text
purpose-specific temporary measurement
```

rather than:

```text
always-on Human experience telemetry
```

# 9. Privacy-minimization tournament

Round 2 left A10 unresolved.
Round 3 directly compares two architectures.

## Architecture G — generic experience HOC

Potential temptation:

```text
collect reusable experience profile broadly
then let many consumers query it
```

Benefits:

```text
standardization
reuse
cross-domain divergence detection
```

Costs:

```text
intimate-data accumulation
context collapse
secondary-use temptation
stale experience persistence
cross-domain inference leakage
surveillance incentives
manipulation/optimization risk
```

## Architecture P — projection protocol

```text
consumer declares target and decision
→ collect minimum necessary first-person/proxy evidence
→ apply HF2 evidence boundary
→ compare with domain evidence if needed
→ route to owner
→ expire/discard under consumer policy
```

Benefits:

```text
most of the methodological reuse
without one centralized intimate Human experience object
```

Round-3 result:

```text
P dominates G for generic Human core.
```

This is the strongest A10 result.

# 11. Human–Agent destructive attack

Human–Agent systems remain the strongest case for objective/subjective divergence.

Automation research demonstrates:

```text
apparent performance / automation level
and
sense of agency
```

can change differently, and action-contingent but control-irrelevant feedback can increase felt agency under automatic control.

This proves:

```text
ExperiencedAgency != ActualControl
```

but it does not prove a generic experience HOC.

The correct system model is:

```text
Runtime/Harness: actual execution/control
HOC5/HOC6: goal/authority/delegation relation
HF2-derived projection: reported/felt agency
Security/Governance: manipulation/legitimacy boundary
```

The projection protocol is sufficient to preserve the dissociation.

# 12. Objective–experience divergence survives as a cross-cutting pattern

Round 2's strongest object remains useful:

```text
ObjectiveExperienceDivergenceCase
```

But Round 3 reclassifies it.

It is not a Human state family.
It is a **comparison pattern** between two separately owned projections.

Examples:

```text
HOC4 objective/subjective state mismatch
HOC7 biomarker/function vs symptom burden
HOC6 relationship structure vs loneliness
Runtime actual control vs experienced agency
HOC3 learning gain vs aversive learning experience
```

Therefore:

```text
ObjectiveExperienceDivergenceCase
= cross-HOC comparison pattern
!= HOC family
```

This avoids duplicate ownership.


No generic `QualityOfLife` HOC.

Fresh unnamed search therefore finds no candidate stronger than the existing HOC0–HOC9 core in Round 3.

This is evidence, not proof of exhaustive coverage.
