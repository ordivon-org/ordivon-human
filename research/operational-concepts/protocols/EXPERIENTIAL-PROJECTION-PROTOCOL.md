# ExperientialProjectionProtocol

`ExperientialProjectionProtocol` is an **unnumbered cross-cutting consumption protocol**, not a Human Operational Concept family.

```text
ExperientialProjectionSpec = {
  use_question,
  experiential_target,
  target_owner,
  Human,
  episode/domain/context,
  time_scope / recall_horizon,
  support/environment state,
  direct_first_person_evidence,
  third_person_evidence,
  proxy_evidence,
  reportability constraints,
  semantic/cultural/developmental scope,
  objective_or_structural_comparator?,
  divergence?,
  uncertainty,
  update_rule,
  expiry_rule,
  minimum_data_rule,
  downstream_use_scope,
  forbidden_inferences,
  routing_owner
}
```

It supports purpose-scoped first-person evidence without creating a universal experience profile or one generic `NextBestExperienceOperation`.

Core guardrails include: report is evidence, not automatic phenomenon identity; proxy evidence is not first-person evidence; mixed experience need not collapse to one valence scalar; use the minimum data required; route substantive intervention to the target owner.
