# HUMAN-AI-001 R1–R6 Round 1

## Overall disposition

R1–R6 are now **implemented as experiments**, but they do not all have resolved
Human outcomes. This distinction is intentional: hidden-answer learning/audit
experiments cannot be scored before Human responses, and prospective timescale /
calibration experiments cannot be resolved before future events occur.

The round therefore separates:

```text
apparatus complete
≠ Human endpoint resolved
≠ prospective hypothesis validated
```

## Status

| Experiment | What is complete now | What remains unresolved |
|---|---|---|
| R1 learning/distillation | 3 exact closed cases, deterministic condition assignment, frozen packets/questions/rubric | Human response, time, transfer/verification scores; later condition rotation |
| R2 capability surfaces | minimal decision-linked matrix; reuse of R1/R3/R4 observations | Human independent/verification/transfer/recovery values and deletion tests |
| R3 selective audit | 3 hidden-disposition packets, deterministic full/selective/conclusion assignment, scoring key | blinded Human decisions/review time; later condition rotation |
| R4 delegation/recovery | 3 real failure classes and intervention-substrate probes | blinded Human recovery performance and maintenance-cost comparison |
| R5 timescale coordination | 3-task hindsight replay; fixed-60m rival; prospective policy freeze | prospective critical-recall/interruption/correction-cost outcomes |
| R6 calibration | admission/record/resolution schema; FS0 apparatus preflight | enough prospectively frozen Human predictions and resolved outcomes |

## Immediate R5 result

Across the three reconstructible Host tasks, every-checkpoint review would have
created 10 preterminal Human interruptions; fixed 60-minute review would create
4; a hindsight-labeled event policy would create 1. The fixed cadence would have
reviewed Web while a later-falsified RTNL hypothesis was current and would have
surfaced Runtime P5's known critical rev6 falsifier about 23.18 minutes after it
occurred.

This is **not** evidence that event triggering wins. The event labels use future
knowledge. It earns only the prospective `eventTriggeredV1` comparison now
frozen in `r5-v1/PROSPECTIVE-POLICIES.json`.

## R1/R3 design caution

Wave 1 uses one Human and one case per condition. It can reveal unusable packet
burden, scoring insensitivity, obvious review failures, and individual learning
signals, but case difficulty is confounded with treatment. No format-level causal
claim is allowed until later materially different cases rotate conditions.

## R2/R4 privacy boundary

The public repository stores experiment contracts and aggregate conclusions, not
a permanent personal capability profile. Human raw responses may be retained in
private continuity only when needed to score the current experiment and should be
reduced after aggregation.

## R6 first-principles boundary

R6 does not turn Human life into prediction logging. A record is admitted only
when the event is uncertain, resolvable, decision-relevant, and cheap enough to
log. Exact claim identity matters: general progress on a Task does not resolve a
prediction about a different pressure inside that Task.

## Next empirical action

The next interaction should collect the **blinded Human wave** without exposing
scoring keys. The same responses can populate R1 reconstruction/transfer, R2
capability surfaces, R3 audit quality, and R4 intervention probes. Separately,
freeze a small R6 prediction set before R5/R1–R4 outcomes are known. No new Human
Learning Harness is justified by apparatus construction alone.
