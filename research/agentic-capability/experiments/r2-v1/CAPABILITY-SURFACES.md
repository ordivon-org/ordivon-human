# R2 v1 — Minimal Capability Surface Matrix

## Question

Does measuring more than assisted output change a real Human–Agent allocation or
recovery decision?

## Reuse policy

R2 reuses R1/R3/R4 responses to minimize Human burden. It does not create a
separate psychometric battery.

| Surface | Observation | Source in round 1 | Decision it may change |
|---|---|---|---|
| joint-system | verified task result with normal Agent/Ordivon support | already-established owner/task evidence | whether the combined system can perform the task now |
| independent reconstruction | explain the mechanism without external help | R1 response | whether the model is internally available enough for later reasoning |
| verification | detect a plausible seeded wrong claim | R1/R3 | how much delegated work can be accepted without escalation |
| varied/novel transfer | apply the mechanism to a different case | R1 | whether a stable-core promotion is justified |
| intervention | choose a useful action under hidden failure | R4 | whether current Human substrate is enough for supervisory control |
| recovery/switching | restore a viable path when preferred aid/provider is removed | R4 | whether dependency is rational or fragile |

## Frozen decision rule

A surface survives R2 only if knowing it changes at least one of:

1. delegation depth;
2. Human review depth;
3. retained-practice requirement;
4. provider/tool redundancy requirement;
5. promotion into Human stable knowledge.

If two surfaces repeatedly make the same decisions across materially different
cases, test deleting the more burdensome one.

## Contraction status

R2 remains a **support-condition accounting model**. Record a surface when ordinary work exposes it or when a live delegation/recovery decision depends on it. Do not create additional observations solely to complete the matrix.
