# HD16-B — Rival Music / Auditory Structural Architectures / Cross-Regime Falsification

## 0. Common battery

Every rival must explain:

```text
T01 amusia without aphasia
T02 aphasia-language deficit with relatively spared musical functions
T03 pitch vs rhythm dissociation
T04 verbal vs musical STM double dissociation
T05 beat perception vs synchronization dissociation
T06 explicit vs implicit timing dissociation
T07 music perception vs music reward dissociation
T08 music reward vs monetary/general reward dissociation
T09 music perception vs imagery/memory dissociation
T10 musical emotion recognition vs intensity/experience dissociation
T11 congenital vs acquired amusia
T12 active production vs passive perception
T13 speech prosody overlap without identity
T14 training/history/cultural dependence
```

---

# 1. Rival A — unitary music module

Strong form:

```text
MusicCognition = one specialized process/module
```

Fails T03–T10.

A single music module cannot preserve rhythm while melody fails, preserve synchronization while explicit beat perception fails, preserve music reward while scale/key/contour/interval processing fails, or preserve generic reward while music reward disappears without adding submodules.

Verdict:

```text
WholeRouteOwner = FAIL
```

---

# 2. Rival B — pitch-core architecture

Pitch is highly important: congenital amusia often centers on pitch-processing deficits, and melody/tonal structure strongly depend on pitch relations.

But:

```text
Pitch != Rhythm
Pitch != Beat
Pitch != MusicReward
Pitch != MusicalEmotionTotality
```

Some pitch-deaf individuals have variable beat deficits; some music-emotion judgments remain surprisingly preserved despite pitch impairment.

Verdict:

```text
PitchMechanism = STRONG LOCAL COMPONENT
WholeMusicOwner = FAIL
```

---

# 3. Rival C — rhythm / beat timing core

Beat and meter organize temporal expectations and action coupling.

But beat perception can dissociate from motor synchronization and implicit temporal facilitation.

HD12 already showed timing itself is plural:

```text
AbsoluteIntervalTiming
!= RhythmicPrediction
!= BeatActionMapping
```

Verdict:

```text
RhythmBeatProcessFamily = REAL
WholeMusicOwner = FAIL
```

---

# 4. Rival D — shared language/music syntax

Music and language share sequential/hierarchical expectations in some tasks, but lesion evidence rejects identity.

2024 lesion-network mapping found an acquired-amusia network distinct from aphasia; older cases show amusia without aphasia and verbal/musical STM double dissociations.

Therefore:

```text
SharedHierarchicalProcessing
!= SharedSemanticOwner

MusicalSyntax_D
!= LanguageSyntax_D by definition
```

Verdict:

```text
SharedMechanismOverlap = POSSIBLE
Music=LanguageOwner = FAIL
```

---

# 5. Rival E — predictive/statistical learning architecture

Music strongly recruits expectation, learned regularities and surprise.

This framework can model:

```text
tonal expectation
rhythmic expectation
meter
melodic continuation
reward from expectation/violation
```

but only if latent variables and learning histories are specified.

The same predictive/statistical shape occurs in generic perception, language and action.

Thus:

```text
SharedPredictiveShape != MusicSemanticOwner
```

Verdict:

```text
ComputationalFramework = RETAIN
WholeRouteOwner = FAIL
```

---

# 6. Rival F — auditory-motor / enactive music architecture

Strong for:

```text
beat synchronization
singing
instrument action
groove / entrainment
sensorimotor prediction
```

but fails passive music perception, specific perceptual amusia and music reward in listeners without overt movement.

Beat-deaf cases with poor explicit perception but preserved tapping also show that auditory-motor mapping cannot be inferred from explicit perceptual score alone.

Verdict:

```text
AuditoryMotorMapping = REAL LOCAL INTERFACE
WholeMusicOwner = FAIL
```

---

# 7. Rival G — reward-coupling architecture

Specific musical anhedonia is a powerful dissociation:

```text
MusicPerception preserved
Generic monetary reward preserved
MusicReward selectively reduced
```

This suggests a real auditory↔reward coupling problem.

But reward coupling cannot explain pitch/rhythm/melody perception, memory, imagery or synchronization.

Verdict:

```text
MusicRewardCoupling = REAL LOCAL INTERFACE
WholeMusicOwner = FAIL
```

---

# 8. Rival H — layered plural architecture

Best current whole-route synthesis:

```text
LayeredPluralMusicCognitionArchitecture {
  auditory feature/perceptual organization,
  pitch/melodic relational structure,
  rhythmic/metrical structure,
  learned structural expectations,
  memory/familiarity,
  auditory-motor mapping,
  imagery,
  emotion/affect,
```

Verdict:

```text
BestWholeRouteSynthesis = LayeredPluralMusicCognitionArchitecture
```
