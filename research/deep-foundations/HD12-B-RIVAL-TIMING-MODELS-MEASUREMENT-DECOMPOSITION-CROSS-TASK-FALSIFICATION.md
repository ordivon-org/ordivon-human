# HD12-B — Rival Timing Models, Measurement Decomposition & Cross-Task Falsification

## 0. Entry

HD12-A established:

```text
TemporalCognition
= heterogeneous research umbrella
```

and left:

```text
TemporalRelationEstimationEpisode
= provisional research object
!= HF24
```

B asks a harder question:

> Which timing model can explain the same cross-task battery without redefining `time`, silently importing neighboring Human Foundations, or treating every failed prediction as a new clock?

---

# 1. Rival set

```text
B1 — Pacemaker / Accumulator / Scalar-Clock Family
B2 — Multiple Specialized Timing Systems
B3 — State-Dependent / Distributed Dynamic Timing
B4 — Bayesian / Contextual Temporal Inference
B5 — Memory + Decision / Task-Construction Account
B6 — Modality-Specific Hierarchical Timing
B7 — Action-Prediction / Motor-System Timing
B8 — Heterogeneous Family / No Peer Timing Owner
```

These are model families, not mutually exhaustive biological theories.

A model can be correct at one explanatory level and still fail semantic ownership.

---

Every rival must face:

```text
T16 selective clinical timing impairments
```

---

# 3. B1 — scalar/pacemaker-accumulator family

Classic scalar expectancy theory separates:

```text
clock / accumulator
memory
comparison / decision
```

This is already more sophisticated than the folk `one internal clock` metaphor.

Classic human peak-interval experiments show approximately scalar response variability across trained intervals and give the model genuine empirical content.

B therefore does **not** reject scalar-clock models as useless.

---

# 4. What B1 explains well

B1 is strong when the target is bounded interval timing and the observed regularity includes:

```text
mean timing
scalar-like variability
comparison threshold
memory variability
```

It can also represent attention/arousal manipulations as changes in:

```text
pacemaker rate
switch/gating
memory
response threshold
```

This gives it substantial local flexibility.

---

# 5. B1 pressure — flexibility becomes hidden-extension risk

The same flexibility creates a problem.

If every timing bias can be assigned after the fact to:

```text
clock speed
switch latency
memory distortion
comparison threshold
response threshold
```

then the model can become difficult to falsify at the semantic-owner level.

A-round evidence already requires separating:

```text
central tendency
task-specific response mapping
retrospective memory
TOJ/SJ
beat hierarchy
passage-of-time
```

No single pacemaker variable naturally owns all of them.

---

# 6. General factor does not rescue one clock

The 2025 latent-structure study found evidence consistent with:

```text
GeneralTimingFactor
+
CentralTendencyBiasFactor
```

across the tested reproduction ranges.

This supports shared variance.

But:

```text
LatentGeneralFactor
!= BiologicalPacemakerByDefinition
```

Shared variance could arise from:

```text
shared temporal representation
shared precision/noise
common task structure
common memory/readout
shared prior calibration
```

or combinations.

---

# 7. B1 disposition

```text
B1
= RETAIN as strong bounded interval-timing model family
= REJECT as whole TemporalCognition ontology
```

Key firewall:

```text
ScalarRegularity
!= OneClockOntology
```

---

# 8. B2 — multiple specialized timing systems

B2 says timing is implemented by multiple partially specialized systems varying by:

```text
timescale
modality
task
motor/perceptual role
beat vs interval structure
```

This immediately fits many HD12-A dissociations.

---

# 9. What B2 explains well

B2 naturally accommodates:

```text
TOJ != SJ
absolute interval != beat timing
auditory hierarchy != visual hierarchy
motor timing != perceptual timing
prospective != retrospective timing
```

without forcing one shared clock parameter.

---

# 10. B2's taxonomy failure mode

The problem is explanatory depth.

If every selective dissociation becomes:

```text
there is a different timing system for that task
```

then B2 merely renames the dataset.

A valid multiple-system theory must specify principled boundaries such as:

```text
input/evidence regime
state dynamics
temporal scale
representational format
readout constraints
learning transfer
```

not one system per task label.

---

# 11. Shared structure pressures B2

B2 also faces positive commonality evidence.

2024 double-training work found complete transfer of subsecond temporal-interval-discrimination learning to an untrained interval when the new interval was exposed through an independent secondary task.

This supports:

```text
some interval-invariant temporal component
```

rather than fully interval-specific mechanisms.

Prior cross-modal transfer in the same research program also pressures strict modality isolation.

---

# 12. Context-invariant precision pressures B2 further

A 2023 sensory-vs-motor / hand-vs-eye timing experiment found:

```text
bias / accuracy
= context specific
```

while:

```text
precision
= partly context invariant across effectors
```

under the fitted framework.

Therefore:

```text
DifferentTimingContext
!= EntirelyIndependentTimingSystem
```

---

# 13. B2 disposition

```text
B2
= STRONG against monolithic timing
= INCOMPLETE without shared-component account
```

A pure pile of specialized clocks does not survive.

---

# 14. B3 — state-dependent / distributed dynamic timing

State-dependent network accounts propose that elapsed time can be encoded in evolving states of neural populations rather than counted by a dedicated pacemaker.

This family is especially relevant to subsecond sensory timing.

---

# 15. Direct subsecond support for B3

Human psychophysics has found interval-discrimination performance depends strongly on the interval separating successive timing operations.

2021 adaptive work localized a performance improvement boundary around roughly:

```text
250–333 ms inter-stimulus reset interval
```

for tested 100/200 ms auditory duration-discrimination tasks, with no analogous effect in the pitch control task.

This is unusually specific evidence for state/history dependence.

---

# 16. B3 explains local interference better than a context-free clock

A continuously reusable independent clock should not obviously require the local sensory network to reset after one timed interval.

B3 explains why:

```text
PreviousNetworkState
→ changes current temporal discrimination precision
```

while leaving the perceived midpoint comparatively intact in some paradigms.

Thus:

```text
TimingPrecision
can depend on local dynamic state.
```

---

# 17. B3 breadth problem

B3 is much weaker as a total account of:

```text
suprasecond reproduction
central tendency from learned interval distributions
retrospective event-boundary timing
passage-of-time judgments
beat hierarchy
symbolic duration estimate
```

A distributed neural implementation can always be asserted at a very broad level, but that becomes vacuous:

```text
CognitionUsesDistributedNetworks
```

does not explain timing semantics.

---

# 18. B3 disposition

```text
B3
= STRONG local mechanism family
= especially credible for subsecond state-sensitive timing
= NOT whole-domain owner
```

---

# 19. B4 — Bayesian / contextual temporal inference

B4 treats temporal judgment as inference under uncertainty:

```text
noisy current temporal evidence
+
prior / temporal context
+
loss/readout
→ estimate
```

This is the strongest model family for central tendency and contextual calibration.

---

# 20. Temporal context is causally decision-relevant

Classic reproduction experiments manipulate the distribution from which sample intervals are drawn.

The same physical sample duration is reproduced differently depending on temporal context.

Bayesian estimators that combine measurement uncertainty with the learned sample distribution account well for:

```text
bias
variance
regression toward the contextual mean
```

Thus:

```text
SamePhysicalDuration
+ DifferentTemporalPrior
→ DifferentEstimate
```

is a genuine timing regularity.

---

# 21. Central tendency is not one global prior

2025 auditory/visual temporal-estimation work complicates simple supramodal-prior accounts.

When auditory and visual duration ranges were interleaved, estimates were better explained by reliability-weighted/modality-specific prior structure than by a single global prior.

For time, audition acted as the more reliable/dominant modality in the studied design.

Therefore:

```text
TemporalPrior
!= OneGlobalPriorByDefinition
```

and:

```text
BayesianTiming
can itself be context/modality structured.
```

---

# 22. Bayesian inference is computational level, not semantic owner

The same reliability-weighted prior integration occurs in non-temporal perceptual estimation.

The 2025 study explicitly compared space and time and found analogous reliability-sensitive contextual weighting principles.

Therefore:

```text
BayesianInference
!= TimingSpecificFoundation
```

It can explain **how** a temporal estimate is calibrated without owning **what temporal evidence/representation is**.

---

# 23. B4 cannot by itself generate the target representation

A Bayesian observer requires at least:

```text
likelihood / evidence representation
prior
loss/readout
```

But it does not by itself specify whether temporal evidence came from:

```text
sensory interval
dynamic network state
beat prediction
memory event structure
motor forward model
```

Hence B4 depends on neighboring mechanisms.

---

# 24. B4 disposition

```text
B4
= STRONGEST computational-level survivor
  for uncertainty/context calibration
= NOT a peer timing owner
```

Retain:

```text
TemporalEstimate
is context/prior sensitive
```

without equating timing with Bayesianism.

---

# 25. B5 — memory + decision / task-construction account

B5 argues much of measured timing variance is produced after temporal evidence is encoded:

```text
memory
comparison
response threshold
symbolic mapping
motor reproduction
context reconstruction
```

This is already partly present inside scalar timing models but can be generalized beyond them.

---

# 26. B5 is strongest for retrospective timing

Naturalistic retrospective-duration work shows remembered event-boundary structure predicts later duration judgment and can change across delay.

Therefore:

```text
RetrospectiveTiming
= strongly memory mediated
```

in ways incompatible with a literal preserved clock readout.

HF7 has real ownership here.

---

# 27. B5 explains task dependence

The same temporal target can require different readouts:

```text
discrimination → binary comparison
reproduction → timed motor output
estimation → symbolic magnitude mapping
TOJ → ordered choice
SJ → simultaneity criterion
```

Decision and response processes can therefore change:

```text
bias
variance
criterion
```

without changing first-order temporal sensitivity.

---

# 28. B5 cannot eliminate first-order temporal evidence

Pure task-construction accounts fail when a manipulation selectively changes temporal discrimination but not a matched non-temporal task.

State-dependent reset effects provide one such pressure.

Causal interval-vs-beat perturbations provide another.

Therefore:

```text
TimingBehavior
!= MemoryDecisionOnly
```

---

# 29. B5 disposition

```text
B5
= MANDATORY measurement decomposition layer
= STRONG for retrospective / symbolic / response-heavy timing
= FAIL as total timing account
```

---

# 30. B6 — modality-specific hierarchical timing

B6 treats temporal information processing as partly structured by sensory modality and temporal complexity.

The strongest current example is:

```text
duration
→ sequence
→ beat
```

in auditory timing.

---

# 31. Auditory hierarchy has current support

2026 data support a hierarchy in which individual differences in basic auditory duration/sequence processing relate to beat perception.

The same hierarchy did not appear in visual timing.

This supports:

```text
TemporalArchitecture_Auditory
!= TemporalArchitecture_Visual by default
```

---

# 32. Reliability-weighted priors reinforce modality dependence

2025 temporal/spatial estimation work also shows modality reliability shapes contextual priors.

Thus modality can affect both:

```text
first-order temporal evidence
and
contextual calibration
```

---

# 33. Cross-modal transfer prevents strict modality ownership

However 2024 training work supports an abstract interval-invariant component, building on cross-modal transfer evidence.

Thus:

```text
ModalitySpecificTemporalMechanism
can coexist with
AbstractTemporalRelationRepresentation
```

The architecture may be layered rather than exclusively modality-specific.

---

# 34. B6 disposition

```text
B6
= STRONG local architecture account
= INCOMPLETE as whole-domain ontology
```

---

# 35. B7 — action-prediction / motor timing

B7 argues motor systems contribute not only to timing output but to temporal prediction/perception itself.

This is strongest in beat-based timing.

---

# 36. Causal premotor evidence is real

2025 TMS work found stimulation of right caudal dorsal premotor cortex selectively modulated beat perception.

A later 2025 TMS experiment found dorsal premotor stimulation also modulated beat imagery performance, especially depending on individual imagery ability.

Thus:

```text
MotorPlanningCircuit
can causally contribute to
Perceptual/InternalBeatProcessing
```

HF11 therefore participates in temporal cognition even without overt movement.

---

# 37. But motor contribution is not motor ownership

2026 rhythm-learning evidence shows visual-only temporal structure can support learning while motor-only temporal structure did not in the tested design.

Therefore:

```text
MotorPredictionContribution
!= AllTemporalLearningIsMotor
```

Likewise basic auditory/visual duration discrimination does not require overt motor synchronization.

---

# 38. B7 disposition

```text
B7
= STRONG for action-coupled / beat-predictive temporal regimes
= REJECT as total temporal cognition owner
```

HF11 remains owner of action-control dynamics.

---


B8 naturally allocates:


# 41. Pure heterogeneity fails positive commonality evidence

But a fully disconnected family is too strong.

Evidence includes:

```text
2025 general timing covariance
2024 interval-invariant learning transfer
prior cross-modal temporal-learning transfer
2023 context-invariant temporal precision across effectors
```

These imply some temporal structure transfers across contexts.

Therefore:

```text
TemporalCognition
!= SetOfCompletelyIndependentTasks
```

---

# 42. B8 must be revised into a layered plural architecture

The strongest B-round synthesis is:

```text
LayeredPluralTemporalArchitecture = {

  local_temporal_evidence:
    modality/domain-specific sensory or action dynamics,

  abstract_temporal_relation:
    transferable representation of interval/order/periodic relation where evidence supports,

  calibration:
    uncertainty + temporal context/prior + reliability weighting,

  task_support:
    attention / working memory / episodic memory / decision criterion,

  output_readout:
    discrimination / estimate / reproduction / synchronization / report,

  metacognition:
    confidence / calibration,

  experience:
    passage / felt temporal structure where relevant
}
```

Not every task requires every layer.

---


The timing-specific residual could only be something like:

```text

or

```

but each currently risks collapsing into HF8 representation or general HF20/HF3 evidence integration.
