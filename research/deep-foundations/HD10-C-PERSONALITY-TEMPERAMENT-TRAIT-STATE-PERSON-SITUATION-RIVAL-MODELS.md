# HD10-C — Personality, Temperament, Trait–State and Person×Situation Rival Models

## 0. Decision

HD10-C is the first substantive model-adjudication round of HD10.

It does **not** produce one winning theory of personality.

Instead, the rival comparison reveals a layered decomposition:

```text
Lexical approaches
→ discover socially encoded descriptive difference vocabulary

Big Five / FFM / HEXACO
→ provide broad shared descriptive coordinate systems

Latent state-trait models
→ decompose measured stable-person / occasion-specific / error variance

Dynamic / idiographic models
→ represent person-specific momentary/state organization

CAPS / social-cognitive models
→ represent conditional person×situation response organization

Whole Trait Theory
→ explicitly joins state-distribution description to social-cognitive explanation

Temperament traditions
→ constrain developmental origins / early-emerging reactivity-regulation profiles
```

These are not interchangeable competitors at one ontological level.

The strongest reconstruction is therefore:

```text
PersonalityDescription
!= PersonalityMeasurementModel
!= PersonalityStateDynamics
!= PersonalityConditionalResponseStructure
!= PersonalityMechanismConfiguration
!= PersonalityDevelopmentalHistory
```

No single existing rival cleanly owns all six.

At C close:

```text
HD10-C = completed
HF24 = UNKNOWN / not admitted
FoundationReopenCondition(HF0–HF23) = false
Next = HD10-D — Cognitive Ability / Intelligence Rival Models
```

```text
MeasurementInstrument
```

A model with strong psychometrics does not win ontology automatically.

A model with elegant dynamics does not win if it lacks evidence or shared descriptive coverage.

# 3. Rival M1 — lexical personality approach

## 3.1 Strong form

The lexical hypothesis begins from the idea that individual differences important in social life tend to become encoded in ordinary language.

Operationally:

```text
Language lexicon
→ collect person descriptors
→ clean/select descriptor class
→ obtain self/peer ratings
→ estimate covariance/factor structure
→ derive broad descriptive dimensions
```

This approach historically contributed to the Big Five and later cross-language six-factor findings.

## 3.2 What survives

Lexical work is powerful for discovering:

```text
which person differences a linguistic community repeatedly notices;
which descriptors covary across persons;
which broad descriptive axes recur across multiple languages;
which content is missing from one existing taxonomy.
```

Thus:

```text
LexicalApproach = DescriptiveDiscoveryProcedure
```

is retained.

## 3.3 Failure as ontology

Language encodes:

```text
social importance
observer salience
moral evaluation
role expectations
historical categorization
cultural communication needs
```

not necessarily the complete causal architecture of a Human.

Also descriptor selection changes recovered structure.

Therefore:

```text
LexicallySalientDifference != NaturalPsychologicalPrimitive
WordFrequency != MechanismImportance
NoSingleWord != NoRealDifference
```

Saucier/Goldberg's cross-language review itself found that Anglo-Germanic Big Five structure reproduced better in some languages than others and considered alternative factor solutions.

## 3.4 Disposition

```text
Retain as discovery/evidence method.
Reject as complete personality ontology.
```

# 4. Rival M2 — Big Five / Five-Factor Model as taxonomy

## 4.1 Strong form

The broad five dimensions are conventionally represented as:

```text
Extraversion
Agreeableness
Conscientiousness
Neuroticism / Emotional Stability
Openness / Intellect
```

The strongest modest claim is not that five mechanisms exist, but that a large amount of between-person covariance in trait descriptors/questionnaire ratings can be organized economically by a five-factor hierarchy.

## 4.2 Strong evidence

The FFM has support across:

```text
lexical descriptors
questionnaires
self report
peer/informant report
many populations/cultures
longitudinal prediction
external outcomes
```

McCrae & Costa's observer/instrument work showed convergence of five broad factors across self and peer methods.

## 4.3 What Big Five actually earns

HD10-C retains:

```text
BigFiveCoordinates_K
```

as one high-value shared descriptive coordinate system for many populations and instruments.

It is especially useful for:

```text
population comparison
compact description
covariate control
broad prediction
mapping narrower descriptors
communication across studies
```

## 4.4 What it does not earn

Factor count does not establish mechanism count.

```text
FiveBroadFactors
!= FiveCausalModules
```

A score such as `Extraversion=70` does not itself specify:

```text
state distribution width
situation exposure
if–then response structure
goals/beliefs/appraisals
learning history
current state
```

Thus:

```text
FFMCoordinate != PersonalityTotality
```

## 4.5 Cross-cultural falsifier

Tsimane Big Five evidence prevents unrestricted universality claims.

At the same time, many other cross-cultural/cross-language results prevent the opposite conclusion that broad trait coordinates are merely English artifacts.

Correct form:

```text
Transport(BigFive, instrument, population_A, population_B)
```

is empirical and scoped.

## 4.6 Disposition

```text
Retain strongly as broad descriptive taxonomy/coordinate family.
Reject as complete causal ontology.
```

# 5. Rival M3 — Five-Factor Theory (FFT) as causal extension

## 5.1 Important separation

```text
Five-Factor Model / Big Five taxonomy
!= Five-Factor Theory
```

FFT adds substantive causal claims.

A common FFT architecture separates:

```text
BasicTendencies
CharacteristicAdaptations
SelfConcept
ObjectiveBiography
ExternalInfluences
```

and treats Big-Five traits as basic tendencies, with characteristic adaptations including skills, habits, goals, beliefs, roles and relationships.

## 5.2 What survives

The distinction:

```text
broad persistent disposition-like parameter
!= acquired/contextual adaptation
```

is useful.

It protects against identifying:

```text
occupation
habit
goal
relationship
skill
current role
```

with a broad trait score.

## 5.3 Strong failure mode

Strong versions of FFT have treated traits as biologically grounded basic tendencies largely insulated from direct environmental shaping, with environment acting mainly through characteristic adaptations.

This is too strong as a general ontology.

Personality trait measures can change:

```text
across adulthood
following some life events
under structured interventions
through deliberate change programs
```

A 2017 systematic review of 207 intervention studies found meaningful changes in personality trait measures, including effects persisting beyond interventions.

A later randomized digital personality-change intervention also produced targeted Big-Five changes.

Therefore:

```text
BroadTraitStability
!= EnvironmentalInsulation
```

and:

```text
BiologicalContribution
!= BiologyOnlyTraitCause
```

## 5.4 Another pressure

HF6 already models persistent history-dependent update:

```text
Theta_{t+1}
= U(Theta_t, Experience_t, Outcome_t, State_t, Context_t)
```

A personality theory cannot categorically forbid learned/environmental update of persistent person parameters without contradicting demonstrated Human plasticity.

## 5.5 Disposition

```text
Retain BasicTendency != CharacteristicAdaptation as useful distinction.
Reject environmentally insulated / biology-exclusive trait ontology as universal.
```

# 6. Rival M4 — HEXACO / six-factor lexical structure

## 6.1 Strong form

HEXACO uses:

```text
Honesty–Humility
Emotionality
eXtraversion
Agreeableness
Conscientiousness
Openness
```

Cross-language psycholexical studies in seven languages recovered similar six-factor structures, including a Honesty–Humility dimension and reorganized Emotionality/Agreeableness content.

## 6.2 Why it matters structurally

HEXACO is not merely `Big Five + one extra variable`.

It demonstrates a deeper falsifier:

```text
BroadTraitCoordinateSystem
is sensitive to lexical corpus + language set + rotational/selection choices.
```

The placement of anger, sentimentality, sincerity/fairness and related content differs materially from many Big-Five representations.

Thus:

```text
BroadFactorLabel != FixedSemanticRegionAcrossTaxonomies
```

## 6.3 Stronger explanatory proposals

Ashton & Lee linked Honesty–Humility and Emotionality/Agreeableness patterns to reciprocal/kin altruism and related evolutionary concepts.

This is a legitimate explanatory hypothesis, but:

```text
EvolutionaryInterpretation
!= EstablishedMechanismIdentity
```

without developmental/causal mediation evidence.

## 6.4 What survives

HEXACO provides strong evidence that:

```text
five is not ontologically privileged by default;
Honesty–Humility-like variance can be substantively important;
broad personality coordinates are taxonomy-dependent yet reusable.
```

## 6.5 Disposition

```text
Retain as high-value alternative broad descriptive coordinate system.
Retain selected explanatory hypotheses for testing.
Reject six factors as six natural causal modules by definition.
```

# 7. Big Five versus HEXACO — result

HD10-C does not choose 5 versus 6 as a metaphysical winner.

They are better interpreted as competing/shared coordinate systems over partially overlapping descriptor spaces.

```text
CoordinateSystem_K
```

must declare:

```text
lexicon / item universe
population/language
factor extraction/rotation
measurement method
facet hierarchy
intended use
```

The existence of both taxonomies is evidence **against**:

```text
OneNamedFactorization = unique personality ontology
```

rather than evidence that one must be discarded.

# 8. Rival M5 — temperament traditions

## 8.1 Strongest common denominator

Temperament traditions study relatively early-emerging person differences in domains such as:

```text
reactivity
affectivity
activity/orienting
approach/withdrawal
attention/regulation
effortful control
```

Rothbart-style work defines temperament through constitutionally based differences in reactivity and self-regulation, while emphasizing development of attentional/regulatory control.

## 8.2 What survives

Temperament contributes three structures underrepresented in adult trait taxonomies:

```text
1. developmental timing
2. reactivity/regulation decomposition
3. process-level links to attention/affect/action systems
```

It therefore interfaces naturally with:

```text
HF3 attention/control
HF4 motivation/regulation
HF5 organismic regulation
HF6 development/plasticity
HF21 affect/appraisal
```

## 8.3 Temperament is not biology-only

Even in psychobiological temperament traditions:

```text
constitutional != immutable
```

Developmental evidence shows regulatory systems change substantially, and environment/socialization can alter trajectories of expression.

Thus:

```text
Temperament != FixedInnateEssence
```

## 8.4 Temperament is not personality by definition

Longitudinal work shows continuity between childhood temperament dimensions and later Big-Five personality dimensions, but not identity.

Retain:

```text
TemperamentProfile_t
→ contributes to later PersonalityProfile
```

without:

```text
Temperament = PersonalityAtYoungAge
```

## 8.5 Multiple temperament traditions

Rothbart's reactivity/regulation framing, behavioral inhibition traditions, EAS-like dimensions and other traditions need not share one exact factor structure.

Thus:

```text
TemperamentResearchDomain != OneTemperamentOntology
```

## 8.6 Disposition

```text
Retain temperament as developmental reactivity/regulation family and causal/developmental pressure layer.
Reject it as synonym for personality or separate immutable biological essence.
```

# 9. Rival M6 — social-cognitive / CAPS

## 9.1 Strong form

Mischel & Shoda's Cognitive-Affective Personality System explains consistency and variability by stable organization among cognitive-affective units such as:

```text
encodings
expectancies/beliefs
affects
goals/values
competencies/self-regulatory plans
```

interacting with psychological features of situations.

Core form:

```text
If psychological situation A
→ response pattern X

If psychological situation B
→ response pattern Y
```

and the **pattern** itself can be person-characteristic.

## 9.2 Strong evidence

Shoda, Mischel & Wright found stable idiographic situation–behavior signatures in naturalistic camp behavior: cross-situational consistency depended on psychological similarity of situations, while individuals showed distinctive stable if–then patterns.

This directly falsifies:

```text
PersonalityConsistency = SameBehaviorEverywhere
```

## 9.3 What survives

CAPS gives HD10 an important object:

```text
ConditionalResponseStructure_H
```

or more generally:

```text
P(ResponseState_{t+1} | PsychologicalSituation_t,
                         CurrentState_t,
                         History_t,
                         MechanismConfiguration_H)
```

This is deeper than an average trait score.

## 9.4 Existing HF consumption

CAPS-like mechanisms do not require a new Human subsystem.

Its main units already map into:

```text
HF3 attention/control
HF4 goals/value/motivation
HF6 learned/history-dependent changes
HF8 encodings/beliefs/schemas
HF10 plans/policies
HF21 affect/appraisal
HF22 relationship-specific expectations
```

Thus personality mechanism may be **organization across existing foundations**.

## 9.5 Main limitations

CAPS does not by itself provide:

```text
one broad shared descriptive taxonomy
complete biological/developmental source model
simple population-comparison coordinates
measurement identification of all cognitive-affective links
```

Also `psychological situation` is not directly given by physical context; it requires representation/appraisal.

Thus:

```text
PhysicalSituation != PsychologicalSituation
```

and person-specific if–then patterns can be hard to estimate without rich repeated sampling.

## 9.6 Disposition

```text
Retain strongly as conditional mechanism/organization architecture.
Reject as complete descriptive taxonomy or complete developmental ontology.
```

# 10. Rival M7 — Whole Trait Theory / density distributions

## 10.1 Strong form

Whole Trait Theory explicitly separates:

```text
Trait_DES
= descriptive density distribution of corresponding personality states

Trait_EXP
= explanatory social-cognitive mechanisms producing those state distributions
```

This directly aligns with HD10-A's firewall:

```text
TraitDescriptor != Mechanism
```

while connecting the two through a causal relation rather than identity.

## 10.2 Major strength

Whole Trait Theory can simultaneously represent:

```text
high within-person variability
+ stable person differences in distribution parameters
```

A person can move across a wide range of extraversion-like states while retaining a characteristic distribution.

This defeats:

```text
Trait = ConstantState
```

## 10.3 Strong integration

Whole Trait also recognizes that social-cognitive processes, goals and situations predict momentary trait states.

Thus it bridges:

```text
Big-trait description
↔ momentary state expression
↔ social-cognitive mechanisms
```

better than a pure factor taxonomy.

## 10.4 First HD10-C reconstruction: actual distribution is exposure-dependent

However HD10 must add a missing distinction.

Observed state distribution depends not only on person mechanism but on the situations actually encountered:

```text
ActualStateDistribution_H,T
= Realize(
    ConditionalResponseStructure_H,
    SituationExposureDistribution_H,T,
    CurrentState/History
  )
```

Therefore:

```text
ActualStateDistribution
!= CounterfactualResponseStructure
```

A monk, prisoner, remote worker, soldier, new parent or socially isolated person may express a different state distribution because their situation exposure changes.

## 10.5 Second reconstruction: descriptor-to-mechanism inversion is non-unique

Different mechanisms can generate similar state distributions:

```text
MechanismSet_A → Distribution_X
MechanismSet_B → Distribution_X
```

and the same mechanisms can generate different actual distributions under different situation exposure.

Therefore:

```text
Trait_DES
!= UniqueIdentifier(Trait_EXP)
```

This is an **equifinality / exposure** correction to any strong inverse reading of Whole Trait.

## 10.6 Big Five state axes are still coordinates

Whole Trait commonly uses Big-Five state content.

HD10-C retains that as useful but does not assume:

```text
EveryImportantStateDifference
must project cleanly onto BigFive
```

HEXACO and lexical transport evidence prevent that closure.

## 10.7 Disposition

```text
Retain Whole Trait as strongest current integration template.
Retain density-distribution description and social-cognitive explanatory program.
Reconstruct with explicit SituationExposureDistribution and non-identifiable mechanism mapping.
Reject Big-Five coordinate uniqueness and descriptor→mechanism one-to-one inference.
```

# 11. Rival M8 — latent state-trait (LST) family

## 11.1 Strong form

Latent state-trait models decompose observed measurement variance into components such as:

```text
stable person-specific / trait consistency
occasion-specific state / person×occasion variance
method effects
random measurement error
```

Extensions can explicitly analyze person, situation and person×situation effects.

## 11.2 What survives

LST gives HD10 rigorous estimands for questions like:

```text
How much reliable variance is stable across occasions?
How much is occasion-specific?
How much is method-specific?
Do self/informant methods share trait-like variance?
```

It is extremely valuable for B/C evidence discipline.

## 11.3 Failure as substantive personality theory

LST is largely a measurement/statistical framework.

`Trait variance` in an LST model means variance satisfying model-defined persistence properties; it does not reveal what causal system creates that variance.

Thus:

```text
LSTTraitComponent != PersonalityMechanism
```

and:

```text
OccasionSpecificVariance
!= SituationCauseIdentified
```

without measured situation/mechanism variables.

Different LST specifications can also embody different assumptions about autoregression, change and method effects.

## 11.4 Disposition

```text
Retain strongly as measurement decomposition family.
Reject as complete substantive personality ontology.
```

# 12. Rival M9 — dynamic / idiographic models

## 12.1 Strong form

Idiographic approaches estimate one person's own:

```text
state profiles
within-person covariance
transition dynamics
context-response relations
```

rather than assuming population covariance is each person's architecture.

## 12.2 Recent evidence

Lee & Beck's idiographic momentary-profile work found most participants expressed multiple distinct multivariate personality-state profiles, and situation characteristics predicted profile expression.

This strongly falsifies:

```text
OnePerson = OneStaticTraitPoint
```

## 12.3 What survives

HD10 retains:

```text
PersonSpecificStateProfileSet_H
TransitionStructure_H
ContextSensitivity_H
```

as legitimate person-level objects.

## 12.4 Main limitations

Idiographic models can be:

```text
data hungry
sampling-policy dependent
sensitive to clustering/model choice
hard to compare across persons
weakly identified in sparse contexts
primarily descriptive unless mechanisms are measured
```

A unique profile is not automatically a causal module.

Thus:

```text
IdiographicPattern != MechanismByDefinition
```

## 12.5 Disposition

```text
Retain as indispensable person-specific realization layer.
Reject as replacement for all shared population coordinates or mechanism theory.
```

# 14. The decisive distinction C adds: exposure distribution

A person's observed personality states are jointly produced by:

```text
PersonMechanismConfiguration_H
× PsychologicalSituation_t
× CurrentState_t
× History_t
```

But the person's **observed distribution** additionally depends on which situations they actually encounter.

Define:

```text
SituationExposureDistribution_H,T
= distribution of psychologically relevant situations encountered by H over interval T
```

Then:

```text
StateDistribution_H,T
= ∫ ResponseDistribution_H(S, state, history)
    d SituationExposureDistribution_H,T(S)
```

conceptually.

This gives:

```text
SamePersonMechanism + DifferentExposure
→ DifferentObservedTraitDistribution
```

and:

```text
DifferentMechanisms + DifferentExposures
→ PotentiallySameObservedDistribution
```

Therefore:

```text
TraitScore
cannot identify
CounterfactualPersonalityResponseStructure
without situation/context evidence.
```

# 15. Descriptive stability now has three possible locations

A person's apparent stability can come from:

```text
A. stable internal mechanism configuration
B. stable situation exposure / social niche
C. stable interaction between person and selected/evoked situations
```

Thus:

```text
StableTraitDescription
!= StableInternalMechanismByDefinition
```

Personality can also shape future exposure through:

```text
selection
evocation
niche construction
relationship formation
role choice
```

so person and environment can form a feedback loop.

# 16. Selection and social niche are part of personality realization, not trait essence

A person may repeatedly enter/construct situations compatible with their current profile.

Conceptually:

```text
PersonalityParameters_t
→ SituationSelection_t
→ ExposureDistribution_t
→ StateExpression_t
→ Learning / SocialResponse
→ PersonalityParameters_{t+1}
```

This avoids both extremes:

```text
Environment alone causes behavior
```

and:

```text
Trait alone causes behavior
```

# 19. Reconstructed Ordivon personality grammar

HD10-C proposes the following **research grammar**, not a new Foundation:

```text
PersonalityDescription_H,T,K
= description of relatively persistent person-specific regularities
  using coordinate system K over interval T

StateDistribution_H,T,K
= distribution of momentary state expressions in coordinate system K
  under actual exposure distribution

SituationExposureDistribution_H,T
= psychologically relevant situations actually encountered/selected/evoked

ConditionalResponseStructure_H
= conditional distribution/function mapping represented situations + current state/history
  to likely state/action expression

PersonalityMechanismConfiguration_H
= persistent organization/parameterization across attention, goals, beliefs,
  affect, regulation, learning, policy and relational mechanisms

DevelopmentalTrajectory_H
= history by which those parameters/configurations changed over time
```

Key non-identities:

```text
PersonalityDescription
!= StateDistribution
!= SituationExposureDistribution
!= ConditionalResponseStructure
!= PersonalityMechanismConfiguration
!= DevelopmentalTrajectory
```

# 20. `Trait` after C

A trait term can now refer to at least three different objects.

## Trait-D — descriptive

```text
TraitDescription_D(H,T,K)
```

= broad description of relatively persistent distributional regularity.

## Trait-R — response structure

```text
TraitResponse_D(H,S)
```

= persistent conditional tendency under a declared situation class.

## Trait-M — mechanism shorthand

Sometimes ordinary theory uses a trait label as shorthand for the underlying mechanism configuration.

HD10 prohibits collapsing them:

```text
Trait-D != Trait-R != Trait-M
```

unless a theory provides linking evidence.

This resolves much of the historical trait/situation dispute as a type error.

---

# 21. Personality state after C

A personality state is:

```text
PersonalityState_K(H,t)
= momentary pattern of thought/affect/motivation/behavior
  projected into declared personality coordinate system K
```

It is not a tiny temporary copy of a trait mechanism.

```text
StateExtraversion_t
!= ExtraversionMechanism_t
```

It is an expression/projection.

---

# 22. Broad factors after C

Big Five and HEXACO broad dimensions remain useful as:

```text
SharedDescriptorCoordinates_K
```

but Ordivon does not require exactly one K.

Possible legitimate uses:

```text
K = BigFive
K = HEXACO
K = domain-specific facet system
K = idiographic coordinate system
```

The use case determines whether cross-person comparability or person-specific fidelity is more important.

# 23. Agent-era perturbation I — personalized agents alter exposure distributions

Persistent AI can change which situations a Human experiences:

```text
recommendations
conversation partners
information exposure
task delegation
social mediation
calendar/choice architecture
conflict buffering
opportunity generation
```

Therefore:

```text
PersistentAgentPolicy
→ SituationExposureDistribution_H
→ PersonalityStateDistribution_H
```

without immediate internal personality-mechanism change.

Thus traditional trait measurement can record apparent trait shift even when the first-order change is ecological/support-mediated.

---

# 24. Agent-era perturbation II — estimated personality can become causal

A persistent agent can estimate a person's traits and then personalize future environments from those estimates:

```text
PastBehavior
→ TraitEstimate
→ AgentPolicy
→ FutureExposure
→ FutureBehavior
→ UpdatedTraitEstimate
```

This creates a performative feedback loop.

Therefore:

```text
TraitPredictionSystem
can become part of trait-expression causality.
```

HF0's reflexivity principle becomes materially stronger in Agent-era Human modeling.

# 25. Agent-era perturbation III — externalized mechanism support

An agent can supply:

```text
planning
emotion regulation prompts
memory
social scripts
response inhibition scaffolds
goal reminders
```
