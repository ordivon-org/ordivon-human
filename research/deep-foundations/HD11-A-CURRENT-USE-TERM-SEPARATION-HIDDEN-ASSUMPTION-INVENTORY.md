# HD11-A — Current-Use, Term Separation and Hidden-Assumption Inventory

## 0. Entry state

```text
HF0–HF23 = preserved
HF24 = UNKNOWN / not admitted

HD11
= Imagination, Nonactual Scenario Construction,
  Pretence and Reality Monitoring

HD11-A
= current-use / term separation / hidden-assumption inventory
```

The round does **not** ask:

```text

```

> Which distinct phenomena are currently hidden under `imagination`, which of them are already owned by existing Foundations, and what residual object/process remains after those separations?

```text

engage with fiction without believing it;

hallucinate while taking content as real;
create novel symbolic output without a rich internal scene;
and narrate actual events without imagining fictional worlds.
```

Therefore:

```text
SurfaceVocabularyOverlap != SharedPrimitive
```

# 3. `Mental imagery`

Working research use:

> sensory- or perceptual-like representational/experiential content in the relative absence of corresponding current external sensory input.

Important qualifiers:

```text
modality
vividness
voluntary/involuntary
conscious/reportable vs inferred processing
static/dynamic
```

Mental imagery is not necessarily visual.

And visual imagery is not imagination totality.

```text
VisualImagery
!= Imagination
```

---

# 4. Aphantasia is the decisive imagery falsifier

2025 evidence is especially useful because it separates subjective visual imagery from other processing.

A high-field fMRI study compared typical imagers and congenital aphantasic participants across object shape, color, words, faces and spatial relations while testing imagery and perception.

A separate 2025 behavioral study found that aphantasic and control participants showed similar property-verification signatures interpreted as mental simulation during language comprehension, despite the aphantasic group's severely reduced conscious voluntary visual imagery.

Thus at minimum:

```text
ConsciousVoluntaryVisualImagery
!= MentalSimulationByDefinition
```

and:

```text
NoReportableVisualImage
!= NoInternallyGeneratedTaskRepresentation
```

This single dissociation kills any HD11 model whose primitive is `picture in the mind's eye`.

---

# 5. `Imagery-like processing` versus `experienced imagery`

Aphantasia also exposes a measurement problem.

Possible levels include:

```text
sensory-format information processing
imagery-like priming/activation
conscious imagery experience
reported vividness
metacognitive access to imagery
```

These are not identical.

HD11 should therefore avoid:

```text
VisualCortexActivation = ExperiencedImagery
```

and:

```text
NoVividnessReport = NoRelevantInternalRepresentation
```

without a measurement model.

HF2 retains experience ownership.

# 7. `Mental simulation`

`Simulation` is more process-like than `imagery`.

A minimal research use is:

> internally evolving or evaluating represented state(s) under some transition, constraint or relational structure.

But this is still too broad.

Simulation may be:

```text
implicit or explicit
conscious or nonconscious
sensory-like or abstract
actual-model predictive
counterfactual
future-oriented
motor
social
linguistic
```

Therefore:

```text
Simulation != ImaginationByDefinition
```

because simulation can occur automatically in comprehension or control without a deliberate imaginative stance.

---

# 8. Strong dissociation: imagery versus simulation

The 2025 aphantasia property-verification result provides exactly the HD11 term-separation case required here.

If participants with very weak/absent conscious voluntary visual imagery can still show evidence consistent with mental simulation in semantic processing, then:

```text
MentalSimulation
can survive major VisualImagery impairment
```

at least in that task family.

This does **not** prove simulation is wholly independent of all imagery-like processing.

It proves only:

```text
VoluntaryConsciousVisualImagery
is not a necessary identity condition for MentalSimulation.
```

---

# 9. `Prospection`

Prospection is a temporal-direction family:

```text
cognition concerning potential future states/events/actions
```

It can include:

```text
future event imagination
forecasting
planning
worry
hope
prospective memory
future self thought
```

These have different owners.

Therefore:

```text
Prospection != Imagination
Prospection != Planning
Prospection != EpisodicFutureThinking
```

---

# 10. Future orientation does not require narrative construction

2026 experiments explicitly isolated temporal orientation from narrative construction.

Young and older adults made agency/self-efficacy judgments while imagining near versus distant future states, using tasks designed to manipulate temporal construal without requiring narrative construction.

Therefore:

```text
FutureOrientation
!= NarrativeConstruction
```

and reduced episodic future-event detail does not imply absence of all future-directed cognition.

This blocks `future imagination = narrative episode construction` as a universal model.

---

Typical coordinates include:

```text
phenomenological richness
```

But future thought can also be:

```text
semantic
abstract

verbal

```

Thus:

```text
EpisodicFutureThinking
!= FutureThinkingTotality
```

# 12. `Counterfactual`

HF9 already owns the canonical counterfactual relation:

```text
actual world W
+ intervention/change X'
+ query Y'
+ assumptions/invariants/model
```

Counterfactual content is nonactual relative to an actual anchor.

Therefore:

```text
Counterfactual
!= AnyImaginedAlternative
```

because an invented fictional world need not be generated by changing one actual-world variable under preserved invariants.

---

# 13. `Hypothetical`

A hypothetical is best treated as a **supposition/conditional reasoning stance**:

```text
Suppose P ...
```

P may be:

```text
actually true
possibly true
unknown
counterfactual
fictional stipulation
```

So:

```text
Hypothetical != Counterfactual
Hypothetical != Imagination
```

A Human can reason propositionally under a supposition without constructing a vivid scenario.

---

# 14. `Pretence / pretense`

Pretence is not a content type alone.

It is a stance/action organization where the Human acts, communicates or reasons under a local nonactual stipulation while some actual-state knowledge can remain available.

A useful minimum structure is:

```text
ActualState
PretendStipulation
PretendSelf/WorldModel
PretendActionPolicy
LeakageFromActualKnowledge
Exit/ReturnCondition
```

---

# 15. Pretense is not false belief or mere false report

2026 game experiments asked adults who knew the solution to behave as though they did not know it.

Participants approximated genuine uninformed play, including broad and subtle decision patterns, while computational/statistical traces still showed imperfect leakage/overacting.

Thus:

```text
PretendedState
!= ActualBeliefState
```

and:

```text
Pretence
!= MereFalseReport
```

This is a strong candidate case for self/world-model simulation under altered informational constraints.

---

# 16. Pretence is not deception by definition

Pretend play can be mutually recognized.

Deception requires an intention/relation concerning another actor's belief or interpretation.

Therefore:

```text
Pretence != Deception
```

though deception can use simulated states.

Ownership split:

```text
pretend scenario structure → HD11 candidate
communicative deception     → HF12/HOC6/HF23 + normative/security domain
```

---

# 17. `Fiction`

Fiction is primarily a **socially/symbolically stabilized content/artifact/discourse status**.

It can contain:

```text
real places
historical persons
invented entities
counterfactual histories
impossible laws
```

A fictional artifact can exist without one particular Human currently imagining its world.

Thus:

```text
Fiction != Imagination
```

Media/HF23 own major artifact/symbolic dimensions.

HD11 only owns Human-side construction/simulation if a residual survives.

---

# 18. Fictional truth is local, not actual-world truth

Within a fiction:

```text
P can be true-in-story
```

while:

```text
P is not actual-world true.
```

So preserve:

```text
FictionalTruth(P,F)
!= ActualWorldTruth(P)
```

This is a World/Media/HF23 boundary problem rather than evidence that Human belief changed.

# 20. `Mind wandering`

Mind wandering is primarily about the relation between ongoing thought and the current task/perceptual field.

Useful dimensions include:

```text
task-related vs off-task
spontaneous vs deliberate
aware/self-caught vs unaware/probe-caught
past/present/future
self/other
real/imaginary
```

Therefore:

```text
MindWandering != Imagination
```

because a mind-wandering episode may be:

```text
actual autobiographical memory
current concern
verbal rumination
future plan
imaginary scene
```

---

# 21. Mind wandering also separates generation from meta-awareness

A 2025 experiment found dissociable effects on aware/self-caught and unaware/probe-caught mind wandering, with self- and future-related content varying by manipulation.

This supports:

```text
ThoughtGeneration
!= MetaAwarenessOfThought
```

and:

```text
Spontaneous != UnconsciousByDefinition
```

HF3 retains attention/meta-awareness ownership.

# 22. `Dreaming`

Dreaming is a sleep-associated conscious-experience family.

HF2 already establishes the key falsifier:

```text
Experience present
+ ExternalConnectedness reduced/altered
```

Dream content can be:

```text
scene-like
narrative
fragmentary
social
spatial
absurd
realistic
lucid/nonlucid
```

But:

```text
Dreaming != VoluntaryImagination
```

because generation/control/reality commitment can differ radically.

---

# 23. Lucid dreaming separates phenomenal realness from cognitive reality judgment

Recent source-memory work on dream lucidity is useful because participants can differ in discrimination of imagined/perceived sources even when vividness is high.

More generally, lucid dreaming provides the logical dissociation:

```text
ExperienceCanFeelReal
+ HumanCanKnowItIsADream
```

Therefore:

```text
PhenomenalRealness
!= HumanRealityCommitment
```

This distinction is mandatory for HD11.

---

# 24. `Hallucination`

Use minimally as:

> perception-like experience/content occurring without the corresponding ordinary external stimulus/source that would normally explain that content.

Do not define hallucination as imagination.

A hallucination can involve:

```text
high phenomenal realness
external-source attribution
actual-world endorsement
low voluntary control
```

which is almost the opposite stance from ordinary deliberate imagination.

Thus:

```text
Hallucination != Imagination
```

while sharing internally generated/perception-like machinery remains a live mechanistic possibility.

---

# 25. Reality monitoring prevents the hallucination/imagination collapse

2025 Neuron evidence shows trial-level reality judgments depend on sensory activity generated by either imagery or perception plus frontal reality-classification signals.

This directly motivates:

```text
GenerationSource
!= ExperiencedSignalStrength
!= RealityJudgment
```

and:

```text
InternallyGenerated
!= KnownInternal
```

No one signal can be treated as the source label by definition.

# 28. Dynamic imagined navigation supports `ScenarioState_t`

2025 intracranial work found related hippocampal theta dynamics during real-world and imagined navigation, including structure related to relative route position despite absence of external navigational cues during the imagined condition.

This supports a candidate:

```text
ScenarioState_t
→ ScenarioState_t+1
```

with structured internal spatial evolution.

It does **not** establish a general imagination mechanism.

---

# 29. Dynamic imagined objects expose capacity/error constraints

2025 preregistered experiments on mentally moving objects found systematic capacity limits when participants had to continue object motion in imagination.

This pressures models where imagination is only:

```text
retrieve one representation
```

and motivates testing:

```text
number of maintained entities
transition complexity
update error
resource load
```

as separate coordinates.

# 34. `Reality monitoring`

Reality monitoring asks a related but not identical question:

```text
Is this content/signal/event attributed to external reality or internal generation?
```

It can operate:

```text
online/perceptually
or retrospectively through memory/source judgments
```

HD11-A retains:

```text
SourceMonitoring
!= RealityMonitoringByDefinition
```

because source monitoring may distinguish:

```text
heard from Person A
vs heard from Person B
```

without an internal/external ambiguity, while reality monitoring specifically targets internal/external reality attribution.

Their overlap remains a B-round model question.

# 35. Core four-way separation: actuality, commitment, source, phenomenal realness

This is HD11-A's strongest positive result.

Do not collapse:

```text
ActualityRelation
HumanRealityCommitment
SourceAttribution
PhenomenalRealness
```

Examples:

## Ordinary deliberate imagination

```text
ActualityRelation       = nonactual/possible
RealityCommitment       = known nonactual
SourceAttribution       = internal
PhenomenalRealness      = low to high
```

## False belief

```text
ActualityRelation       = false/nonactual
RealityCommitment       = endorsed actual
SourceAttribution       = variable
PhenomenalRealness      = irrelevant/variable
```

## Hallucination

```text
ActualityRelation       = no matching ordinary external source
RealityCommitment       = may be endorsed actual
SourceAttribution       = may be external
PhenomenalRealness      = often high
```

## Lucid dream

```text
ActualityRelation       = dream/internal
RealityCommitment       = recognized dream/nonactual
SourceAttribution       = recognized internal/dream
PhenomenalRealness      = can be high
```

## Fiction engagement

```text
ActualityRelation       = fictional stipulation
RealityCommitment       = known fictional
SourceAttribution       = external artifact + internal construction
PhenomenalRealness      = variable
```

These cases cannot be represented by one `reality score`.

Human reality commitment and belief are closely related but not identical at this stage.

For example:

```text

```


Retain:


pending B-round formalization.
