# HD11-C — Cross-Regime Invariance, Selective Dissociation & Ownership Extraction

## 0. Entry question

HD11-B left:

```text
ScenarioConstructionProcess
= strongest bounded functional survivor
= not yet peer Foundation
```

C asks the decisive question:

> Does one reusable construction/update process survive sensory deprivation, imagery variation, memory lesions, motor simulation, social/self simulation, abstract hypotheticals, pretense, psychosis/reality-monitoring disturbance and dream regimes strongly enough to own a peer Human Foundation?

The answer after cross-regime attack is:

```text
NO at current evidence.
```

The reason is not absence of structure.

It is **operator/owner splitting**.

---

# 1. What would have counted as a C-round win?

For the B-round M6 candidate to become peer-level, C required evidence for a reusable process with:

```text
C1 cross-modal persistence;
C2 selective variation not reducible to imagery vividness;
C3 selective variation not reducible to memory material availability;
C4 selective variation not reducible to working-memory/control capacity;
C5 shared construction/update operators across spatial, motor, social and abstract domains;
C6 independence from source/reality monitoring;
C7 Human-side ownership under Agent-seeded content;
C8 deletion harm after giving all domain-specific operators back to neighboring HFs.
```

The decisive conditions are C5 and C8.

---

# 2. Regime R1 — aphantasia

HD11-A already established:

```text
ConsciousVoluntaryVisualImagery
!= MentalSimulationByDefinition
```

Aphantasia is therefore useful evidence for:

```text
VisualPhenomenology
!= StructuredInternalProcessing
```

But it is not enough to establish one generic scenario engine.

Aphantasia can show different profiles across:

```text
object imagery
spatial imagery
autobiographical reliving
future-event richness
semantic simulation
```

So C retains:

```text
ImageryVividness
!= ScenarioStructureByDefinition
```

while refusing:

```text
Aphantasia
→ proof of one modality-independent ScenarioConstruction module
```

---

# 3. Regime R2 — congenital blindness

Congenital blindness is a stronger cross-modal falsifier because the Human lacks ordinary visual experience rather than merely reporting weak visual imagery.

Primary studies show congenitally blind participants can:

```text
perform spatial/pictorial imagery-like tasks;
build metric spatial representations from haptic/verbal/locomotor sources;
recruit sensory-independent spatial organization in parietal cortex;
build/manipulate cognitive maps without visual input.
```

Performance can nevertheless differ by:

```text
task complexity
sensory input mode
mobility skill
strategy
visual-experience history
```

---

# 4. Blindness result: scenario structure is not visually owned

The strongest positive result is:

```text
StructuredSpatialRepresentation
can survive absence of visual experience.
```

Therefore:

```text
ScenarioStructure
!= VisualImagery
```

and:

```text
SpatialConstruction
can be cross-modal.
```

This materially strengthens the idea of **format-flexible structured modeling**.

But it does not establish a generic scenario-construction owner.

Why?

Because the same evidence shows representation strategy and performance depend on:

```text
haptic/auditory/locomotor encoding
spatial skill
mobility history
perspective/angle demands
```

Thus cross-modal structure is real, but its construction is still mediated by domain-specific spatial machinery.

---

# 5. R2 ownership extraction

Best current decomposition:

```text
HF8
→ spatial/relational MentalModel substrate

HF20
→ sensory evidence / spatial perceptual inputs where current perception matters

HF7
→ learned environmental/spatial history

HF3
→ temporary maintenance/manipulation

spatial/scene construction projection
→ arrangement/update of scene/spatial relations
```

The surviving spatial projection is important.

But this does not license:

```text
spatial scene constructor
= universal scenario constructor.
```

# 6. Regime R3 — adult hippocampal amnesia

B-round lesion evidence remains among the strongest evidence for **scene construction as a real functional family**.

Useful dissociations include:

```text
semantic possibility knowledge relatively available
while
constructive possibility / coherent scene modeling impaired
```

and:

```text
future projection demand
!= scene-construction demand.
```

Thus:

```text
SceneConstruction
!= SemanticKnowledge
!= FutureOrientation.
```

This supports a narrower `SceneConstructionProjection` strongly.

---

# 7. Regime R4 — developmental amnesia

Developmental amnesia prevents anatomical overreach.

Some early hippocampal-damage cases retain surprisingly good scene construction despite severe episodic-memory impairment.

Therefore:

```text
HippocampalIntegrity
!= SceneConstructionByDefinition
```

and:

```text
SevereEpisodicMemoryImpairment
!= UniversalSceneConstructionFailure.
```

This means the functional process may be distributed, plastic or supportable through alternative routes.

But again, that evidence is scene/episodic-specific.

---

# 8. What the amnesia pair actually proves

Adult acquired lesion and developmental lesion evidence jointly support:

```text
SceneConstruction
= functionally meaningful and dissociable
```

but not:

```text
SceneConstruction
= one anatomical module
```

and not:

```text
SceneConstruction
= all ScenarioConstruction.
```

C therefore retains:

```text
SceneConstructionProjection
```

as a strong scientific projection.

---

# 9. Regime R5 — motor imagery

Motor imagery is a decisive ownership test because it appears to satisfy the generic M6 language:

```text
state initialization
transition/update
predicted consequence
termination
```

Yet HF11 already has a much more specific architecture:

```text
motor preparation
control policy
feedforward prediction
forward/internal models
predicted sensory consequences
state estimation
feedback
motor inhibition
```

2025 typing-imagery experiments provide evidence that motor inhibition contributes to keeping imagined action covert.

2025 action-imagery-practice work finds effector-dependent sequence representations after imagery practice.

2026 motor-imagery work further supports forward-model prediction of sensory consequences during visual/kinesthetic motor imagery.

---

# 10. Motor imagery falsifies universal construction ownership

If M6 owns motor imagery because it contains a dynamic internal state, then it steals HF11's domain-specific causal machinery.

The better model is:

```text
MotorImageryEpisode = {
  HF11 action/motor internal model,
  HF11 predicted action consequences,
  HF11 execution inhibition / non-release,
  HF3 control/maintenance,
  HF2 imagery phenomenology if conscious,
  reality/stance coordinates
}
```

Therefore:

```text
MotorImagery
!= GenericScenarioConstructionOwner
```

and:

```text
SameAbstractStateUpdatePattern
!= SameSubstantiveMechanism.
```

This is one of C's strongest anti-HF24 results.

# 11. Regime R6 — social / self mental-state simulation

Social simulation also appears scenario-like:

```text
Agent A
Agent B
beliefs/preferences/perspectives
possible actions
state changes
```

But recent Human fMRI evidence distinguishes:

```text
agent-specific self mental-state reasoning
and
agent-general self/other mental-state reasoning.
```

HF12 already owns:

```text
partner models
individual agent states/models/goals
prediction of partners
joint task representation
perspective/common-ground relations
```

HF1 owns self-model/identity structure where self is the target.

---

# 12. Social simulation result

A social scenario can reuse a generic representational substrate, but its update semantics depend on:

```text
belief attribution
preference attribution
perspective
agent model
social history
roles/common ground
```

Those are not equivalent to spatial transition operators.

Therefore:

```text
SocialMentalSimulation
!= SpatialSceneConstruction
```

and the only common remainder is:

```text
structured model
+ domain-specific update.
```

That remainder is too abstract for a new owner.

---

# 13. Regime R7 — verbal / abstract hypothetical reasoning

Consider:

```text
Suppose all A are B.
Suppose taxation rule X changes.
Suppose a graph edge is removed.
Suppose a program invariant is false.
```

A Human may manipulate these alternatives without:

```text
scene imagery
agent model
motor prediction
spatial layout
```

HF8 already owns structured representations/mental models.

HF9 owns inferential transformation, hypothetical/counterfactual reasoning and search over representations.

Thus:

```text
AbstractHypotheticalModeling
= HF8 substrate + HF9 operators
```

unless a richer scene/state model is demonstrably required.

---

# 14. Abstract cases expose the vacuity threshold

To make `ScenarioConstructionProcess` include arbitrary abstract hypothetical reasoning, M6 would need to define scenario as:

```text
any structured representation that can change.
```

But HF8 already owns MentalModel/WorldModel at that abstraction level.

Therefore:

```text
ScenarioConstruction
that covers every structured representation transformation
→ collapses into HF8/HF9 boundary.
```

This is the central C-round ownership result.

---

# 15. Regime R8 — child pretense

Pretense is a useful developmental case because young children can maintain local pretend conventions/rules.

2024 experiments show preschoolers apply conventional norms inside pretend play, demonstrating sensitivity to local pretend conventions rather than arbitrary behavior.

Earlier controlled work also found links between causally coherent pretense and counterfactual causal reasoning.

So pretense can involve:

```text
actual state
pretend stipulation
local pretend rule
allowed/forbidden pretend transition
```

---

# 16. Developmental pretense does not isolate a generic scenario engine

The same child performance can be reconstructed through:

```text
HF8 representational separation
+ HF9 causal/counterfactual structure where used
+ HF12 social convention/partner relation in shared pretense
+ stance/nonactual commitment
```

Pretend competence does not prove a common mechanism with:

```text
motor imagery
spatial route simulation
abstract hypothetical logic.
```

Therefore:

```text
SharedLocalStipulationGrammar
!= SharedScenarioConstructionMechanism.
```

---

# 17. Regime R9 — schizophrenia / hallucination continuum

This regime is decisive because it can separate:

```text
generation
from
source attribution / reality monitoring.
```

A 2025 empirical study across schizophrenia-spectrum groups and nonclinical hallucinatory-like-experience groups found increased source-monitoring errors and false perceptions in patient groups, while hallucination status did not map cleanly onto one unique deficit profile.

Other current schizophrenia studies relate hallucination severity to self-agency/source-monitoring disruptions.

```text
GenerationFailure

```

```text
ScenarioConstructionFailure
```

It strengthens the **orthogonal reality/source axis**.

# 19. Regime R10 — lucid dreaming

Lucid dreaming offers the inverse-style dissociation:

```text

+
```

2025 EEG/source-memory work found higher trait dream lucidity associated with better aspects of source-memory discrimination despite similarly vivid imagined/perceived content.

Thus:

```text
PhenomenalVividness
!= SourceDiscrimination
```


```text
construction
!= monitoring.
```

# 20. Regime R11 — Agent-seeded scenario

Agent-era pressure provides the cleanest provenance test.

Case A:

```text
Agent generates complete scenario S.
Human reads S.
```

Then:

```text

HumanScenarioGeneration = not established
```

Case B:


Then Human-side transformation is established, but its substantive operator depends on the domain:

```text
spatial update
social model update
motor simulation
causal inference

```

There is no reason to assign those heterogeneous operators to one new Human owner.

# 23. Ownership-extraction theorem for C

C adopts the following rule:

```text
If two domains share only:
  state + operator + update
but the state semantics and operator semantics are independently domain-owned,
then `state-update` alone is not sufficient evidence for a new semantic owner.
```

Otherwise almost every cognitive process could be merged into one generic simulator.

Thus:

```text
CommonComputationalShape
!= CommonSemanticOwner.
```

This rule is directly relevant beyond HD11.
