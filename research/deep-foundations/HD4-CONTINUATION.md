# 1. Why no HF23

`Social learning` is primarily a causal path into HF6 persistent learning through social/
artifact/institutional sources already represented by HF7/HF8/HF12/HF22.

`Culture / cultural inheritance` is broader, but it spans multiple existing owners rather
than forming one clean neighboring object:

```text
HF6  learner change
HF7  memory / external memory
HF8  knowledge / representation / provenance
HF10 source/search decisions
HF12 interaction / communication
HF13 conventions / norms / institutions / intergenerational persistence
HF19 technology / artifacts / production
HF22 persistent relationship transmission routes
HD4  transmission / reconstruction / selection / drift / recombination dynamics
```

A generic HF23 `Culture` box would duplicate these surfaces or become a catch-all.

Therefore:

```text
NextFoundationAdmissionCondition(Culture/HF23) = false
FoundationReopenCondition(HF0–HF22) = false
```
