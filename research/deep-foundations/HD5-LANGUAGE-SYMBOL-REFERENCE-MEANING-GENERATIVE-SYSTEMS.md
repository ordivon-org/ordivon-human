# HD5 — Language, Symbol, Reference, Meaning, Compositionality and Generative Symbolic Systems

## 0. Status and decision

HD4 localized a residual that generic cultural inheritance could not absorb:

```text
perceivable form / gesture / mark / word
→ stands for / indicates / expresses something
→ can be conventionally reused
→ combines with other forms under system constraints
→ yields structured content not stored as one whole token
→ is interpreted relative to context and interlocutors
→ can refer to absent / abstract / fictional / counterfactual states
→ can be externalized in speech, sign, writing or other notation
```

HF8 already owns generic representation and separates vehicle/content/referent/truth.
HF12 already owns communication events, signal/message/interpreted meaning, grounding,
reference choice and common-ground estimates.
HF13 owns convention and population persistence.
HD4 owns cultural transmission/reconstruction.

The missing object is not `meaning` in the abstract and not speech. It is a **persistent
socially stabilized generative symbolic system** that supplies reusable form–content
relations and combinatorial constructions across many communication and representation
events.

HD5 therefore finds:

```text
NextFoundationAdmissionCondition(GenerativeSymbolicSystem) = true
FoundationReopenCondition(HF0–HF22) = false
```

and admits thin HF23.

---

# 1. First firewall — signal is not symbol

HF12 already establishes:

```text
Signal != Message
```

HD5 adds:

```text
Signal != Symbol
```

A signal can causally influence a receiver without participating in a reusable symbolic
system.

Examples include:

```text
alarm sound
body movement
odor cue
network packet
physiological indicator
```

Symbolic status requires further structure.

---

# 2. `Sign` is a broad family, not one essence

Use:

```text
SignUse_D(vehicle, interpreter, content/target, context)
= a relation in which a perceivable/processable vehicle is treated as standing for,
  indicating, constraining or conveying something beyond itself in domain D
```

This definition is intentionally broader than `symbol`.

No one Peircean/Saussurean taxonomy is promoted to universal ontology.

---

# 3. Symbolic status is relation-relative

A mark is not intrinsically a symbol merely because it has a shape.

```text
SymbolStatus_D(vehicle)
```

depends on:

```text
learned mapping
community/system practice
interpretation rule
context
historical stabilization
```

Thus:

```text
PhysicalMark != SymbolByDefinition
```

---

# 4. Symbol is not referent

```text
Symbol != Referent
```

The written string `Singapore` is not the city.

The word `pain` is not the experience of pain.

The numeral `5` is not a five-item set.

---

# 5. Symbol is not concept

HF8 already establishes:

```text
LexicalLabel != Concept
```

HD5 generalizes:

```text
SymbolToken != Concept
SymbolType != Concept
```

A person can possess a concept without the conventional word and can produce a word without
possessing the full concept normally associated with it.

---

# 6. Word is qualifier-required

`Word` varies across orthographic, phonological, morphological and syntactic definitions.

Use:

```text
Word_D
```

when the relevant segmentation criterion matters.

Therefore:

```text
WrittenWord != SpokenWordUnitByDefinition
```

and spaces in writing do not define universal lexical ontology.

---

# 7. Word form is not lexical meaning

```text
WordForm != LexicalMeaning
```

The same form can be ambiguous/polysemous.
Different forms can overlap strongly in meaning.

---

# 8. `Meaning` is overloaded

At minimum separate:

```text
LexicalMeaning
ConstructionMeaning
CompositionalSemanticContent
SpeakerMeaning / CommunicativeIntention
UtteranceInterpretation
PragmaticEnrichment
Social/IndexicalMeaning
ProceduralMeaning
```

Therefore:

```text
Meaning_D != Meaning_E
```

Unqualified `the meaning` is not canonical.

---

# 9. Semantic content is not referent

A referring expression can contribute descriptive/perspectival content beyond identifying a
target.

Conversely different expressions can pick out the same target while differing in cognitive,
social or contextual contribution.

Thus:

```text
SemanticContent != Referent
```

---

# 10. Reference is not truth

```text
Reference != Truth
```

A sentence can successfully refer to a real person while making a false claim about that
person.

A fictional name can participate in meaningful discourse without ordinary real-world
reference.

---

# 11. Reference is use- and context-sensitive

Use:

```text
ReferenceRelation_D(expression-use, candidate target(s), context, interlocutors)
```

rather than a context-free word→object pointer.

Deixis makes this obvious:

```text
I
here
now
this
that
```

change reference with use context.

---

# 12. Reference is not a private lookup only

Collaborative referring experiments show speakers and listeners establish and reuse
partner-specific conceptual pacts.

Therefore:

```text
ReferenceSuccess
can depend on
InteractionHistory
```

and:

```text
ReferenceChoice != LexiconLookupOnly
```

HF12 remains current interaction/common-ground owner.

---

# 13. Same referential success does not imply identical representation

Two participants can coordinate on the same object while:

```text
using different conceptual detail
holding different beliefs
remembering different histories
```

Thus:

```text
SuccessfulReference != IdenticalInternalRepresentation
```

This preserves HF12 common-ground discipline.

---

# 14. Semantic content is not utterance interpretation

A conventional semantic contribution can be enriched, narrowed, disambiguated or otherwise
interpreted using context.

Therefore:

```text
SemanticContent != FullUtteranceInterpretation
```

---

# 15. Semantics is not pragmatics

A minimal working separation:

```text
Semantics_D
= system/construction-relative contribution to conventional content under declared theory D

Pragmatics_D
= context/interlocutor/use-dependent inference and action around what is conveyed in D
```

The exact boundary is theory-contested.

Thus:

```text
Semantics != Pragmatics
```

without pretending there is one universal cut.

---

# 16. Scalar implicature is a high-information firewall

For `some`, truth-conditional/semantic compatibility can include `all`, while ordinary adult
use often supports a pragmatic `not all` inference.

Developmental experiments show children can preserve the weaker semantic interpretation
where adults derive the stronger pragmatic inference.

Therefore:

```text
EncodedSemanticCompatibility
!= PragmaticallyInferredContent
```

---

# 17. Pragmatic inference is goal/task sensitive

Children's scalar-implicature rates increase under manipulations that make the communicative
goal/relevance structure more salient.

Thus:

```text
PragmaticCompetence
!= OneContextFreeScalar
```

---

# 18. Context enters language processing online

Visual-world experiments show listeners rapidly integrate visual scene information with
spoken language when resolving temporary syntactic/referential ambiguity.

Therefore:

```text
LanguageComprehension != TextOnlyDecode
```

and:

```text
ContextUse != PostHocOptionalDecoration
```

in those tasks.

---

# 19. Syntax is not semantics

Use:

```text
Syntax_D
= constraints/relations over linguistic forms, constituents, dependencies or constructions
  under declared analysis D
```

A syntactic distinction can occur without semantic difference and a semantic relation can
be expressed through different syntactic forms.

Thus:

```text
Syntax != Semantics
```

---

# 20. Grammar is not prescriptive correctness

Scientific `grammar` concerns the structure of a linguistic system/competence/use pattern,
not school rules about prestige varieties.

Therefore:

```text
Grammar != PrescriptiveRulebook
```

---

# 21. Grammar is not syntax only

Depending on theory, grammatical organization can include:

```text
morphology
syntax
constructional mappings
agreement
word order
prosodic structure
```

Thus:

```text
Grammar != SyntaxOnly
```

---

# 22. Compositionality

Use a family definition:

```text
Compositionality_D
= systematic dependence of a complex expression's interpretation on contributions of its
  parts plus their mode of combination under theory/domain D
```

This is weaker and safer than claiming all language is strictly compositional.

---

# 23. Concatenation is not composition

```text
Concatenation != Compositionality
```

Putting two signals next to one another does not prove the receiver computes structured
content from the parts and combination rule.

---

# 24. Composition is not syntax totality

```text
Compositionality != SyntaxTotality
```

A system can contain structural ordering constraints not obviously reducible to semantic
composition.

---

# 25. Compositionality is not productivity totality

```text
Compositionality != Productivity
```

A finite system may have compositional combinations without broad open-ended productive use.

Productivity also depends on inventories, constructions, recursion/reuse, pragmatic
flexibility and learning/use constraints.

---

# 26. Productivity is not literal infinity as an empirical observable

Use:

```text
Productivity_D
= capacity to generate/interpret novel well-formed or conventionally intelligible
  expressions beyond memorized wholes in domain D
```

Therefore:

```text
Productivity != ObservedInfinity
```

---

# 27. Memorized chunks and generative construction can coexist

Human language uses:

```text
idioms
collocations
formulaic sequences
productive constructions
```

Therefore:

```text
GenerativeLanguage != NoStoredChunks
StoredChunk != NoProductivity
```

---

# 28. Idioms attack universal strict compositionality

Some expressions have conventional interpretations not predictable by simple transparent
composition of isolated word meanings.

Thus:

```text
LanguageSystem != StrictlyCompositionalEverywhere
```

A viable grammar must permit mixtures of lexicalized and productive structure.

---

# 29. Language is not communication

HF12 already establishes:

```text
Communication != Language
```

HD5 adds the reverse:

```text
LanguageUse != CommunicationOnly
```

Language can be used for:

```text
private rehearsal
writing notes
planning
story construction
self-directed speech
```

without a current external addressee.

---

# 30. Communication can be nonlinguistic

```text
Communication != Language
```

through:

```text
gaze
gesture
posture
movement
icons
alarm calls
shared action
```

depending on context.

---

# 31. Language is not speech

```text
Language != Speech
```

Natural sign languages are decisive.

Speech is one sensorimotor modality/channel for language.

---

# 32. Sign language is not pantomime

Natural sign languages have conventional lexicons and linguistic structure across multiple
levels.

Therefore:

```text
SignLanguage != GesturePantomimeByDefinition
```

although gesture and sign can interact historically and during use.

---

# 33. Language computation can be modality-general while input pathways differ

Lesion and neuroimaging evidence shows core left-hemisphere language organization in signed
as well as spoken language, despite visuo-manual versus auditory-vocal input.

Thus:

```text
LanguageSystem != AuditorySystem
```

while modality-specific cortical systems still contribute.

---

# 34. 2026 naturalistic sign-language narrative pressure

Native signers watching Polish Sign Language narratives show a hierarchy in which
frontotemporal language regions track word/sentence-level structure while plot-level
integration recruits broader networks, with additional modality-specific visual/spatial
contributions.

Therefore:

```text
ModalityInvariantLanguageStructure
can coexist with
ModalitySpecificProcessing
```

---

# 35. Cross-language neural regularity does not erase linguistic diversity

A 45-language / 12-family fMRI study found robust common topography, left lateralization and
functional integration/selectivity of the language network.

Therefore:

```text
CrossLinguisticNeuralRegularity != IdenticalGrammar/Semantics
```

and:

```text
LinguisticDiversity != NoSharedBiologicalInfrastructure
```

---

# 36. Language acquisition is not memorizing a lexicon

A learner must acquire, to varying degrees:

```text
form categories
segmentation
lexical mappings
constructional regularities
semantic distinctions
reference use
pragmatic expectations
speaker/community variation
```

No one mechanism is assumed to solve all of these.

---

# 37. Statistical learning is one acquisition mechanism

Eight-month-old infants can use transitional probabilities to segment artificial continuous
speech after brief exposure.

Thus:

```text
DistributionalStatistics
can support
FormSegmentation
```

---

# 38. Statistical learning is not language-specific by definition

Infants/adults also learn statistical structure in nonlinguistic tone or visual sequences.

Therefore:

```text
StatisticalLearning != LanguageFacultyByDefinition
```

---

# 39. Statistical segmentation is not word meaning

```text
SegmentedForm != LexicalMeaning
```

Identifying a recurring syllable sequence does not determine what it refers to or means.

---

# 40. Statistical learning is not sufficient for all natural segmentation

Infant experiments show performance can fail when artificial word-length/structure becomes
more complex despite equivalent local transitional-probability cues.

Thus:

```text
StatisticalCueAvailable != GuaranteedSegmentation
```

---

# 41. Reference learning uses social/context evidence

Infant word-learning experiments show learners can consult the speaker's focus/attention
rather than blindly bind a label to the object currently salient to themselves.

Therefore:

```text
WordLearning != TemporalCoOccurrenceOnly
```

---

# 42. Joint reference is not identical to word learning

Joint attention/reference can constrain candidate mappings, but:

```text
JointReference != LexicalAcquisition
```

The learner must still retain/generalize a form–content mapping.

---

# 43. Social gating and statistical learning can interact

2026 infant work across UK/Singapore samples found adult-speaker→infant neural coupling
modulated by eye contact and predictive of selective learning of an artificial language.

Thus:

```text
StatisticalLearning
and
SocialAttention
```

need not be rival explanations.

---

# 44. Language structure can emerge without conventional linguistic input

Homesigning deaf children without accessible spoken/sign language input spontaneously create
gesture systems with language-like structural properties.

Therefore:

```text
ConventionalLanguageInput != NecessaryForEveryLanguageLikeStructure
```

under those observed properties.

---

# 45. Homesign is not a complete community language by definition

Homesign systems can show resilient structure but lack the full population conventionality,
shared lexicon, transmission ecology and breadth of established natural languages.

Thus:

```text
Homesign != EstablishedCommunityLanguage
```

---

# 46. Individual creation and community language emergence differ

```text
IndividualHomesign
!= CommunityLanguageEvolution
```

The Nicaraguan case provides rare direct pressure on this distinction.

---

# 47. Emerging Nicaraguan Sign Language is a decisive generativity case

Successive cohorts of deaf Nicaraguan signers transformed an emerging system: children
segmented complex events into elements and recombined them into increasingly language-like
structured expressions not directly copied from surrounding co-speech gesture.

This supports:

```text
Learners + CommunityTransmission
can create/stabilize
new linguistic structure
```

---

# 48. Language structure is not fully pre-specified by one individual's input

The Nicaraguan case shows the system changes across cohorts.

Therefore:

```text
LanguageSystem_t
→ acquired/reconstructed by learners
→ LanguageSystem_{t+1}
```

Language is both an acquisition target and a culturally evolving object.

---

# 49. Emergence does not prove one innate universal grammar theory

Homesign/NSL evidence constrains theories of learner bias and cultural transmission.

It does not by itself uniquely identify:

```text
innate grammar
usage-based construction
iterated-learning bias
communicative optimization
```

as the sole mechanism.

---

# 50. Language is not thought

A central HD5 firewall:

```text
Language != Thought
```

Severe aphasia can coexist with retained forms of:

```text
approximate quantity reasoning
algebraic structure manipulation
causal reasoning
Theory of Mind
```

under specific tasks/cases.

---

# 51. Grammar is not necessary for all propositional reasoning

Agrammatic aphasia cases preserve false-belief/causal reasoning despite profound grammatical
impairment.

Therefore:

```text
NaturalLanguageGrammar
!= NecessarySubstrateForAllReasoning
```

---

# 52. Language impairment does not erase mathematical structure

Patients with severe aphasia can retain approximate calculation or even algebraic
transformation under specific lesion profiles.

Thus:

```text
LanguageCapacity
!= MathematicalCognitionTotality
```

---

# 53. Language nevertheless can influence thought

Rejecting identity/necessity does not imply causal irrelevance.

Language can alter:

```text
attention to distinctions
memory strategies
categorization habits
spatial/temporal framing
problem decomposition
external rehearsal
```

under task/context.

Therefore:

```text
Language != Thought
but
Language can causally modify Thought_D
```

---

# 54. Language influence is domain- and study-specific

Cross-linguistic spatial studies show both cases where language/cognition covary and cases
where linguistic differences do not produce corresponding nonlinguistic-memory differences.

Thus:

```text
LanguageDifference != ThoughtDifferenceByDefinition
```

and:

```text
LanguageEffect_D != LanguageEffect_E
```

---

# 55. Language can scaffold a representation without constituting it

Homesigners lacking conventional spatial language can show reduced performance on some
nonlinguistic spatial tasks; acquiring/using spatial relational language can facilitate such
cognition.

Therefore:

```text
LinguisticScaffolding != RepresentationalIdentity
```

---

# 56. Internal speech is not thought totality

Even if internal/verbal rehearsal supports many Human tasks:

```text
InnerSpeech != ThoughtTotality
```

Nonverbal imagery, perception, motor planning, affect, mathematical/spatial representations
and other processes remain possible.

HD5 does not establish one theory of inner speech.

---

# 57. Animal communication attacks Human-exclusive definitions of composition

Japanese great tits combine meaningful ABC and D call units; receivers produce compound
responses to ABC–D but not artificially reversed D–ABC sequences.

Thus under the experiment's criterion:

```text
CompositionalSyntax != HumanUniqueByDefinition
```

---

# 58. Animal compositionality is not Human language equivalence

The great-tit system does not establish Human-like:

```text
lexicon scale
cross-domain productivity
open-ended topic range
narrative
displacement breadth
metalinguistic reflection
```

Therefore:

```text
OneCompositionalMechanism != FullLanguageEquivalence
```

---

# 59. Comparative language claims must be property-specific

Ask:

```text
reference?
intentional signaling?
meaningful units?
ordering rule?
composition?
productivity?
learning?
conventionality?
displacement?
```

rather than:

```text
Does species X have language? yes/no
```

---

# 60. Human language generativity is a bundle, not one magic property

Potential contributors include:

```text
large reusable inventories
hierarchical/relational combination
productive constructions
context/pragmatic inference
reference to absent/abstract targets
rapid social transmission
writing/external symbols
cross-domain recombination
```

No one is promoted as the single essence.

---

# 61. Conventionality is not arbitrariness totality

Many linguistic forms are conventional, but languages can also use iconic or gradient
structure.

Therefore:

```text
SymbolicConvention != CompletePhysicalArbitrariness
```

Sign languages make this especially visible.

---

# 62. Iconicity is not non-language

A form can resemble aspects of its referent yet participate in a conventional linguistic
system.

Thus:

```text
IconicForm != NonLinguisticByDefinition
```

---

# 63. Conventionality is not truth

```text
StableWordMeaning != TrueBelief
ConventionalExpression != TrueStatement
```

HF8/HF14 truth/normativity firewalls remain intact.

---

# 64. Shared form is not shared meaning

Different speakers can use the same string while differing in:

```text
conceptual detail
social meaning
technical definition
contextual reference
associated experience
```

Thus:

```text
SharedWord != SharedMeaningByDefinition
```

---

# 65. Shared dictionary meaning is not identical use

Language users adapt expression choice to:

```text
partner
register
role
institution
culture
purpose
```

```text
LexiconEntry != UsePolicy
```

---

# 66. Translation is not semantic identity

Two expressions in different languages can be good translations for one context while
differing in:

```text
scope
connotation
aspect
politeness
category boundary
grammatical obligations
```

Thus:

```text
Translation_D(A,B) != SemanticIdentity(A,B)
```

# 67. Cross-language equivalence is task-relative

Translation can optimize for:

```text

pragmatic effect
style

poetic form
```

Different objectives can conflict.

# 68. Language varieties are not errors by definition

Descriptive grammar must distinguish:

```text
community variety
register
dialect
idiolect
prestige standard
```

from prescriptive judgments.

```text
NonstandardVariety != UngrammaticalByDefinition
```

# 69. Social-indexical meaning is real but not semantic totality

A form can signal:

```text
identity
stance
status
politeness
community membership
```

in addition to descriptive content.

Thus:

```text
SocialMeaning != ReferentialMeaning
```

HF13 social structure composes here.

---

# 70. Pragmatic success can occur with semantic mismatch

Interlocutors can coordinate despite incomplete or non-identical internal interpretations.

Therefore:

```text
CommunicationSuccess != SemanticIdentity
```

HF12 repair/grounding remains relevant.

---

# 71. Misunderstanding is not language-system failure only

Failure can arise from:

```text
lexical ambiguity
syntactic ambiguity
reference mismatch
wrong common-ground estimate
pragmatic inference
hearing/vision/noise
concept mismatch
social convention mismatch
```

Thus:

```text
LanguageFailure != OneErrorClass
```

---

# 72. Repair can update local meaning conventions

Partner-specific referential pacts can form, simplify and be abandoned/rebuilt.

Thus:

```text
UseHistory_t
→ LocalConvention_{t+1}
```

Language use can locally alter the symbolic system used by a dyad/group.

---

# 73. Local convention is not whole-language change

```text
DyadicReferentialPact != CommunityLexicalChange
```

Community diffusion and persistence require HD4/HF13 population dynamics.

---

# 74. Language is multi-timescale

At least:

```text
milliseconds: perception / lexical access / parsing
seconds-minutes: utterance/discourse/pragmatic grounding
days-years: acquisition / individual adaptation
generations: cultural language change
centuries: historical restructuring / writing standardization
```

Therefore:

```text
LanguageState_t != OneTimescaleState
```

---

# 75. Language system and language use event differ

Use:

```text
LanguageSystem_L
```

for persistent community/individually represented regularities.

Use:

```text
LanguageUseEvent_E
```

for a particular production/comprehension/interaction episode.

Thus:

```text
LanguageSystem != UtteranceEvent
```

---

# 76. Minimum language-system profile

```text
LanguageSystemProfile_D = {
  users/community/history,
  modalities/channels,
  form inventories,
  lexical/constructional mappings,
  morphosyntactic/ordering/dependency constraints,
  semantic interpretation resources,
  pragmatic conventions,
  discourse/reference resources,
  productive operators,
  variation/registers,
  acquisition/transmission pathways,
  external inscription/notation links,
  uncertainty
}
```

This is question-relative, not a mandatory schema for every language.

---

# 77. Minimum language-use event

```text
Producer state / goal
        ↓
Intended communicative or representational content
        ↓
Expression planning under LanguageSystem_L
        ↓
Signal / sign token in modality M
        ↓
Perception / segmentation
        ↓
Lexical + constructional interpretation
        ↓
Context / common-ground / pragmatic inference
        ↓
InterpretedContent / Reference / Action
        ↓
Grounding / repair / learning / convention update
```

No arrow proves identical representation between participants.

---

# 78. Writing is not language

```text
Writing != Language
```

Writing is an external inscription/notation technology that maps visual/tactile marks to
linguistic or other symbolic structure.

Many languages exist without writing; multiple writing systems can represent one language.

---

# 79. Writing is not speech transcription only

Writing can encode:

```text
words
morphemes
syllables
phonological segments
numbers
logic
music
mathematics
program code
```

depending on system.

Thus:

```text
WritingSystem != SpeechRecordingByDefinition
```

---

# 80. Literacy changes cognition/brain organization

Adult illiterate, adult-literacy-acquired and childhood-literate comparisons show reading
acquisition changes visual and language-related cortical responses; longitudinal/intervention
work also shows substantial plasticity.

Therefore:

```text
Writing/Literacy
can alter
Perceptual + Language Processing Infrastructure
```

---

# 81. Literacy is not natural-language acquisition

A person can be a fluent language user without literacy.

Thus:

```text
Literacy != LanguageCompetence
```

and:

```text
Illiterate != Languageless
```

---

# 82. External symbols are cognitive resources

Notes, diagrams, algebra, code and written language can externalize state that would
otherwise require memory/reconstruction.

Thus:

```text
InternalWorkingMemory
!= TotalAvailableSymbolicWorkspace
```

HF7 external memory and HF11 tool use compose here.

---

# 83. External symbolic system can change the problem itself

Algebraic notation, diagrams and writing do not merely preserve information; they can make
operations visible/reusable/rearrangeable.

Therefore:

```text
ExternalSymbol != PassiveMemoryOnly
```

---

# 84. Symbolic competence is domain-specific

Ability to use natural language does not imply competence with:

```text
algebra
formal logic
music notation
programming language
chemical notation
```

Thus:

```text
LanguageCompetence != GeneralSymbolicCompetenceTotality
```

---

# 85. Formal languages are not natural languages

Programming/math/formal logic systems can have strict syntax/semantics without ordinary
Human pragmatic/social language properties.

Therefore:

```text
FormalLanguage != NaturalLanguage
```

while both can instantiate generative symbolic-system principles.

---

# 86. Symbolic systems are the broader foundation candidate

The cross-context invariant is not `spoken natural language`.

It is:

```text
persistent reusable sign types
+ stabilized mappings/constructions
+ interpretation rules/resources
+ combinatorial/generative operators
+ user/community competence
+ context/use interface
```

This survives speech, sign, writing and formal notation variation.

---

# 87. Meaning is not groundedness

A system can support internally coherent relations among signs while its connection to the
world remains weak, indirect or source-dependent.

Thus:

```text
SemanticCoherence != Grounding
```

---

# 88. `Grounding` is overloaded

At minimum distinguish:

```text
ReferentialGrounding
PerceptualGrounding
SensorimotorGrounding
InteractiveGrounding
CausalWorldGrounding
SocialConventionalGrounding
EmbodiedRegulatoryGrounding
ExperientialGrounding
```

Therefore:

```text
Grounding_D != Grounding_E
```

---

# 89. Referential success is not sensorimotor grounding

An agent can correctly identify a referent through text/database lookup without having
sensorimotor experience of it.

# 165. Final HD5 compression

Human symbolic capacity is not:

```text
thought → words → listener decodes words
```

It is closer to:

```text
Representational / World / Social State
        ↕
Persistent Generative Symbolic System
  [forms + mappings + constructions + semantics + pragmatic conventions]
        ↕
Production / Perception / Reference / Contextual Inference
        ↕
Communication / Private Cognition / External Inscription / Action
        ↕
Repair / Learning / Cultural Transmission / System Change
        ↺
```

The foundation-level discovery is the middle object:

```text
GenericRepresentation
!= GenerativeSymbolicSystem
!= OneCommunicationEvent
```

That structure is what HF23 extracts.
