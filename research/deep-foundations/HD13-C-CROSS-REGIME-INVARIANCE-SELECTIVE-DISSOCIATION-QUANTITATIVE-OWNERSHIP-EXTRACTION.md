# 2. Local numerosity specificity survives domain-general reduction

2024 developmental-dyscalculia psychophysics compared children with severe numerical impairment to controls matched on age, IQ and visuospatial memory.

The lower dot-comparison accuracy was linked to:

```text
weaker numerosity encoding
```

rather than:

```text
stronger interference from nonnumerical visual properties.
```

Spontaneous categorization also showed weaker number-based categorization without greater continuous-feature dominance.

Therefore:

```text
VisualNumerosityDeficit
!= VisualFeatureBiasOnly
!= LowIQByDefinition
!= VisuospatialMemoryOnly
```

A real local numerosity mechanism must be retained.

---

```text
SensoryEvidence_D
PerceptualOrganization_D
PerceptualContent_D

```

A visual mechanism that extracts/organizes numerosity from individuated items is therefore a specialized perceptual projection.

```text
NumerositySpecificPerceptualMechanism
!= MissingPeerOwnerByDefinition
```

Local specificity creates a deep scientific projection, not automatic HF24 deletion harm.

# 4. Cross-modal approximate judgment is not invariant in precision or bias

Controlled visual, auditory and cross-modal approximate-number comparison found:

```text
auditory discrimination precision
!= visual discrimination precision
```

with cross-modal performance intermediate and systematic modality-dependent biases in subjective equality.

Therefore:

```text
ApproximateNumerosityProcess_Visual
!= ApproximateNumerosityProcess_Auditory
```

at least at the complete processing-chain level.

---

# 5. 2025 neural evidence sharply limits amodal-code claims

A 2025 JNeurosci multivariate fMRI study compared numerosity across:

```text
auditory
visual
sequential
simultaneous
symbolic
nonsymbolic
```

Numerical information was represented across a dorsal network, but visual↔auditory representations aligned in intraparietal/frontal regions only when they shared a sequential presentation format.

The representational geometry retained major effects of:

```text
sensory modality
presentation format
spatial-vs-temporal structure
```

Therefore:

```text
CrossModalNumerosityRepresentation
!= OneFormatFreeAmodalCode
```

and:

```text
SharedNumericalContent
can coexist with format-specific implementations.
```

---

# 6. The strongest positive commonality is representational alignment, not one process

C accepts:

```text
some numerical information can align across modalities/formats.
```

But the 2025 format condition means the commonality is conditional rather than invariant.

This matches HD12's general lesson:

```text
PositiveCrossTaskCommonality
can indicate SharedRepresentation
without indicating SharedSemanticOwner.
```

# 7. Tactile numerosity breaks a simple visual-to-amodal generalization

Simultaneous vibrotactile stimuli distributed over the body surface did not show the classic visual RT/error discontinuity associated with a four-item subitizing range.

Participants nevertheless used number-of-tactors information rather than merely global tactile intensity.

Therefore:

```text
TactileNumerosityJudgment
= real numerosity processing
```

while:

```text
VisualSubitizingSignature
!= TactileSubitizingSignatureByDefinition.
```

This is strong mechanism-regime dependence.

---

# 8. Congenital blindness does not restore one universal tactile mechanism

In a different tactile regime—rapid enumeration of stimulated fingers—congenitally blind adults did show a small-number subitizing-like range.

Thus:

```text
TactileNumerosityMechanism
depends on body layout / individuation / task regime.
```

The contrast with distributed body-surface tactors shows:

```text
Modality label alone
is insufficient to identify mechanism.
```

---

# 9. 2026 tactile fMRI narrows subitizing to object individuation

A 2026 NeuroImage study localized task-independent tactile object-individuation structure to bilateral inferior parietal lobule.

Within the OI range, neural patterns decoded both numerosity and working-memory load across tasks.

Crucially, quantity-specific decoding was restricted to the OI range.

This supports:

```text
TactileSmallSetNumerosity
≈ object-individuation-limited mechanism family
```

rather than a mechanism spanning arbitrary numerosities.

Canonical ownership:

```text
SmallSetSubitizing / OTS-like mechanism
→ HF20 object individuation / perceptual organization
```

not HF24.

---

# 10. Small-set and large-set numerosity remain distinct local mechanisms

Behavioral work directly rejects one Weberian estimation system for both 1–4 and large numerosities: small numerosities show much higher precision than a single-estimation account predicts.

Lesion evidence already separates subitizing and serial counting.

Therefore:

```text
SmallSetApprehension
!= LargeSetApproximateEstimation
```

and the label `numerosity` still spans multiple local mechanisms.

---

# 11. Cross-modal adaptation is real

Adaptation to visual or auditory numerical sequences can alter perceived numerosity across modalities and across sequential/simultaneous formats.

Finger-tapping adaptation can bias subsequent perceived visual numerosity.

Motor adaptation can alter auditory numerosity judgments in both sighted and congenitally blind participants.

Thus:

```text
ActionNumerosity
↔ PerceptualNumerosity
```

and:

```text
AuditoryNumerosity
↔ VisualNumerosity
```

are real interaction surfaces.

---

# 12. But adaptation is not owner identity

HF20 explicitly separates:

```text
Integration
!= Recalibration
!= MotorAdaptation
```

and owns multisensory integration/recalibration.

HF11 owns action/motor adaptation/control.

Therefore an adaptation aftereffect crossing those surfaces can be represented as:

```text
HF11 action history
→ shared/learned quantitative mapping or representational state
→ HF20 perceptual estimate shift
```

without a new semantic owner.

Canonical firewall:

```text
CrossModalNumerosityAdaptation
!= OneNumerosityOwnerProof
```

# 13. Congenital blindness supports representation flexibility, not a new owner

Congenitally blind adults/children can develop strong numerical abilities and frontoparietal numerical organization without visual experience.

This rejects:

```text
VisualExperience = NumericalFoundation
```

But HF20 already states:

```text
MissingSense != NormalSystemMinusInput
```

and permits developmental cross-modal routing/recalibration.

HF8 permits the same representational content through different vehicles.

Thus blindness evidence supports:

```text
modality-flexible quantitative representation
```

more directly than it supports a separate numerical owner.

---

# 14. Symbolic and nonsymbolic representations can be neurally distinct

Human single-neuron recordings found distinct populations tuned to nonsymbolic versus symbolic number in the tested calculation context, rather than one population coding both formats identically.

Therefore:

```text
SymbolicNumberCode
!= NonsymbolicNumerosityCode
```

at least at that representational scale.

This further weakens one-code/HF24 interpretations.

---

# 15. Approximate quantity and exact verbal number can dissociate clinically

Two classic acalculic cases produced complementary patterns:

```text

  approximation/subitizing/quantity comparison impaired
  rote verbal arithmetic relatively less impaired

semantic/verbal-deficit patient:
  exact/verbal arithmetic impaired
  approximation/nonsymbolic numerosity preserved
```

Therefore:

```text
ApproximateQuantityProcessing
!= ExactVerbalNumberProcessing
```

This supports layered ownership, not one number faculty.

# 16. Severe aphasia can spare approximate calculation


# 17. Estimation output can fail while number semantics remain intact

A frontal-lesion patient produced grossly abnormal verbal numerosity estimates while:

```text

and

```

Therefore:

```text
NumerosityEstimationScore
```

