# HD10-D — Cognitive Ability and Intelligence Rival Models

## 0. Decision

HD10-D does not answer `what is intelligence?` with one noun.

The rival-model comparison shows that ordinary `intelligence` language conflates at least:

```text
1. PositiveManifold
   = population covariance regularity among cognitive test performances

2. GeneralFactorEstimate
   = model/battery/population-relative statistical summary of shared covariance

3. Broad/NarrowAbilityCoordinates
   = hierarchical descriptive organization of test/task performance domains

4. CognitiveProcessConfiguration
   = working memory, attention/control, processing speed, representation,
     reasoning, retrieval, learning and other mechanisms

5. AcquiredKnowledge/Expertise
   = history-dependent domain organization and stored/retrievable structure

6. Learning/Modifiability
   = how performance changes under feedback, instruction, practice and transfer

7. IndependentCognitiveCapability
   = what H can reliably achieve under a declared unaided support boundary

8. Situated/JointCognitiveCapability
   = what H can achieve with tools, external memory, collaborators or Agents
```

They are related but not identical.

Therefore:

```text
Intelligence
!= one currently justified Human primitive
```

At D close:

```text
HD10-D = completed
HF24 = UNKNOWN / not admitted
FoundationReopenCondition(HF0–HF23) = false
HD10-E = required next for cross-domain synthesis/falsification
```

# 3. First object — PositiveManifold

Define:

```text
PositiveManifold(Battery B, Population P, Conditions C)
= predominantly positive covariance/correlation among diverse cognitive task scores
  across persons in P under B/C.
```

It is a property of a measurement population/test system.

Large modern batteries continue to recover it. In Human Connectome Project data, diverse cognitive tests correlate positively and support general plus group-factor descriptions.

Thus:

```text
PositiveManifold = empirical regularity
```

is strongly retained.

But:

```text
PositiveManifold != ExplanationOfPositiveManifold
```

# 4. Rival I1 — psychometric g / general-factor model

## 4.1 Strong form

Given a positive covariance matrix, a general factor can summarize variance common across cognitive tests.

A working object is:

```text
GeneralFactorEstimate_g(Battery B, Population P, Model M, Scoring S)
```

This is deliberately parameterized.

## 4.2 What survives strongly

A general factor often provides powerful statistical compression and prediction.

In HCP data (`N≈1181` in one widely used analysis), a bifactor solution included one general factor plus crystallized, speed, visuospatial and memory group factors; the general factor accounted for a large proportion of covariance.

Thus:

```text
PsychometricG
= high-value shared general-ability coordinate / covariance summary
```

is retained.

## 4.3 What factor analysis alone cannot prove

A reflective factor diagram can be statistically represented as:

```text
g → Test1
g → Test2
...
```

But covariance fit does not establish that one causal substance literally drives every test.

Therefore:

```text
GeneralFactorEstimate
!= DemonstratedGeneralCausalCapacity
```

## 4.4 Factor score is battery/model dependent

`g` estimated from one battery is not a context-free meter reading from inside the brain.

It depends on:

```text
task battery
score construction
population/range
factor model
age/context
missingness and estimation choices
```

Hence:

```text
g_{B1,P1,M1}
!= g_{B2,P2,M2} by identity
```

although estimates may correlate strongly.

## 4.5 Biological correlation does not close ontology

Brain-network/neurostructural variables can predict or correlate with psychometric g.

But:

```text
NeuralCorrelate(g)
!= BiologicalIdentityOfG
```

Recent network-neuroscience evidence favors distributed/global network properties rather than a single privileged anatomical locus.

## 4.6 Disposition

```text
Retain strongly:
  positive-manifold summary
  broad general-ability coordinate
  prediction/statistical compression

Reject:
  g-factor extraction as proof of one causal substance
  g score as complete cognitive profile
  g as moral/authority rank
```

# 5. Rival I2 — hierarchical / Three-Stratum / CHC-like models

## 5.1 Strong form

Hierarchical models organize cognitive-test covariance across levels such as:

```text
narrow task/ability variables
      ↓
broad ability factors
      ↓
(optional/general) higher-order g
```

Common broad families include some version of:

```text
fluid reasoning
acquired/crystallized knowledge
working/short-term memory
processing speed
visual-spatial processing
auditory processing
long-term retrieval/learning
quantitative/reading-related knowledge
```

depending on the exact CHC-family specification.

## 5.2 Important historical/theoretical correction

There is not one timeless singular `CHC theory`.

Cattell/Horn traditions and Carroll's Three-Stratum work are related but not identical; Horn did not require a higher-order g in the same way Carroll did. Later integrations created a family of CHC-like taxonomies.

Therefore:

```text
CHC = family of related hierarchical ability taxonomies/models
```

is safer than one canonical ontology.

## 5.3 What survives

CHC-like broad/narrow organization is useful for:

```text
describing cognitive profile heterogeneity
sampling multiple task families
preventing FullScaleScore = PersonTotality
neuropsychological/test interpretation
tracking development/aging by domain
```

It preserves important dissociations such as strong acquired knowledge with weaker novel reasoning, or preserved verbal knowledge with localized cognitive loss.

## 5.4 Main limitation

A factor called `WorkingMemory`, `FluidReasoning` or `ProcessingSpeed` is a statistical/task-family construct unless separately linked to process mechanisms.

Thus:

```text
BroadAbilityFactor_Gf
!= FluidReasoningMechanismTotality

BroadAbilityFactor_Gwm/Gsm
!= OneWorkingMemoryMechanism
```

## 5.5 Task-family coordinate, not process table

The best Ordivon interpretation is:

```text
AbilityCoordinate_K,D
= relative standing/profile in a declared family of cognitive task demands
  under a declared measurement model.
```

## 5.6 Disposition

```text
Retain strongly as broad/narrow shared ability coordinate family.
Reject factor labels as mechanism identities.
Reject one fixed CHC hierarchy as complete Human cognitive ontology.
```

# 6. Rival I3 — fluid / crystallized ability

## 6.1 Core distinction

The Gf/Gc tradition distinguishes approximately:

```text
Gf-like performance
= solving/inducing relations in relatively novel problems with reduced dependence
  on specific previously acquired content

Gc-like performance
= deployment of acquired language, concepts, factual/procedural knowledge
  and culturally developed cognitive organization
```

These are useful but not process-pure.

## 6.2 What survives

The distinction captures a real developmental/clinical pattern:

```text
novel problem-solving surfaces
can differ from
acquired knowledge surfaces.
```

It also protects:

```text
Knowledge != CurrentNovelReasoningPerformance
```

and:

```text
CurrentNovelReasoning != AllAdultIntelligence
```

## 6.3 Historical correction

The early fluid/crystallized distinction emerged from Hebb/Cattell work on direct intellectual power versus acquired, persistent organization; its later psychometric form should not be read as two literal brain fluids.

## 6.4 Gf is never culture/history free in the strong sense

Even abstract reasoning tests require:

```text
instructions
visual/perceptual conventions
test-taking behavior
prior experience with symbolic tasks
working-memory/control processes
strategy discovery
```

Therefore:

```text
GfTest != PureCultureFreeGeneralCapacity
```

## 6.5 Gc is not merely stored facts

Gc-like ability can include organized language/concept knowledge and efficient use of learned structures.

HF8 already separates:

```text
Memory != Knowledge
Recall != Understanding
KnowledgeAvailable != KnowledgeUsed
```

so:

```text
Gc != MemoryVolume
```

## 6.6 Investment/development

A useful developmental hypothesis is:

```text
reasoning/learning resources
× education/opportunity
× motivation/personality
× culture
× practice
→ acquired knowledge/skill structure
```

not:

```text
Gc = Gf accumulated mechanically
```

## 6.7 Disposition

```text
Retain Gf/Gc as useful broad developmental/task-demand distinction.
Reject either as process-pure or context-free essence.
```

# 7. Rival I4 — working-memory / executive-control accounts

## 7.1 Strong form

A major cognitive tradition argues that individual differences in working-memory capacity / executive attention explain substantial variation in complex reasoning and fluid intelligence.

Latent-variable studies show strong WMC–Gf relations.

## 7.2 What survives

Working memory and executive control are genuine constraints on many demanding tasks involving:

```text
maintenance under distraction
updating
interference control
goal maintenance
relational integration
multi-step reasoning
```

Thus:

```text
WMC/ExecutiveControl
= important contributor to many high-Gf tasks
```

is retained.

## 7.3 Identity fails

HF9 already established:

```text
Reasoning != WorkingMemoryCapacity
```

The same applies at the broader level:

```text
Intelligence != WorkingMemoryCapacity
Gf != WMC by identity
```

because reasoning also depends on:

```text
representation
knowledge
strategy
processing speed
attention
motivation/state
learning history
task format
```

## 7.4 Empirical pressure

Process-overlap tests have found that broad common executive-function variance may relate to Gf, but specific executive process hypotheses do not consistently explain the overlap.

Thus:

```text
StrongCorrelation(WMC,Gf)
!= UniqueMechanismIdentity
```

## 7.5 Disposition

```text
Retain working-memory/executive control as major mechanism/resource family.
Reject as intelligence totality or unique g cause.
```

# 8. Rival I5 — Thomson sampling / bonds model

## 8.1 Strong form

Thomson's sampling idea explains positive test correlations without one general causal factor.

Each test samples many underlying cognitive elements/processes; different tests overlap in what they sample.

Conceptually:

```text
Task A samples {p1,p2,p3,p7,...}
Task B samples {p2,p3,p5,p7,...}

Overlap
→ positive covariance
```

## 8.2 Modern reconstruction

Modern stochastic bonds models have been fitted to mental-test data and can produce covariance structures statistically competitive with Spearman-style general-factor models while implying radically different underlying architectures.

This is a decisive identifiability warning:

```text
SameCovarianceStructure
can be compatible with
SingleGeneralCause
or
ManyOverlappingElements
```

## 8.3 What survives

Sampling theory strongly supports:

```text
TaskDemandComposition matters
TestBatteryComposition matters
FactorStructure != UniqueMechanism
```

## 8.4 Main limitation

The underlying sampled elements/bonds are not automatically identified with known cognitive processes.

A sampling model can fit covariance while leaving mechanism underspecified.

Thus:

```text
SamplingExplanation != IdentifiedProcessArchitecture
```

## 8.5 Disposition

```text
Retain as serious alternative measurement/process explanation of positive manifold.
Reject unspecified bonds as final mechanism ontology.
```

# 9. Rival I6 — Process Overlap Theory (POT)

## 9.1 Strong form

POT modernizes sampling logic by proposing that cognitive tasks draw on:

```text
domain-general executive processes
+
domain-specific processes
```

with domain-general processes being sampled more broadly across tests.

In this view, psychometric g emerges as an index of overlapping process requirements rather than a single reflective causal trait.

## 9.2 Major strength

POT directly links:

```text
psychometric covariance
↔ task process demands
↔ executive-control research
```

better than purely descriptive factor models.

## 9.3 Main falsifier

Specific implementations must identify which processes actually account for covariance.

Empirical tests have not uniformly supported proposed specific executive-process explanations of Gf/WMC overlap.

Therefore:

```text
POTArchitecture
may survive
while
SpecificPOTProcessAssignment
fails.
```

This is important.

## 9.4 g under POT

POT suggests:

```text
gScore = statistical index of process overlap
```

not one process.

But HD10-D does not force every common variance source to be executive.

## 9.5 Disposition

```text
Retain strongly as process-sampling integration architecture.
Reject any specific executive-process assignment not independently supported.
```

# 10. Rival I7 — mutualism / developmental network theory

## 10.1 Strong form

Mutualism explains the positive manifold through positive reciprocal interactions among initially distinguishable cognitive processes during development.

Conceptually:

```text
Ability_A ↑
→ improves learning/use of Ability_B
→ improves Ability_C
→ feeds back into Ability_A
```

Over time:

```text
reciprocal developmental coupling
→ positive covariance across abilities
```

without requiring one initial common cause.

## 10.2 Major strength

Mutualism naturally explains why:

```text
positive manifold can strengthen/emerge developmentally;
abilities can be causally interconnected;
early weak prediction can become stronger later;
environmental opportunity can enter multiplier loops.
```

This aligns strongly with HF6 history-dependent update.

## 10.3 Environment can participate

A network can include education/opportunity/practice nodes:

```text
CognitiveProcess
↔ Environment/Opportunity
↔ Learning
↔ OtherCognitiveProcess
```

Thus general ability differences can partly emerge from cumulative developmental feedback rather than one immutable starting quantity.

## 10.4 Main limitation

Mutualism is a model family, not proof that every positive covariance is produced by reciprocal causation.

Sampling, shared biological resources, common executive processes and mutualism can coexist.

## 10.5 Disposition

```text
Retain strongly as developmental causal architecture.
Reject mutualism as exclusive explanation of all common covariance.
```

# 11. Rival I8 — unified network / hybrid models

Later network models explicitly combine:

```text
mutualism
sampling
central/shared processes
environmental multipliers
```

This is important because the rival tournament need not end with exactly one cause.

A realistic system can contain:

```text
shared bottlenecks
+ overlapping task demands
+ reciprocal development
+ acquired knowledge
```

simultaneously.

Therefore:

```text
PluralCausalGenerationOfPositiveManifold
```

is retained as a live hypothesis.

# 12. Rival I9 — fractionated / multiple-component intelligence

## 12.1 Strong form

Large-scale task batteries can recover several partially distinct components rather than one process.

Hampshire et al. reported separable components associated with reasoning, short-term memory and verbal ability, with different functional brain networks; their simulations suggested higher-order g-like covariance could arise from tasks co-recruiting multiple networks.

## 12.2 What survives

This strongly supports:

```text
ComplexTask
= joint demand on multiple cognitive systems
```

and:

```text
HighGLoading
can reflect multi-system recruitment
```

rather than one indivisible general process.

## 12.3 Main limitation

Recovering three or another number of components from one battery does not prove that exactly those components are universal primitives.

```text
ThreeComponents != ThreeCognitiveAtoms
```

## 12.4 Disposition

```text
Retain multi-component / multi-network realization.
Reject exact component count as ontology by factorization alone.
```

# 13. Rival I10 — idiographic within-person cognitive structure

HD10-A/B already retained a crucial result:

```text
BetweenPersonCognitiveStructure
!= WithinPersonCognitiveStructure
```

Repeated daily assessment of nine cognitive tasks in 101 adults showed person-specific within-person structures that differed from the modal between-person ability structure; g was less prominent within persons.

Therefore a person's `ability profile` cannot be reduced to the population covariance model.

Retain:

```text
PersonCognitiveDynamics_H
```

separately from:

```text
PopulationAbilityCoordinates_K
```

## Disposition

```text
Retain as indispensable person-level realization layer.
Reject population factor structure as automatic intraindividual architecture.
```

# 14. Rival I11 — dynamic assessment / learning potential

## 14.1 Strong form

Static testing asks approximately:

```text
What can H do now under protocol P?
```

Dynamic assessment adds instruction/feedback/prompts and asks:

```text
How does H change under intervention protocol I?
How much support is required?
Does improvement transfer?
```

## 14.2 New object

Define:

```text
ModifiabilityProfile_D(H | InterventionProtocol I, interval T)
= {
    gain,
    hints/support required,
    strategy change,
    retention,
    transfer,
    error correction,
    learning rate
  }
```

## 14.3 What survives

Dynamic testing demonstrates:

```text
SameInitialScore
!= SameLearningResponse
```

and:

```text
CurrentPerformance
!= FutureLearningTrajectory
```

This is highly relevant to `potential`.

## 14.4 But potential is still protocol-relative

A larger gain under one teaching protocol does not reveal a timeless hidden `Potential` scalar.

```text
LearningPotential_I
!= GeneralFutureCapacity
```

because gains depend on:

```text
instruction type
prior knowledge
motivation/state
feedback
support
transfer target
measurement ceiling
```

## 14.5 Disposition

```text
Retain dynamic assessment as intervention-based evidence for modifiability.
Reject learning potential as hidden fixed essence.
```

# 15. Rival I12 — expertise / acquired knowledge

HF8/HF9/HF11 already provide strong boundaries.

Expertise can produce:

```text
better problem representation
faster cue recognition
more efficient search
chunking/compression
stronger domain prediction
proceduralized skill
```

without implying universally higher general reasoning.

Thus:

```text
Expertise_D != GeneralIntelligence
```

remains.

But the reverse collapse also fails:

```text
GeneralAbilityScore != DomainExpertise
```

because domain mastery requires extensive acquisition and organization.

## 15.1 Knowledge as cognitive resource

Knowledge changes task difficulty.

A problem that is novel for one person may be retrieval/pattern recognition for an expert.

Therefore:

```text
TaskDifficulty
= relation(PersonKnowledge, Representation, Task, State, Support)
```

not a person-independent scalar.

## 15.2 Disposition

```text
Retain expertise/knowledge as acquired domain-specific capability structures.
Reject intelligence as either knowledge totality or knowledge-free processing power.
```

```text
ObservedAbilityProfile

    KnowledgeHistory,
    SupportBoundary,
    ScoringModel
  )
```

This gives:

```text
BatteryFactorStructure
!= CompleteHumanCognitiveArchitecture
```

Persistent agents can supply:

```text
retrieval
long-horizon memory
notes

reminders
```

This can improve task performance while leaving internal memory capacity unchanged or even reducing internal retention/practice.

Thus:

```text
ExternalMemoryAvailable
```

# 22. Agent-era perturbation II — process substitution

An Agent can substitute for specific processes:

```text
calculation
search
translation
planning
proof checking
coding
summarization
option generation
```

Therefore a task's apparent cognitive demand changes when support changes.

```text
TaskDemandProfile_withoutAI
!= TaskDemandProfile_withAI
```

This means old intelligence tests cannot simply be reused under arbitrary assistance while preserving interpretation.

# 23. Agent-era perturbation III — process amplification

Agents need not only substitute.

They can increase Human effective performance by:

```text
reducing working-memory load
externalizing intermediate states
forcing verification
providing counterexamples
reformatting representations
generating practice
```

This can produce a genuine Human–Agent cognitive system whose capability exceeds either component alone.

But:

```text
SystemCapability != HumanIndependentAbility
```

This is valuable because it creates a common experimental surface for Human and artificial systems.

But:

```text
SameBenchmark
!= SameMechanism
!= SameOntology
```

and:

```text
ARCPerformance
```

# 28. Genuine conflicts versus level differences

## Genuine conflicts

```text
One common causal g
vs
positive manifold generated without one common cause

Population factor hierarchy = person mechanism architecture
vs
within-person structure differs materially
```
