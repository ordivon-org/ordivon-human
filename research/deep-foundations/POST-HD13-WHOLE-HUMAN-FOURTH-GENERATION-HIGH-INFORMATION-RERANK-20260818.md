# 4. Developmental topographical disorientation gives unusually clean selective pressure

Developmental topographical disorientation (DTD) provides a natural experiment in which individuals can show lifelong severe navigation/orientation impairment without acquired brain injury and with otherwise broadly preserved cognitive functions.

Classic DTD work identified cognitive-map formation as a major differentiating deficit.

Therefore:

```text
GeneralCognitionPreserved
+
NavigationSeverelyImpaired
```

is empirically possible.

This makes spatial navigation more than a trivial application of generic memory or vision.

---

# 5. Navigation is not one task

A 2025 DTD assessment study directly compared self-report and actual computerized navigation performance.

The study separated tasks involving:

```text
route knowledge
landmark knowledge
survey knowledge
landmark ordering
```

and found that self-report screening and objective navigation battery classifications overlapped only weakly.

Thus:

```text
SenseOfDirectionSelfReport
!= ActualNavigationPerformance
```

and:

```text
NavigationAbility
!= OneScoreByDefinition
```

This gives HD14 immediate measurement value.

---

# 6. Allocentric and egocentric spatial maps partially dissociate

A 2025 behavioral study explicitly assessed allocentric and egocentric coordinate-based spatial memory after virtual navigation.

Environmental relationships predicted allocentric performance; participant-centered distance/orientation relationships predicted egocentric performance; spatial feedback benefited performance within each domain rather than transferring across them.

Therefore:

```text
AllocentricSpatialRepresentation
!= EgocentricSpatialRepresentation
```

while both participate in navigation.

---

# 7. Landmark navigation and path integration are separable but coupled

Naturalistic human navigation combines:

```text
self-motion / path integration
and
external landmark evidence.
```

2025 immersive-VR/mobile-EEG work found accumulated homing error could be corrected by a briefly presented landmark, with correction dynamics depending on confidence in the current self-motion-derived estimate.

Therefore:

```text
PathIntegration
!= LandmarkNavigation
```

and:

```text
Navigation
= dynamic cue integration / recalibration in many regimes.
```

This strongly pressures HF20/HF11/HF8 boundaries.

---

# 8. Scene/view integration is itself plural

2026 JNeurosci work distinguished two ways of integrating views of a place:

```text
panoramic association across views from one vantage point
vs
landmark-based association across different views of the same distal place/object
```

with distinguishable place-selective cortical mechanisms.

Therefore:

```text
ViewIntegration
!= OneSceneMechanismByDefinition
```

and cognitive-map construction should not be defined as one hippocampal operation.

---

# 9. Allocentric representation formation is a process, not a static map object

2025 naturalistic virtual-city work explicitly studied formation of allocentric representations from navigation experience.

The important architectural pressure is:

```text
EgocentricExperience
→ possible transformation/integration
→ AllocentricRepresentation
```

rather than:

```text
NavigationInput
→ one fixed CognitiveMap store.
```

This suggests a layered transformation architecture requiring direct reconstruction.

---

# 10. Sensory deprivation separates spatial content from visual format

Blind and sighted navigation studies show spatial navigation can use nonvisual sensory substitution, body-based cues and remembered landmarks.

Congenital blindness can preserve important egocentric/navigation functions while affecting some allocentric spatial judgments.

Therefore:

```text
SpatialNavigation
!= VisualNavigationByDefinition
```

and:

```text
SpatialRepresentationContent
!= VisualRepresentationalFormat
```

HF20 modality-plurality and HF8 format-plurality are immediately relevant.

---

# 11. Individual path-integration bias is not one population constant

2026 virtual-reality path-integration work found persistent individual left/right biases that disappear when data are averaged across sides at the population level.

Thus:

```text
PopulationMeanNavigationError
!= IndividualNavigationMechanism
```

Navigation evidence requires within-person and directional typing.

---

# 12. Why spatial navigation outranks Human-Agent adaptation now

Persistent Human-Agent interaction is extremely important and current longitudinal/RCT evidence is growing.

However current effects naturally consume already-established Human owners:

```text
HF6  adaptation/plasticity
HF7  memory/retention/offloading
HF8  knowledge/understanding
HF12 trust/reliance/joint action
HF22 attachment/persistent relationship
HOC1/HOC3/HOC6 support attribution
```

Current studies also show strong dependence on usage intensity, anthropomorphism, conversation design and participant predispositions.

Thus it is a powerful Agent-era perturbation ecology but currently a weaker missing Human architecture test than spatial navigation.

# 13. Why spatial navigation outranks psychopathology

Psychopathology remains one of the best cross-HF destructive-falsifier programs.

Current transdiagnostic computational work continues to show similar clinical endpoints can arise through different underlying effort/reward processes.

That increases falsifier value while decreasing support for a diagnosis-level Human owner.

Spatial navigation instead supplies a cleaner ordinary-function architecture with selective developmental impairment and multiple experimentally separable subfunctions.
