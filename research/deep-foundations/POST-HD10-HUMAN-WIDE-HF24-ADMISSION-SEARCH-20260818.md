# 1. New foundation-admission signal

A candidate cannot win because it is famous, under-cited or operationally useful.

For HF24 admission pressure, require evidence for:

```text
F1. a stable reusable Human-side object/process/relation;
F2. cross-regime recurrence beyond one domain/application;
F3. inability to represent it through HF0–HF23 composition without recurrent hidden choices;
F4. a coherent causal/state architecture rather than measurement label or consumer taxonomy;
F5. destructive counterexamples against neighboring owners;
F6. evidence/measurement distinctions sufficient to avoid one-score ontology;
F7. Agent-era pressure that tests rather than manufactures novelty;
F8. deletion harm: removing the candidate causes systematic explanatory/decision loss.
```

A deep research route can be admitted with weaker evidence than a Foundation.

Therefore:

```text
DeepRouteAdmission
!= FoundationAdmission
```

# 11. Candidate A — imagination / nonactual scenario construction

The strongest current survivor is not `Narrative`.

Use the broader provisional label:

```text
Imagination / Nonactual Scenario Construction / Reality-Decoupled Simulation
```

The key Human capability/process is:

> Constructing, sustaining, manipulating or experiencing structured content that is not currently taken as the actual external state, while preserving variable constraints, source/reality relations and possible downstream use.

This can appear in:

```text
mental imagery
future-event simulation
counterfactual-like alternatives
fictional-world construction
pretence
role simulation
creative recombination
spatial imagination
narrative scene/event construction
spontaneous mind wandering
dream-like internally generated experience
```

These are not assumed to be one mechanism.

# 13. Why HF9 also leaves an explicit crack

HF9 owns counterfactual simulation.

Its canonical structure is:

```text
Counterfactual(H, actual world W, intervention/change X', query Y')
```

and:

```text
CounterfactualAnswer
= Function(Model, Intervention, Invariants)
```

Critically HF9 explicitly says this is:

```text
not free imagination
```

That line is a direct canonical residual.

Counterfactual reasoning asks:


Free/nonactual scenario construction may instead allow:

```text
no actual-world intervention anchor
invented entities/rules
unknown or intentionally relaxed invariants
pretend stance

```

Therefore:

```text
CounterfactualSimulation
!= FreeImaginationByDefinition
```

is currently unsupported but highly plausible.

# 14. Recent imagined-navigation evidence

Human intracranial recordings during real and imagined navigation show structured hippocampal dynamics during imagined routes even without current external sensory cues.

This supports:

```text
ImaginedSpatialTrajectory
can preserve structured internally generated spatial dynamics
```

without implying imagined and perceived navigation are identical.

It pressures any model that reduces imagination to a verbal proposition or static image.

---

# 15. Dynamic imagination has measurable capacity limits

2025 preregistered experiments on mentally tracking moving objects show that Humans can continue object motion in imagination with systematic performance limits.

This matters because it demonstrates:

```text
Imagination
can involve dynamic state evolution
```

rather than only retrieving one stored representation.

The candidate therefore needs to represent:

```text
scenario state_t
transition/update
capacity/resource limits
error accumulation
```

if deep research supports it.

---

# 16. Reality monitoring is a separate operation

2025 neuroimaging work on distinguishing imagination from reality shows that internally generated and externally generated perceptual signals can overlap and that reality judgments require additional monitoring/classification processes.

Thus:

```text
ImaginedContent
!= KnownImaginedSourceByDefinition
```

and:

```text
ImaginationGeneration
!= RealityMonitoring
```

A useful future grammar must separate:

```text
generation source
phenomenal/perceptual vividness
memory source
current reality judgment
belief/endorsement
```

---

# 17. Pretence provides a high-information dissociation

2026 experiments on pretending not to know show Humans can approximate decision behavior under a simulated counterfactual informational state.

This is not ordinary belief or ordinary memory deletion.

It requires something like:

```text
actual knowledge state K
+ simulated self-model without K
→ pretend action policy
```

with imperfect leakage from actual knowledge.

Therefore:

```text
PretendedState
!= ActualBeliefState
!= MereFalseReport
```

and:

```text
SelfSimulation
may be a real imagination pressure case.
```

---

# 18. Narrative is a consumer/organization mode, not the candidate itself

Recent narrative-comprehension work shows Humans encode event boundaries and sequences during ongoing narratives.

Narrative therefore remains important.

But:

```text
Narrative
!= Imagination
```

because:

```text
actual-history narratives can be non-imaginary;
non-narrative spatial imagery can be imaginative;
counterfactual scenes can lack plot;
dream experience can be fragmentary;
pretence can operate locally without a story.
```

Media owns external narrative artifact structure.

Human candidate ownership, if any, is scenario construction/organization rather than story objects.

---

# 19. Dreams are a pressure case, not identity

Dreaming shows:

```text
Experience present
+ reduced external connectedness
+ internally generated scene/event content
```

but:

```text
Dream != VoluntaryImagination
```

Dreams can be involuntary, poorly controlled and reality-confused.

HF2 remains experience/connectedness owner; sleep mechanisms remain HF5/HD9; HF7 owns memory relations.

HD11 should use dreams to test the breadth of scenario-generation architecture without redefining dreaming as imagination.
