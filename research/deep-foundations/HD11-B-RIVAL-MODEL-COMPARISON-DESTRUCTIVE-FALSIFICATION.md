# 2. M1 — HF8 Generative Representation

## Claim

```text
Scenario construction
= generation/manipulation/use of HF8 representations and mental/world models.
```

## Strength

HF8 already owns:

```text
fictional / future / false / possible content
Represented(P) != Believed(P)
MentalModel(Possibility X) != Belief(X actual)
relational/possibility structure
transition dynamics in WorldModel_D
```

So M1 is not a strawman.

## Hard-case performance

```text
B1 aphantasia                 PASS
  representation need not be visual.

B2 nonvisual imagination      PASS

B3 actual-content imagery     PASS
  nonactuality is not required for representation.

B4 free fiction               PARTIAL
  can represent invented entities/rules;
  but generation/update policy is unspecified.

B5 counterfactual             PASS as substrate
  HF9 supplies operator semantics.

B6 pretence                   PARTIAL
  can represent actual and pretend states;
  stance/policy selection is extra.

B7 lucid dream                TYPES
  content and belief can be represented;
  phenomenal state/reality monitoring are HF2/other.

B8 hallucination              TYPES
  does not explain source/reality error.

B9 mind wandering             TYPES
  does not define task decoupling/meta-awareness.

B10 Agent-generated scenario  PASS
  Human can represent externally generated content.

B11 dynamic state             PARTIAL/PASS
  WorldModel permits transitions,
  but construction/update operator remains underspecified.

B12 future without narrative  PASS
```

## Main failure

M1 can store or instantiate every required relation only by quietly adding an operator that says:

```text
construct this model
choose these constraints
relax those constraints
instantiate these entities
advance this state
```

That operator is exactly the residual under test.

Therefore:

```text
RepresentationalSubstrate
!= Construction/UpdateProcessTotality
```

## Disposition

```text
M1 = STRONG SURVIVOR AS SUBSTRATE
     INCOMPLETE AS FULL PROCESS ACCOUNT
```

No HF8 reopen condition is triggered: HF8 already allows models to be constructed/used, but it never claimed to exhaust every transformation process over them.

# 3. M2 — Generalized HF9 Simulation

## Claim

```text
Scenario construction
= HF9 simulation generalized beyond strict counterfactual reasoning.
```

## Strength

HF9 already handles:

```text
representation transformation
simulation
counterfactual alternatives
model/invariant/transition structure
```

and thus naturally handles B5.

## Destructive problem

HF9's counterfactual object is explicitly:

```text
actual world W
+ intervention/change X'
+ query Y'
+ model/invariants
```

and canonical text says:

```text
CounterfactualAnswer
= Function(Model, Intervention, Invariants)
not free imagination.
```

For B4 free fiction, one may invent:

```text
entities with no actual counterpart
new local laws
new causal rules
new social ontology
```

without an actual-world intervention anchor.

To make M2 cover this, `simulation` must be expanded to mean:

```text
any evolving represented state under any locally chosen constraints
```

At that point it no longer identifies HF9 counterfactual reasoning; it merely renames the HD11 residual.

## Pretence pressure

B6 is also damaging.

Pretending not to know can be modeled as a counterfactual epistemic state, but 2026 evidence shows behavior is generated from a simplified self-model and contains systematic leakage/overacting.

This requires:

```text
model of self-state
policy generation under that state
comparison with actual knowledge
```

not merely external-world `do(X)` semantics.

## Disposition

```text
M2 = RETAIN for constrained counterfactual subset
     REJECT as total imagination/scenario account
```

Key firewall:

```text
CounterfactualSimulation
!= FreeScenarioConstruction
```

# 4. M3 — Constructive Memory Recombination

## Claim

```text
Imagined scenarios are constructed by retrieving and recombining memory elements.
```

## Strong evidence

This model has serious support.

2024 fMRI work explicitly separated retrieval from subsequent imaginative creation and showed differential patterns for constructing novel scene/object representations from learned components.

Classic and newer autobiographical-event simulation work also shows overlap between remembering and imagining, with hippocampal and default-network contributions to event construction.

Aphantasia studies show degraded visual imagery is often associated with reduced autobiographical detail and future simulation richness.

Thus:

```text
MemoryMaterial
is often causally important for scenario construction.
```

## Failure 1 — material source is not process identity

Every Human construction must ultimately use learned priors/history at some level, but that fact is too weak.

It does not tell us:

```text
which retrieved elements are bound together
which relations are invented
which rules are preserved
which constraints are relaxed
which transition occurs next
```

## Failure 2 — invented local structure

B4 permits novel local rules not remembered as prior episodes.

Those rules still depend on learned concepts, but:

```text
UsesMemory
!= IsMemoryRetrieval/RecombinationOnly
```

## Failure 3 — Agent-seeded content

In B10 an Agent may provide most content.

The Human may then:

```text
accept
inspect
simulate
modify
continue
```

without independently retrieving the scenario elements.

Memory remains necessary background knowledge, but not sufficient ownership.

## Failure 4 — pretense

M3 does not by itself explain why actual knowledge can remain present while a simulated ignorance state governs policy.

## Disposition

```text
M3 = STRONG CONTRIBUTOR / MATERIAL-SOURCE ACCOUNT
     REJECT as universal process identity
```

Key firewall:

```text
ScenarioUsesMemory
!= ScenarioConstructionIsMemoryOnly
```

# 5. M4 — Predictive / Generative Decoupling

## Claim

```text
Imagination is generative modeling when processing is decoupled/shielded from current sensory input.
```

## Strength

2025 work on internal attention finds reduced early sensory responses during internal versus external selection, consistent with perceptual decoupling/internal shielding.

Reality-monitoring work also shows internally generated and perceived signals can overlap and require classification of their source/reality.

This gives M4 a plausible mechanistic layer:

```text
ExternalInputWeight ↓
InternalGeneration/Attention ↑
```

## Failure 1 — decoupling is too broad

Perceptual decoupling occurs in:

```text
memory retrieval
mind wandering
internal arithmetic
semantic thought
planning
```

not only imagination.

Therefore:

```text
PerceptualDecoupling
!= ScenarioConstruction
```

## Failure 2 — dream/hallucination

Dreams and hallucinations can also be internally driven/decoupled but have radically different:

```text
voluntary control
reality commitment
source attribution
meta-awareness
```

So decoupling cannot supply the stance/reality grammar.

## Failure 3 — local structure

A sensory-precision account does not specify:

```text
which entities exist
which local laws hold
how the state changes
```

without importing a representational/model layer.

## Disposition

```text
M4 = RETAIN as gating/attention/generative-regime mechanism
     REJECT as total scenario/imagination ontology
```

# 6. M5 — Heterogeneous Family / No Single Owner

## Claim

```text
There is no unitary imagination process.
Imagery, fiction, future thought, pretense, dreams, mind wandering and creativity
are heterogeneous families composed from existing systems.
```

## Strong support

HD11-A already established:

```text
visuality not necessary
future orientation not necessary
novelty not necessary
narrative not necessary
volition not universal
fictionality not necessary
```

2025 precision-neuroimaging work on self-generated states also reports different distributed networks for scene-like versus speech-like imagined states rather than one sensory-imagery module.

Aphantasia demonstrates large variation in imagery while some semantic simulation remains.

So:

```text
ImaginationUmbrella
is genuinely heterogeneous.
```

## Why full no-owner is too strong

M5 risks turning every repeated functional pattern into mere coincidence.

Across:

```text
imagined navigation
novel scene construction
future-event construction
fictional scene elaboration
pretense self-state simulation
```

one recurring question remains:

```text
What structured state is currently instantiated?
What elements/relations/constraints define it?
What transition produces the next state?
```

The answer need not be one neural module, just as other HFs do not require one neural locus.

## Disposition

```text
M5 = PASS for broad `imagination` umbrella heterogeneity
     FAIL if interpreted as denying every reusable construction process
```

This is a major B-round result:

```text
Imagination umbrella may have no single owner
while
ScenarioConstructionProcess may still be a reusable bounded process.
```

# 7. M6 — Distinct Scenario-Construction Architecture

## Claim

```text
A reusable Human process constructs and updates locally coherent scenario states
across modalities and uses.
```

## Minimal bounded object

```text
ScenarioState = {
  entities/participants,
  properties,
  relations,
  perspective,
  spatial/temporal/event state where relevant,
  information state,
  local constraints/rules,
  transition possibilities,
  local truth/stipulation,
  uncertainty
}
```

and:

```text
ScenarioConstructionProcess = {
  source/material,
  state initialization,
  element/relation binding,
  constraint selection,
  constraint relaxation/addition,
  transition/update,
  detail elaboration,
  monitoring,
  termination/return
}
```

## Evidence that helps M6

### dynamic scene/object evidence

Imagined navigation and imagined moving-object experiments show state evolution and measurable capacity/error constraints rather than static retrieval only.

### memory-to-novel-scene evidence

2024 fMRI work explicitly uses learned components to create new scene/object representations, separating retrieval from imagination phases.

### hippocampal lesion evidence

Classic bilateral hippocampal amnesia studies show selective difficulty constructing spatially coherent novel scenes despite access to semantic fragments.

A particularly useful dissociation found patients could make semantic possibility judgments but were impaired on constructive possibility judgments requiring flexible internal scene models.

This is stronger than mere term convenience:

```text
SemanticKnowledgeAvailable
+ specific SceneConstructionImpairment
```

can coexist.

### future-vs-scene dissociation

fMRI work matching future orientation while varying scene-construction demand found medial temporal activity tracked scene construction more than future projection itself.

This supports:

```text
SceneConstruction
!= FutureProjection
```

## Main weakness

Most strong causal evidence is **scene/spatial/episodic**.

It does not yet prove one architecture spans:

```text
abstract verbal hypothetical
social self-simulation
motor imagination
fictional rule systems
nonspatial scenarios
```

If M6 expands to every internally structured representation, it collapses back into HF8 MentalModel.

Therefore its valid scope must remain bounded.

## Disposition

```text
M6 = STRONGEST BOUNDED FUNCTIONAL SURVIVOR
     NOT YET PEER-FOUNDATION ARCHITECTURE
```

# 8. M7 — Stance / Activity Account

## Claim

```text
The key difference is not a new architecture,
but how existing content is treated/used:
fictional, pretend, hypothetical, supposed, entertained, etc.
```

## Strength

M7 explains several A-round dissociations elegantly.

### actual-content imagery

A Human can imagine an actual room.

So imagination cannot be defined solely by world nonactuality.

### pretense

Actual knowledge can remain while behavior is organized under:

```text
PretendStipulation
```

### fiction

One can process fictional content while maintaining:

```text
KNOWN_FICTIONAL
```

without false belief.

Therefore stance is indispensable.

## Failure

Stance does not generate the state.

Two Humans can both adopt:

```text
"imagine this scene"
```

yet differ in:

```text
number of bound elements
spatial coherence
transition accuracy
capacity limit
constructed detail
```

Likewise the same pretend stance can be supported by better/worse self-model simulation.

Thus:

```text
Stance
!= ConstructionProcess
```

## Disposition

```text
M7 = RETAIN AS ORTHOGONAL RELATION/USE ACCOUNT
     REJECT AS TOTAL GENERATION ACCOUNT
```

Suppose an Agent generates a complete fictional scenario.

Human reads it but does not elaborate it.

Then:

```text
AgentScenarioGeneration = true
HumanScenarioConstruction = not established

```

If the Human then mentally places themselves in the scene, fills spatial gaps, predicts an event and changes a local rule:

```text
Agent content provenance
+ Human scenario construction/update
```

can coexist.

Thus:

```text
ContentAuthor
!= ScenarioConstructorByDefinition
```

and:

```text
AgentGenerativeOutput
!= HumanIndependentScenarioGenerationCapability
```

This case strongly favors separating HF8 access/provenance from HD11 construction operations.

```text

  semantic knowledge
```

# 14. Why existing hippocampal evidence is important but insufficient

Bilateral hippocampal damage can severely impair novel scene construction, and some experiments distinguish scene-construction demand from future projection.

This strengthens:

```text
SceneConstruction
is not just FutureThinking.
```

But developmental amnesia cases can show preserved scene construction despite hippocampal damage/atrophy, presumably through residual or alternative organization.

Therefore:

```text
Hippocampus = ScenarioConstruction
```

is rejected.

The correct conclusion is functional, not anatomical:

```text
ScenarioConstruction has identifiable constraints and dissociations;
its exact mechanism may be distributed/plural.
```
