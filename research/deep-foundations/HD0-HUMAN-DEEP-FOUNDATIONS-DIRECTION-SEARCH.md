# HD0 — Human Deep Foundations Direction Search

## 0. Decision

HF0–HF19 remain a strong first-generation **boundary grammar / view library**, but they
are not a complete mechanistic Human world model.

HD0 therefore does **not** reopen the frozen foundations and does **not** name HF20.
It opens a second research mode:

```text
Foundation skeleton
→ semantic coverage audit
→ mechanism-depth audit
→ cross-scale / comparative / developmental / perturbational pressure
→ repeated residual ledger
→ deep research route
→ only then decide whether any canonical foundation must be added or reopened
```

The first admitted deep route is:

```text
HD1 — Perception, Sensing, Active Sampling and Perceptual World Coupling
```

`HD1` is a research route, not a new canonical HF round. Its job is to test whether the
current HF2/HF3/HF5/HF8/HF11 surfaces can actually represent perception without hidden
choices. Only HD1 evidence may decide whether a future foundation admission condition
is satisfied.

---

# 1. Why a second research mode is needed

HF0–HF19 achieved unusually broad horizontal coverage:

```text
projection / identity
→ experience / attention / value
→ regulation / learning / memory
→ representation / reasoning / decision / action
→ sociality / institution / normativity
→ standing / population / governance / mechanism
→ production / economic organization
```

But horizontal presence is not the same as vertical mechanism closure.

A topic can appear many times while remaining only an interface variable. Examples:

```text
perception
emotion
development
language
culture
social cognition
```

They are repeatedly consumed by existing HF rounds, yet the chain beneath them may
still be represented as one unexplained arrow.

HD0 therefore distinguishes:

```text
Absent
!= Named
!= InterfacePresent
!= SubstantialModel
!= MechanisticallyReconstructed
!= AdversariallyTested
```

The keyword inventory used during HD0 is only a navigation aid. It is explicitly not
semantic proof of coverage.

---

# 2. Completeness target

Human Deep Foundations does not pursue encyclopedic completeness. It seeks three more
useful closures.

## 2.1 Coverage closure

For a materially important Human phenomenon, the system should be able to say:

```text
which projection(s)?
which scale(s)?
which current model family?
which evidence surface?
which unknown bridge?
which ownership boundary?
```

## 2.2 Causal / mechanistic closure

A model should progressively replace unexplained arrows with typed mechanisms:

```text
implementation
constraint
state transition
learning/history
cross-scale bridge
social transmission
institutional mediation
```

This does not require one universal causal graph.

## 2.3 Falsification closure

For every major model family, Human should know:

```text
what observation discriminates it?
what perturbation separates neighboring constructs?
where does transport fail?
what would force revision?
```

Therefore:

```text
MoreLiterature != MoreClosure
MoreConstructs != BetterWorldModel
```

# 3. Explanatory scales

Future deep research must state which explanatory role is being claimed.

```text
physical / chemical
cellular / molecular
physiological
neural circuit / systems
computational
cognitive / experiential
behavioral / sensorimotor
relational / social
organizational / institutional
cultural / historical
ecological / technological
```

Do not infer:

```text
NeuralImplementation = PsychologicalConstruct
GeneticAssociation = IndividualCause
EvolutionaryFunction = CurrentMotivation
CulturalRegularity = HumanUniversal
SocialExplanation = BiologicalIrrelevance
```

Cross-scale explanation is a first-class research object rather than an invitation to
collapse levels.

# 4. Pressure axes

HD0 rejects the idea that every important topic should become its own foundation.
Several of the deepest missing dimensions are better treated as **mandatory pressure
axes** applied repeatedly across domains.

## 4.1 Evolution / comparative axis

For relevant mechanisms ask:

```text
mechanism now?
ontogeny / development?
possible function under ancestral/relevant ecology?
phylogenetic history / comparative precursors?
```

Evolution is not admitted as a universal explanatory solvent. It must distinguish
historical origin, selected function, current mechanism and present adaptive value.

## 4.2 Development / lifespan axis

Pressure cases include:

```text
prenatal
infancy
childhood
adolescence
adulthood
aging
end of life
```

`HF6 Development` provides the change grammar, but not a complete empirical life-course
model.

## 4.3 Cross-cultural / historical axis

Every proposed Human universal should survive, where evidence permits:

```text
multiple language families
multiple social/ecological regimes
non-WEIRD populations
historical variation
institutional variation
```

## 4.4 Pathology / lesion / disability axis

Selective breakdown can expose distinctions hidden in ordinary adult performance.
Use pathology and disability as natural or designed falsification contexts, not merely
as downstream applications.

Retain:

```text
Impairment != DisabilityByDefinition
Functioning = Person × Body × Task × Environment × Support × Institution
```

## 4.5 Altered-state axis

Pressure cases include:

```text
sleep
Dreaming
anesthesia
drugs / altered states
extreme fatigue
extreme stress
sensory deprivation
```

## 4.6 Human × AI axis

AI is a new perturbation capable of separating historically coupled variables:

```text
internal memory vs external retrieval
reasoning vs answer access
choice vs recommendation
execution vs authorization
skill vs supported performance
individual vs joint capability
language production vs human experience
```

AI output is not itself ontology evidence.

# 6. Residual ledger

## R1 — Perceptual world coupling

Current HF surfaces repeatedly use:

```text
sensory evidence
perceptual content
attention
interoception
affordance
state estimation
sensory feedback
```

without an independent reconstruction of:

```text
world/source
→ physical signal
→ sampling action
→ receptor/transduction
→ sensory evidence
→ integration / segregation
→ percept / object / scene / body state
→ uncertainty
→ action-conditioned resampling
```

This residual recurs across HF2, HF3, HF5, HF8 and HF11.

Recent human olfaction evidence is especially useful because sniffing is simultaneously
motor action and sensory acquisition: fine-grained perceptual features can alter the
sampling action itself. This is direct pressure against a purely one-way
`World → Perception` pipeline. See HD0-SOURCES S01.

**Status:** strongest first-route residual. Not yet a canonical foundation admission.

## R2 — Affect / emotion bridge

HF4 models valuation/motivation; HF5 models regulation/interoception/stress; HF14 models
welfare/harm; HF15 depends on valenced experience. Yet the bridge among:

```text
bodily regulation
interoceptive representation
appraisal / prediction
emotion concepts
action tendencies
social signaling
cultural learning
```

remains thin.

Cross-cultural meta-analytic evidence shows that the relation between common emotion-
regulation strategies and mental-health outcomes is moderated by cultural context,
warning against one context-free scalar model. See S07.

**Status:** high-priority domain candidate after HD1.

## R3 — Language / symbolic generativity

HF8 uses concepts/representations; HF12 separates communication from language; HF13–18
rely heavily on explicit rules, norms and institutional representations. But Human lacks
a reconstruction of:

```text
signal / gesture
→ conventional sign
→ lexical / compositional structure
→ semantics / pragmatics
→ displaced / counterfactual reference
→ narrative / writing
→ externally persistent symbolic systems
```

Large typological analyses continue to revise which grammatical universals are robust,
and comparative neuroanatomy continues to revise which language-related structures are
strictly human-specific. See S03–S04.

**Status:** high-priority domain candidate; do not precommit a universal grammar theory.

## R4 — Culture as more than norm/institution

HF13 reconstructs persistent social order but not the full dynamics of cultural
inheritance. Missing bridges include:

```text
individual learning
→ social learning / teaching / imitation
→ population transmission
→ cumulative / recombinative change
→ symbolic and opaque culture
→ institutions
→ changed developmental environment
```

Current cultural-evolution research itself is revising the candidate signature of human
cultural uniqueness: cumulative change and high-fidelity transmission may be insufficient,
with open-ended inherited variation proposed as an alternative distinguishing feature.
Comparative evidence also finds culturally dependent repertoires outside humans. See
S05–S06.

**Status:** strong domain candidate; likely coupled to language, development and social
learning rather than standalone first route.

## R5 — Relational development / social cognition

HF12 models interaction, joint action, communication and trust but only partially models:

```text
other-mind inference
self/other distinction
impression formation
attachment
caregiver regulation
persistent dyads
family / kin / friendship / romantic relations
```

Recent cross-cultural/historical work supports both shared dimensions and substantial
cultural structuring of relationship concepts; developmental work emphasizes that early
social interaction can become embodied in developmental trajectories. See S08–S09.

**Status:** strong domain candidate / HF12 deep-pressure route.

## R6 — Biological implementation without biological reductionism

HF5 provides regulatory grammar but not a detailed organismic model. Human still lacks
systematic bridge work among:

```text
endocrine
immune
metabolic
circadian
cardiovascular
respiratory
musculoskeletal
neural
```

and higher-level state/capability. Developmental cortical atlases continue to reveal
previously unresolved cell-lineage and subtype dynamics, demonstrating that even the
neural implementation substrate remains under active reconstruction. See S02.

**Status:** deepening programme, not one giant `Body` foundation.

## R7 — Individual variation without essentialism

HF0 correctly rejects a Human trait vector, but current foundations do not yet deeply
reconstruct genetic/environmental sources of variation, psychometric structure, or
trait-context dynamics.

Current large population research illustrates why this requires strict typing:
heritability estimates vary with measure, method and context; heritability is a
population statistic and is not individual destiny or immutability. See S11.

**Status:** pressure axis and later candidate.

## R8 — Pathology / disability as model-breaking evidence

Current HF reports use some disorders and impairment cases, but no systematic
perturbation matrix exists. NIMH's RDoC programme explicitly studies functional
constructs across multiple units of analysis and across normal-to-abnormal dimensions;
WHO's ICF explicitly embeds functioning/disability in environmental context. See S10,
S12.

**Status:** mandatory test axis, not a new disease taxonomy.

## R9 — Generativity: play, imagination, creativity and aesthetics

HF9/HF10 contain search and counterfactuals, and HF19 contains innovation, but the system
has no deep account of open-ended generation, fiction, play, humour, music or aesthetics.

**Status:** lower current centrality but potentially high discovery value, especially if
culture/language research exposes a common generativity mechanism.

# 7. A deeper HD0 finding: the missing objects are often bridges, not nouns

The first HF cycle was intentionally noun-splitting: `A != B` prevented category errors.
HD0 finds that the next research pressure often has a different form:

```text
How does A become B?
Under what mechanism?
At which scale?
When does the bridge fail?
```

High-value bridge examples:

```text
signal → percept
interoception → affect / emotion
experience → persistent learning
individual learning → cultural inheritance
physical action → inference about another mind
caregiver interaction → developmental regulation
language → persistent institutional representation
tool / AI support → joint capability → internal learning or dependency
```

Therefore second-generation research should optimize for **bridge discovery and bridge
falsification**, not construct accumulation.

---

# 8. Why pre-Agent literature cannot be assumed complete

HD0 does not claim that Agent systems automatically discover superior science. It makes a
narrower claim: several mature research areas remain actively revisable and fragmented.

Representative current pressures include:

- human cortical development still gaining lineage-resolved cellular mechanisms;
- large language-typology datasets rejecting many traditional universal claims while
  retaining narrower recurring constraints;
- comparative neuroanatomy revising claims of strictly human-specific language pathways;
- cultural-evolution theory revising what property of human culture is actually unique;
- psychology explicitly confronting construct fragmentation;
- psychopathology research using cross-unit dimensional frameworks rather than treating
  diagnostic labels as mechanism definitions.

See S02–S06, S10 and S13.

The legitimate Agent-era opportunity is therefore:

```text
higher-bandwidth cross-disciplinary synthesis
+ explicit typed boundaries
+ automated evidence maintenance
+ cheaper formal/model comparison
+ novel Human×AI perturbations
```

not:

```text
Agent = automatic scientific truth
```

# 9. Grand-theory guard

Human Deep Foundations must actively resist universalization pressure.

Do not precommit:

```text
PredictiveProcessing = HumanOntology
ActiveInference = UniversalMechanism
Evolution = CompleteExplanation
ReinforcementLearning = MotivationTotality
InformationTheory = CognitionTotality
NeuralCorrelate = ConstructIdentity
Culture = SocialNormsOnly
Language = Thought
Genes = Traits
```

This guard is empirically motivated as well as methodological. Recent reviews of
predictive coding / active inference emphasize that empirical support is mixed or
incomplete and that model discrimination against alternatives remains necessary. See
S14–S15.

# 10. Human Deep research protocol

Each deep route should run at least the following sequence.

```text
D0  phenomenon-space opening
D1  term separation
D2  measurement/evidence audit
D3  competing model families
D4  mechanistic decomposition
D5  explanatory-scale map
D6  developmental pressure
D7  evolutionary/comparative pressure
D8  cross-cultural/historical pressure
D9  pathology/lesion/disability pressure
D10 altered/extreme-state pressure
D11 formal/computational model comparison
D12 Human×AI perturbation
D13 cross-project boundary audit
D14 adversarial falsifier matrix
D15 reconstruction / minimum retained structure
D16 foundation-admission/reopen audit
```

Not every route requires equal evidence at every axis; `not applicable` is permitted but
must be explicit.

# 12. HD1 admission

HD0 admits exactly one next deep route:

# HD1 — Perception, Sensing, Active Sampling and Perceptual World Coupling

Why HD1 wins:

1. **Repeated interface:** perception is already required by HF2, HF3, HF5, HF8 and
   HF11.
2. **Low current mechanism depth:** the current chain often jumps from signal/sensory
   input to experience/representation/state estimation.
3. **High falsifier density:** multimodal perception, illusions, sensory substitution,
   agnosia/blindsight-like dissociations, developmental cases, active sensing and
   sensorimotor perturbation can separate models.
4. **Cross-scale tractability:** physical signal, receptor, neural implementation,
   computational inference, experience and action can be kept typed.
5. **Human×AI usefulness:** biological perception can be compared with machine/robot
   sensing without assuming equivalence.
6. **Theory pluralism:** feedforward, Bayesian/predictive, ecological, recurrent,
   sensorimotor/enactive and active-inference families offer genuine competing models.
7. **Boundary value:** it can test whether a new canonical neighboring distinction is
   actually needed rather than assuming one.

HD1 should begin by separating at minimum:

```text
WorldSource
PhysicalSignal
SamplingAction
Sensor / Receptor
Transduction
SensoryEvidence
Sensation
PerceptualContent
Feature
Object
Scene
Body / Self-related perception
MultisensoryIntegration
CueIntegration
Segregation / Binding
Uncertainty
PerceptualInference
ActiveSensing
SensorimotorContingency
PerceptualLearning
PerceptualReport
```

Do not assume these labels define the final ontology.

# 17. Stop rule

HD0 is complete when direction search has produced:

- a semantic coverage audit;
- a distinction between domain candidates and pressure axes;
- a residual ledger;
- a method stronger than the first HF cycle;
- exactly one first deep route;
- no unjustified HF successor.

Those conditions are met.

The next work is HD1, not HF20.
