# 12. Classic double dissociation — rote verbal arithmetic vs quantitative knowledge

A classic neuropsychological study described two acalculic patients with opposite patterns:

```text
Patient A
→ impaired rote verbal arithmetic facts
→ preserved quantitative numerical knowledge

Patient B
→ impaired quantitative numerical knowledge
→ preserved rote arithmetic facts
```

Therefore:

```text
ArithmeticFactKnowledge
!= QuantitativeMagnitudeKnowledge
```

and:

```text
Calculation
!= one unitary faculty
```

This is directly owner-relevant.

# 13. Exact and approximate calculation dissociate

Neuroimaging and lesion work distinguishes:

```text
small exact/rote calculation
```

from:

```text
approximation / quantitative manipulation
```

with different reliance on verbal and parietal quantity networks.

Severe aphasia can coexist with relatively preserved approximate calculation while exact calculation is impaired.

Therefore:

```text
ExactCalculation
!= ApproximateCalculation
```

and:

```text
LanguageImpairment
!= QuantityApproximationLossByDefinition
```

---

# 14. Munduruku evidence attacks `exact number = generic quantity`

Munduruku speakers in the classic study had a very restricted lexicon for exact number words.

They could:

```text
compare large approximate quantities
perform approximate addition on large numerosities
```

while failing exact arithmetic for quantities beyond the small exact lexical range.

Therefore:

```text
ApproximateNumericalCompetence
can survive without
LargeExactNumberLexicon
```

and:

```text
ApproximateQuantityRepresentation
!= ExactSymbolicNumberRepresentation
```

# 15. Piraha evidence refines the language claim

Piraha speakers without an exact number-word system can nevertheless perform exact one-to-one matching for large visible sets when the matching structure remains externally available.

Performance degrades in tasks requiring memory for exact quantity.

Thus:

```text
ExactMatchingInPresentScene
!= ExactNumberConcept/WordByDefinition
```

and:

```text
NoExactNumberWords
!= NoExactQuantityPerformanceUnderAllSupports
```

This directly invokes HOC-style support attribution and HF7 memory boundaries.

---

# 16. Current Amazonian evidence prevents overgeneralizing the classic cases

A 2026 study of Awety speakers documented a conventional counting system to twenty and found reliable exact-number performance within that learned symbolic range, while nonsymbolic number performance was comparable to Portuguese-speaking controls on the tested tasks.

Therefore:

```text
AmazonianLanguage
!= RestrictedNumberSystemByDefinition
```

and:

```text
Cultural/LinguisticNumericalSystem
is an empirical coordinate,
not an ethnic category.
```

# 17. Symbolic and nonsymbolic integration is task dependent

A 2025 study of 8–10-year-olds compared symbolic/nonsymbolic numerical integration across two paradigms.

One task showed:

```text
mixed symbolic–nonsymbolic comparison cost
```

while another showed:

```text
facilitation when numeral and dot-array quantities matched.
```

Derived integration/estrangement measures did not map straightforwardly onto standardized mathematics achievement.

Therefore:

```text
SymbolicIntegration
!= OneStableTraitByDefinition
```

and:

```text
SymbolicNumber
!= NonsymbolicNumerosity
```

while interaction between them is task-sensitive.

---

# 18. Dyscalculia/MLD attacks pure domain-general reduction

Well-matched developmental dyscalculia samples can show impaired symbolic and nonsymbolic number sense despite average IQ and matched visuospatial memory.

2024 psychophysical/computational work further found weaker numerosity encoding without evidence that the deficit was explained simply by greater interference from non-numerical visual features.

Therefore:

```text
NumerosityDeficit
!= GeneralIQDeficitByDefinition
```

and:

```text
PoorNumerosityJudgment
!= VisualInterferenceOnlyByDefinition
```

This establishes a real local quantitative/perceptual mechanism candidate.

---

# 19. But current MLD evidence also attacks one core-number-deficit theory

2025 longitudinal work found later mathematical learning disability was predicted by a mixture of:

```text
symbolic comparison
number identification
executive working memory
```

A 2026 symbolic/nonsymbolic quantity-discrimination study found format-dependent differences in latent response caution and post-error adjustment, including metacognitive/control contributions, even where observed performance could appear similar.

Therefore:

```text
MathematicalLearningDisability
!= OneNumberSenseDeficitByDefinition
```

and:

```text
ObservedQuantityTaskPerformance
!= UnderlyingNumericalRepresentationOnly
```

HF3 must remain in the model.

---

# 20. Developmental evidence is heterogeneous

Large developmental studies show dyscalculia can resemble delayed development across many basic numerical skills while some specific tasks such as dot enumeration remain atypical.

Other severe, carefully matched samples show deficits in both symbolic and nonsymbolic number sense.

Therefore:

```text
Dyscalculia
!= OneDevelopmentalTrajectory
```

and:

```text
DevelopmentalDelay
!= QualitativeNumericalDeviation
```

without task-specific evidence.
