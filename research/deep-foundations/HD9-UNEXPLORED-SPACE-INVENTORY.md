# 31. Required search axes

Do not search only by topic names. Cross the space by:

```text
Scale:
  molecular → cellular → organ → organism → dyad → group → institution → population

Timescale:
  milliseconds → days → lifespan → generations → historical/evolutionary

Explanatory question:
  mechanism → development → history → function → prediction → intervention → normativity

Evidence position:
  experience → behavior → physiology → environment → social record → historical trace

Contexts:
  healthy → pathological → developmental → aging → disability → cross-cultural
  cross-species → extreme environment → Human×Agent

Modal role:
  actual → possible → counterfactual → expected → desired → required
```
