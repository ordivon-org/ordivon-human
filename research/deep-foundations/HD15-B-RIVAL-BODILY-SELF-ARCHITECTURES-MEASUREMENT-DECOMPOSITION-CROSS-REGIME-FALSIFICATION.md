# 3. Rival A — unitary / minimal-self integrator

Strong form:

```text
one bodily-self integration process
→ ownership + location + perspective + agency + body representation
```

This immediately faces direct destructive rows.

## T01/T02 — part and whole are distinct

Body-part ownership can occur without full-body ownership, while full-body context can feed back onto local parts. A one-scalar self variable does not naturally predict both local autonomy and nonlinear global feedback.

## T03 — self-location can move without ownership

Full-body VR demonstrates that self-location and ownership are not interchangeable.

## T04 — ownership and agency double-dissociate

Passive synchronous movement can retain ownership without agency; active anatomically incongruent movement can retain agency while strongly reducing ownership.

## T15 — lesion phenotypes are not one deficit

Somatoparaphrenia, anosognosia and neglect can overlap but separate clinically and anatomically; mirror perspective can reverse ownership judgments within seconds in somatoparaphrenia.

Verdict:

```text
UnitaryMinimalSelfAsWholeOwner
= REJECT
```

A broad phenomenological family may remain useful, but it has no explanatory deletion harm once typed subcomponents are restored.

# 4. Rival B — multisensory / Bayesian causal inference for ownership

Core proposal:

```text
sensory evidence
+ reliability / uncertainty
+ prior common-cause probability
→ posterior probability that observed/felt signals arise from one bodily source
→ ownership percept/judgment
```

This rival receives unusually strong support.

## Positive row B1 — tactile input is not strictly required

Bayesian sensory-inference work predicted ownership without touch and confirmed substantial illusion probability under visual/proprioceptive evidence alone, while synchronous touch increased the posterior evidence.

## Positive row B2 — uncertainty matters quantitatively

Visual and proprioceptive uncertainty manipulations alter ownership probability in ways fit by causal-inference models. Proprioceptive noise can increase the probability of ownership, consistent with reliability-sensitive inference rather than rigid signal matching.

## Positive row B3 — neural activity tracks model variables

Posterior-parietal activity can be fit trial-by-trial with Bayesian causal-inference variables during ownership judgments.

## Positive row B4 — 2026 causal perturbation

Parietal alpha frequency causally changes temporal binding windows and sensitivity for both body-ownership and visuotactile-simultaneity judgments. Computational fitting links this manipulation to uncertainty in temporal evidence.

This is stronger than correlation:

```text
TemporalIntegrationPrecision
causally constrains
OwnershipInference
```

## Failure row B5 — ownership is not bodily-self totality

The model does not by itself reconstruct:

```text
agency
self-location
body schema/image
actual motor control
normative responsibility
clinical ownership attribution hierarchy
```

## Failure row B6 — target and prior specification remain architecture choices

A BCI model still needs declared:

```text
which signals
which body target
which structural priors
which reference frame
which scale
which decision/report mapping
```

Those are not supplied merely by saying `Bayesian`.

Verdict:

```text
BayesianCausalInferenceAsWholeBodilySelfOwner
= REJECT

BodyOwnershipCausalInferenceProjection
= STRONG SURVIVOR
```

This survivor is ownership-local and must face owner extraction in HD15-C.

# 5. Rival C — hierarchical part→whole ownership architecture

Core proposal:

```text
local ownership processes for body parts
→ nonlinear global combination
→ full-body ownership
→ top-down contextual modulation of parts
```

This is directly supported by the 2024 multi-part mannequin experiments.

## Positive row C1 — local ownership independence

Local synchrony primarily controls ownership of the stimulated part; local ownership can survive when full-body ownership is weak.

## Positive row C2 — nonlinear global combination

Full-body ownership rises nonlinearly with the number/configuration of coherently bound parts rather than as a simple linear sum.

## Positive row C3 — top-down global feedback

Full-body ownership predicts increased ownership of nonstimulated parts, establishing bidirectional local/global dependence.

## Positive row C4 — scrambled-body test

Synchronous movement of spatially scrambled hands/feet can induce part ownership without coherent full-body ownership, showing that global body structure imposes additional constraints.

## Failure row C5 — hierarchy is ownership-specific

Part→whole ownership does not explain by itself:

```text
agency
self-location
motor control
body-schema/image dissociation
intentional binding
clinical motor-awareness deficits
```

Verdict:

```text
HierarchicalPartWholeAsWholeBodilySelfOwner
= REJECT

PartWholeOwnershipIntegrationProjection
= STRONG SURVIVOR
```

# 7. Rival E — comparator / motor-prediction agency architecture

Core proposal:

```text
intention / motor command
→ predicted sensory consequence
compare with actual consequence
→ sense of agency
```

## Positive row E1 — active/passive agency separation

Moving-RHI paradigms show that voluntary control and congruent action feedback strongly support agency; passive matched movement can preserve ownership while removing agency.

## Positive row E2 — sensorimotor conflict carries implicit information

Kinematics and early neural responses encode sensorimotor conflict before or beyond explicit agency judgment.

## Positive row E3 — BMI preserves agency-relevant prospective state

Agency-related premovement sensorimotor states can predict later agency judgments even when ordinary limb execution is replaced by BMI-mediated action.

## Failure row E4 — prospective comparison is not sufficient

Outcome valence, context and retrospective causal evidence alter agency-related judgments/binding. Causal stimulation studies dissociate prospective and retrospective contributions.

## Failure row E5 — explicit agency can survive when binding does not

In a 2026 VR study, participants reported more explicit agency for active than passive actions even when the stationary avatar condition produced no standard intentional-binding effect. Making the avatar responsive restored binding only at short delay, without equivalently changing explicit agency.

Therefore:

```text
ComparatorEvidence
!= complete AgencyArchitecture
```

Verdict:

```text
ComparatorAsWholeAgencyOwner
= REJECT

ProspectiveAgencyEvidenceProjection
= RETAINED LOCAL MECHANISM
```

# 8. Rival F — prospective + retrospective cue-integration agency architecture

Core proposal:

```text
agency judgment/experience
= reliability-weighted integration of
  prospective motor/intention cues
  + outcome contingency
  + temporal relation
  + context / beliefs / priors
  + observed causal structure
```

This rival absorbs the strongest failures of comparator-only accounts.

## Positive row F1 — prospective and retrospective evidence can dissociate

Action selection contributes to agency before outcome knowledge; outcome information and valence contribute after the event.

## Positive row F2 — explicit and implicit surfaces differ

The 2026 responsive-avatar experiment shows that avatar motion congruency affects intentional binding under specific short-delay conditions while explicit agency remains primarily sensitive to active versus passive generation.

## Positive row F3 — vicarious agency

2025 VR work shows prior body ownership can support later vicarious agency and behavior even when actual control over the performing avatar is minimal. Therefore actual motor control is not necessary for every agency-like attribution.

## Failure row F4 — `cue integration` is not one semantic owner

To compute an agency judgment, the architecture consumes variables already owned by:

```text
World  actual causation
HF10   intention/choice where relevant
HF11   motor control/prediction
HF20   sensory/action feedback
HF8    self/action/outcome representation
HF3    monitoring/confidence/explicit judgment
HF2    phenomenal experience
HD12   temporal-estimation surface when binding is used
```

Verdict:

```text
AgencyCueIntegrationProjection
= STRONG SURVIVOR
!= HF24
```

Broad proposal:

```text

```

It can explain many positive rows:

```text

structural priors
uncertainty effects

```

But this breadth creates a destructive problem.

If the model is permitted to add arbitrary latent levels for:

```text
part ownership
whole ownership
agency
self-location
body schema
context
clinical syndrome
```

then almost any outcome can be post-hoc redescribed as a prediction-error or precision-weighting change.

Therefore the admissible form is only:

```text
PredictiveModel
= specified variables
+ specified generative dependencies
+ specified priors
+ specified likelihoods
+ specified readout
+ falsifiable cross-regime predictions
```

Once specified, its useful components largely reduce to the local survivors already identified.

Verdict:

```text
GenericPredictiveProcessingAsWholeOwner
= REJECT as underconstrained

= allowed implementation/model family
```

# 10. Rival H — enactive / sensorimotor-contingency architecture

Core proposal:

```text
bodily self emerges through active mastery of sensorimotor contingencies
```

## Positive row H1 — active noncorporeal ownership

Tight action-contingent mappings can expand ownership beyond normal corporeal appearance.

## Positive row H2 — responsive avatars support agency

Avatar responsiveness can create an implicit agency signature absent when the avatar is visually static.

## Positive row H3 — BMI and tools expand action coupling

Human-side agency can survive substantial transformation of execution channels.

## Failure row H4 — passive ownership

Robust ownership can occur under passive matched movement or classical passive visuotactile induction.

## Failure row H5 — no delivered action/touch required in some ownership regimes

Expectation of an approaching touch can induce ownership-related responses without actual tactile contact, undermining active contingency as a necessary condition.

## Failure row H6 — hemiplegia / lesion regimes

Ownership illusions can remain possible even when normal voluntary movement signals are absent, and ownership disturbances can arise from representational/integrative lesions rather than a simple failure of active mastery.

Verdict:

```text
EnactiveSensorimotorArchitecture
= IMPORTANT REGIME-SPECIFIC FAMILY
!= whole bodily-self owner
```
