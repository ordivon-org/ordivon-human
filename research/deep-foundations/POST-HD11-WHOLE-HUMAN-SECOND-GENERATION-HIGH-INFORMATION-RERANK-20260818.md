# 1. Method learned from the failed HF24 attempts

Post-HOC10 and HD11 established three reusable warnings:

```text
UsefulCrossOwnerGrammar
!= MissingFoundation

CommonComputationalShape
!= CommonSemanticOwner

DeepScientificProjection
!= PeerFoundation
```

Therefore a candidate gets high rank only if it has some combination of:

```text
R1 substantive Human-side state/process/relation not already owned;
R2 selective dissociation from nearest existing owners;
R3 recurrence across materially different regimes;
R4 deletion harm after full neighboring-owner allocation;
R5 dense cheap falsifiers / rival-model leverage;
R6 current evidence capable of changing the architecture;
R7 Agent-era pressure that tests rather than manufactures novelty;
R8 scope broad enough for a deep route without being a vague application domain.
```

A deep route does **not** need to pass the peer-Foundation gate.

# 4. Candidate C — psychopathology / altered states

Psychopathology remains one of the best **falsifier continents**.

Recent transdiagnostic studies show that psychiatric symptom dimensions can map differently onto:

```text
objective task performance
confidence / metacognitive efficiency
goal-directed/model-based inference
risk taking
effort/reward valuation
```

and that diagnostic categories need not correspond to one mechanism.

This is highly valuable because it pressures HF3/HF4/HF8/HF9/HF10/HF21 and HD10.

But the very success of transdiagnostic decomposition argues against:

```text
Psychopathology = one missing Foundation
```

Current best status:

```text
falsifier axis / perturbation continent
```

rather than owner.

Disposition:

```text
Falsifier information = VERY HIGH
```

# 13. 2025 latent-structure evidence attacks `one short clock + one long clock`

A 2025 Cognition study ran two experiments with N=302 each and interval reproduction spanning roughly 400–2400 ms.

Multiple latent-variable and changepoint analyses converged on:

```text
GeneralTimingFactor
+
CentralTendencyBiasFactor
```

rather than strong evidence for a clean discontinuity between separate subsecond and suprasecond clocks.

This establishes two important pressures:

```text
TimingPerformance
!= PureClockReadout
```

and:

```text
ObservedShortVsLongDifference
may reflect prior/context bias
rather than distinct timing systems.
```

# 14. 2026 duration → sequence → beat work attacks one flat timing ability

A 2026 Multisensory Research study tested:

```text
single-duration timing
nonbeat temporal sequence timing
beat-sequence timing
```

across auditory and visual modalities.

Result:

```text
auditory domain
→ evidence for a duration → sequence → beat hierarchy

visual domain
→ same hierarchy did not hold
```

Therefore:

```text
TimingAbility
!= one modality-invariant scalar
```

and:

```text
BeatPerception
!= DurationPerceptionByDefinition.
```

---

# 15. 2026 perceptual-vs-motor rhythm learning gives a selective dissociation

A 2026 experiment separated temporal structure in:

```text
visual perception + motor response
visual perception only
motor response timing only
```

Reliable rhythm learning appeared in visuomotor and visual-only conditions, but not when rhythmic structure was confined to motor timing.

This directly pressures:

```text
TemporalRhythmLearning
!= RepeatedMotorTimingByDefinition
```

and shows that HF11 motor timing cannot own the entire temporal domain.

---

# 16. ADHD provides a useful clinical non-monolithic pressure case

A 2026 adolescent ADHD study compared:

```text
duration discrimination
time reproduction over multiple intervals
53-second time estimation
```

and found selective time-reproduction differences rather than uniform impairment across every timing task.

Executive dysfunction/attention also related differently to specific timing measures.

Therefore:

```text
TemporalProcessingDeficit
!= one global timing loss
```

and:

```text
TimingTask_D
!= TimingTask_E
```

without evidence linking them.
