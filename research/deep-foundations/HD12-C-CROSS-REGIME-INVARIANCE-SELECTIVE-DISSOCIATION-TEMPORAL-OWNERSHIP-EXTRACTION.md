# HD12-C — Cross-Regime Invariance, Selective Dissociation & Temporal Ownership Extraction

## 0. Entry

HD12-B rejected both extremes:

```text
one global timing mechanism
```

and:

```text
no shared temporal structure at all
```

It left three possible common-core residues:

```text
R1 Abstract temporal relation representation
R2 Context-sensitive temporal calibration under uncertainty
R3 Shared temporal precision/noise across some contexts
```

C asks:

> Do these residues jointly define a peer Human timing owner after HF8/HF20/HF3/HF7/HF11 are fully restored, or are they owned projections plus narrow timing mechanisms?

C's answer is:

```text
Peer cross-domain timing owner
= NOT ESTABLISHED
```

---

# 1. Ownership extraction rule

C does not ask whether timing mechanisms are real.

It asks whether one peer semantic owner is required across materially different temporal targets.

Therefore:

```text
RealTimingMechanism
!= PeerTimingFoundation
```

and:

```text
CrossTaskCovariance
!= CommonSemanticOwnerByDefinition
```

---

# 2. Cerebellar degeneration gives a first decisive split

In auditory timing, cerebellar degeneration selectively impairs:

```text
absolute duration-based timing of single subsecond intervals
```

while leaving comparatively preserved:

```text
relative timing of rhythmic sequences using a regular beat
```

Thus:

```text
AbsoluteIntervalTiming
!= BeatBasedRelativeTiming
```

not only by task design but by lesion regime.

---

# 3. Cerebellar perturbation replicates the split causally

Medial cerebellar cTBS selectively worsens single-interval timing while sparing beat detection/deviation tasks in the tested design.

Therefore:

```text
CerebellarContribution_absolute
!= CerebellarContribution_beat
```

This narrows any common owner claim.

---

# 4. Cerebellum versus Parkinson's disease yields a true double dissociation

A visual temporal-orienting study compared:

```text
single-interval temporal prediction
vs
rhythmic temporal prediction
```

Cerebellar degeneration:

```text
single-interval cue benefit = impaired
rhythm cue benefit = preserved
```

Parkinson's disease:

```text
single-interval cue benefit = preserved
rhythm cue benefit = impaired
```

Therefore:

```text
SingleIntervalTemporalPrediction
!= RhythmicTemporalPrediction
```

with causal/pathological cross-regime support.

This is one of C's strongest ownership falsifiers.

---

# 5. The double dissociation defeats a unified timing-process interpretation

A peer timing owner could still contain multiple mechanisms.

But then the surviving common semantic object must do explanatory work beyond:

```text
both concern temporal relations
```

The cerebellar/Parkinsonian split shows that:

```text
interval prediction
rhythmic prediction
```

can be selectively implemented and selectively impaired.

Their commonality may therefore live at representational/task abstraction rather than one process architecture.

---

# 6. Parkinsonian action duration dissociates from interval duration

In Parkinson's disease under selected treatment conditions, participants can:

```text
accurately reproduce ordinary time intervals
```

while:

```text
under-reproducing duration of their own actions
```

Thus:

```text
ActionDurationReproduction
!= IntervalDurationReproduction
```

and:

```text
MotorTime
!= GenericIntervalTime
```

HF11 remains a required action-timing owner.

---

# 7. Parkinsonian timing is itself context-dependent

Other Parkinsonian studies show deficits in:

```text
beat-based rhythm discrimination
rhythmic temporal prediction
some interval sensitivity measures
intersensory temporal processing
```

but not uniformly across every beat, interval or perceptual timing task.

Dopaminergic medication can alter some rhythm comparisons while leaving Beat Alignment Test performance comparatively unaffected.

Therefore:

```text
ParkinsonTimingDeficit
!= OneBasalGangliaClockLoss
```

---

# 8. Beat-deaf poor synchronizers separate perception from action mapping

Some poor synchronizers show:

```text
normal detection of small duration deviations
normal rhythm discrimination
```

while being unable to synchronize reliably to musical beat.

This supports:

```text
BeatPerception
!= AuditoryMotorBeatMapping
!= MotorSynchronization
```

The deficit can lie between temporal representation and action execution.

---

# 9. Reverse beat-deaf cases strengthen the separation

Other beat-deaf cases show:

```text
poor explicit beat tracking
+
relatively preserved synchronization
```

suggesting implicit temporal pathways can support movement even when explicit beat judgment is poor.

Therefore:

```text
ExplicitBeatJudgment
!= ImplicitBeatSupportForAction
```

and:

```text
BeatRepresentationAccess_D
!= BeatRepresentationAccess_E
```

without evidence of identity.

---

# 10. Beat processing therefore decomposes

At minimum separate:

```text
rhythmic sensory evidence
beat extraction/prediction
explicit beat judgment
implicit beat availability
beat imagery
motor mapping
motor synchronization
```

No single one of these can be treated as `beat ability` without qualifiers.

---

# 11. ADHD supplies a task-selective pressure case

2026 adolescent evidence finds selective group differences in several time-reproduction intervals while:

```text
duration-discrimination threshold
and
53-second estimation
```

were not uniformly impaired.

Executive dysfunction and attention related differently to different timing measures.

Therefore:

```text
ADHDTimingDifference
!= GlobalTimingMechanismDeficit
```

and:

```text
ReproductionDeficit
can include HF3/HF11/task-readout contributions.
```

---

# 12. Older ADHD evidence points toward support-process ownership

Older child/adolescent work similarly found stronger deficits for longer intervals with preserved short-interval judgments and preserved pitch discrimination, interpreting the pattern as impaired utilization of temporal information possibly involving working memory/strategy rather than one central clock.

Thus clinical labels do not identify timing owners.

---

# 13. Aging shows task-specific temporal change

Large within-subject audiovisual work found older adults had broader/poorer temporal-order and causal-binding performance while simultaneity judgment remained comparatively preserved.

Therefore:

```text
AgeEffect_TOJ
!= AgeEffect_SJ
```

and aging does not produce one uniform temporal-processing decrement.

---

# 14. aMCI gives a direct clock-versus-memory dissociation

Amnestic mild cognitive impairment participants show stronger regression toward the mean in multi-duration reproduction.

Crucially:

```text
clock-time variability
```

did not differ between groups and did not explain the increased central tendency.

The stronger bias is better explained by memory impairment increasing relative reliance on prior/context.

Therefore:

```text
CentralTendencyIncrease
!= ClockNoiseIncreaseByDefinition
```

and:

```text
HF7MemoryState
can alter measured timing bias
without a changed clock parameter.
```

---

# 15. Cerebellar lesions separate timing from generic WM/attention support

Classic focal-lesion work compared neocerebellar and prefrontal patients.

Prefrontal patients showed longer-duration timing deficits alongside working-memory/attention/strategy deficits.

Cerebellar patients showed more pervasive timing deficits that were less responsive to strategic support and not readily explained by general WM/attention measures.

This supports a real **local interval-timing mechanism** independent of generic HF3 support.

But:

```text
LocalTimingSpecificity
!= CrossDomainTimingOwner
```

because cerebellar absolute timing is itself dissociated from rhythm timing.

---

# 16. Cerebellar lesion literature is not perfectly uniform

Other lesion studies report:

```text
reproduction/production impairment
with relatively preserved discrimination
```

or task-/lesion-location-specific patterns.

Children treated for cerebellar medulloblastoma can show reproduction differences strongly associated with processing speed rather than a clean perceptual-time deficit.

Therefore C does not promote:

```text
Cerebellum = master clock
```

from one lesion family.

C accepts the **representational inference** provisionally.

This is exactly what the cross-modal/interval transfer evidence is compatible with.

|---|---|---|
