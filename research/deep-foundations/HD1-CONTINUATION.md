# 1. Deep result

Perception is not retained as a passive `World → Percept` arrow.

The minimum grammar is:

```text
World / distal source
↔ body + sensor pose + sampling policy
→ proximal physical signal
→ transduction
→ sensory evidence
→ perceptual organization
→ perceptual state/content
→ possible experience / attention / memory / recognition / action
→ changed sampling/world
↺

history/development update the loop
```
