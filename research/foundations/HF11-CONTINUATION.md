# Human Foundations Continuation after HF11

## HF11 completed result

HF11's minimum situated-action grammar is:

```text
Goal / Selected Policy / Plan
        ↓
Action Goal / Intended Effect
        ↓
Action Selection
        ↓
Motor Preparation
        ↓
Initiation / Release
        ↓
Control Policy / Commands
   ↙ predictive/feedforward       ↘
Estimated Body/World State ← Sensory Feedback
        ↓                         ↑
Effector / Tool / Robot Movement
        ↓
Task / Environmental Effect
        ↓
Reward / Consequence
        ↓
Typed Error Signals
        ↓
Online Correction + Adaptation + Skill Learning
        ↺
```

## Action / execution

Retain:

```text
Action != Choice
Action != Intention
Action != Movement
Movement != TaskOutcome
TaskOutcome != RewardOutcome
ActionGoal != MotorCommand
MotorCommand != MovementTrajectory
MovementTrajectory != ActionIdentity
VoluntaryAction != ConsciousControlOfEveryCorrection
```

One action goal can be realized through many movements, and one movement can have
different action meanings depending on goal/context.

## Action-effect / ideomotor control

Retain action-effect anticipation as a major control family:

```text
anticipated effect
→ can bias/select/initiate learned action
```

but preserve:

```text
ActionEffectRepresentation != Action
IdeomotorEffect != UniqueAssociativeMechanismProof
GoalRepresentation != MovementRepresentation
ActionControl != IdeomotorControlOnly
```

Associative, causal/propositional and event-file accounts remain competing models.

## Preparation / initiation / volition

Retain:

```text
Intention != MotorPreparation
MotorPreparation != Initiation
Commitment != Initiation
Initiation != Continuation
MovementInitiation != SenseOfVolition
ReadinessPotential != Intention
InitiationFailure != GoalAbsence
```

StartReact, Parkinsonian freezing/akinesia and voluntary-action evidence are key
falsifiers against a simple conscious-intention trigger model.

## Praxis

Apraxia provides a strong competence/production boundary:

```text
ActionKnowledge != SkilledActionExecution
Strength != PraxisCapability
GestureImitation != GoalDirectedExecution
GoodPerformanceWithVision != IntactUnaidedControl
```

`Apraxia` is not one mechanism; conceptual, sequencing, production and dexterity
components can dissociate.

## Motor abundance / equivalence

Retain:

```text
SameActionGoal != SameMovementTrajectory
SameTaskOutcome != SameCoordinationPattern
MovementVariability != Noise
ZeroVariability != PerfectControl
MoreMotorVariability != BetterFlexibility by definition
ActionType != CanonicalTrajectory
```

Goal-equivalent versus non-goal-equivalent variability is more informative than
total movement variance.

## Predictive / feedback control

Retain competing/complementary model families while rejecting total collapse:

```text

MotorControl != FeedforwardOpenLoopProgram

OnlineMotorCorrection != ConsciousAwareness
OnlineCorrection != ExplicitReplanning
PhysicalState != EstimatedState
ProprioceptiveEstimate != ExactBodyState
```

Feedback modality/latency and task relevance must be preserved.

## Typed error grammar

## High-information falsifiers to preserve

- action-effect anticipation facilitating learned actions while associative and
  propositional accounts remain rivals;
- prepared movement released by startling input;
- Parkinson freezing/akinesia despite clear goal/intention;
- preserved conceptual action/tool knowledge with severe apraxic execution deficit;
- gesture imitation versus visually guided movement dissociations;
- goal-equivalent movement/joint variability preserving outcome;
- motor execution contributing to speed–accuracy tradeoff;
- rapid online correction without conscious perturbation detection;
- visuomotor adaptation shifting proprioceptive estimates;
- sensory/perceptual prediction, task and reward errors dissociating;
- explicit/implicit adaptation measures failing simple additive assumptions;
- skill learning differing from perturbation adaptation;
- strong motor learning with persistent dual-task attention costs;
- tool-use-driven recalibration/body-schema changes without identity/parthood;
- person-plus-object affordance recalibration;
- bimanual performance depending on coupling rather than individual limb quality;
- interpersonal coordination through explicit communication or action
  predictability;
- teleoperation delay producing strategy change and performance degradation;
- real-time haptic feedback mitigating some delayed visual-control costs;
- autonomous robot stabilization with Human tactical override;
- nominal Human-in-loop failing to establish meaningful control;
- high-level machine delegation generating lower-level actions and altered realized
  behavior.

## Exact next foundation

HF11 can model a single embodied controller, a Human+tool system and layered
Human–machine control. It breaks at the same point across interpersonal movement,
joint tasks and AI teamwork:

```text
another participant is an independently modeling agent
```

with distinct:

```text
beliefs
perception
goals/subgoals
attention
capabilities
roles
authority
communication state
```

Pure sensorimotor coupling cannot explain misunderstandings, role allocation,
shared goals, communication, repair or cooperation.

Therefore the exact next round is:

# HF12 — Social Interaction, Joint Action, Communication, Shared Goals, Roles and Cooperation

## HF12 starting questions

1. What is interaction relative to co-presence, influence and reciprocal coupling?
2. What is joint action relative to parallel action and sensorimotor coordination?
3. What is a shared goal relative to identical individual goals?
4. What is joint intention/commitment relative to individual intention?
5. What is communication relative to signaling, information transfer and action?
6. How do speech, gesture, gaze and action-based signaling differ?
7. What is common ground/shared representation, and can it be partial/false?
8. What is role relative to task assignment, authority and responsibility?
9. What is cooperation relative to coordination, competition and prosociality?
10. How do turn-taking, prediction, signaling and repair stabilize interaction?
11. How do dependence/trust/uncertainty about another agent alter joint action?
12. How should Human×AI joint action distinguish tool use, delegation,
    supervision, teaming and social interaction?
13. When does a group/joint system have capability not attributable to any one
    member?
14. What next boundary emerges after relational multi-agent action is rebuilt?

## Candidate HF12 falsifiers

- spontaneous synchrony without shared goal;
- shared goal without synchronous movement;
- same individual goals versus genuine joint-task commitment;
- coordination through action predictability when explicit communication is absent;
- communication reducing need for behaviorally constrained predictability;
- implicit action-based signaling versus speech/gesture;
- asymmetric-information joint action;
- dynamic role allocation/switching;
- coordination failure from common-ground mismatch;
- explicit repair after misunderstanding;
- cooperative versus competitive coordination with similar motor structure;
- individual versus collective sense of agency;
- Human×AI teaming versus tool use/delegation/supervision;
- joint success despite weak individual capability and joint failure despite strong
  individual capability.

## Do not precommit

HF11 does not establish that:

- coordination implies cooperation;
- synchrony implies shared goal;
- shared goal requires explicit language;
- communication is information transmission only;
- common ground is literally identical representation;
- joint action requires identical goals or roles;
- cooperation implies altruism;
- Human×AI teamwork is socially equivalent to Human×Human teamwork;
- trust is one scalar;
- group capability is the sum of member capabilities.

## Stop rule

Do not schedule HF13 now. HF12 must expose a repeated neighboring distinction whose
absence creates category failures across materially different social/joint-action
cases.
