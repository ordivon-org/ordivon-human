# Human Foundations Continuation after HF2

## HF2 completed result

HF2 rejects unqualified `Consciousness` as one scalar primitive and retains:

```text
Experience(subject, content, t)
GlobalStateProfile(subject,t)
Connectedness(subject,environment,t)
Responsiveness_type(subject,input,t)
AvailableFor_D(content,subject,t)
Reportable(content,channel,conditions)
Report(event)
Recall(content,t2 | event at t1)
EvidenceBundle(claim)
```

The central methodological result is:

```text
Phenomenon != Evidence != Inference != Theory
```

and evidence is often asymmetric:

```text
specific positive command-following evidence
can strongly support connected cognitive processing

but

no detected response
usually has many possible downstream failure paths
```

so:

```text
NoDetectedResponse != NoExperience
```

without validated sensitivity and scope.

## Awareness

HF2 does not retain `Awareness` as one free-standing primitive.

Use qualified forms such as:

```text
PerceptualAwareness
EnvironmentalAwareness
BodyAwareness
SelfAwareness
MetaAwareness
```

and state the evidence/operation used.

## Conscious state

HF2 rejects one-dimensional `level of consciousness` as a default foundation
ontology. A multidimensional state profile is safer:

```text
[
  Wakefulness,
  ExperientialEvidence,
  Connectedness,
  ContentProperties,
  AvailabilityProfile,
  ResponsivenessProfile,
  ReportChannelState,
  EncodingRecallProfile,
  MetacognitiveEvidence
]
```

This is a research coordinate set, not a mandatory personal profile.

## Downstream availability

```text
AvailableFor_D(C,S,t)
```


without evidence linking the two downstream functions.

## High-information falsifiers to preserve

- REM and NREM experience reports;
- awakenings with no remembered experience;
- anaesthesia isolated-forearm command following;
- command following without later explicit recall;
- anaesthesia EEG pattern coexisting with volitional response;
- cognitive motor dissociation in DoC;
- negative imaging task despite bedside command response;
- infant late neural responses under nonverbal conditions;
- blindsight objective discrimination with altered/absent ordinary visual report;
- type-II blindsight / degraded awareness;
- P3b disappearing when report requirements are removed;
- no-report proxy confounds;
- attribute amnesia;
- theory-adversarial tests that challenge predictions of multiple leading
  consciousness theories.

## Exact next foundation

HF2 cannot explain `AvailableFor_D` without decomposing the mechanisms that make
content selectively usable.

The repeated residual is:

```text
Attention
Access
Working Memory
Metacognition
Confidence
Cognitive Control
```

These appear across no-report paradigms, blindsight, attribute amnesia,
command-following tasks, report generation and state/content selection.

Therefore the next round is:

# HF3 — Attention, Access, Working Memory, Metacognition, Confidence and Cognitive Control

## HF3 starting questions

1. `Attention` selects what—sensory evidence, representation, processing
   resources, action priorities, or all of these under different mechanisms?
2. Is attention necessary or sufficient for conscious experience?
3. What should `access` mean after HF2 rejects one global availability variable?
4. When does conscious content enter working memory, and when can working-memory
   operations use weak/unreported content?
5. How does reportability depend on working memory versus current experience?
6. What is metacognitive access, and how does it differ from first-order task
   performance?
7. How should confidence be separated from accuracy, evidence strength and
   experience quality?
8. Can metacognitive sensitivity be impaired while first-order performance is
   preserved, or vice versa?
9. How do task relevance and cognitive control alter neural signatures usually
   attributed to consciousness?
10. Which forms of automatic action guidance require neither report nor
    metacognitive access?
11. How does Human attention relate to Media MF2 attention without importing a
    perception-only ontology?
12. What residual boundary does HF3 expose naturally?

## Candidate HF3 falsifiers

- inattentional blindness;
- attentional blink;
- divided-attention paradigms;
- blindsight plus confidence/metacognition measures;
- attribute amnesia;
- no-report versus report task relevance;
- working-memory tasks with masked/weakly conscious inputs;
- metacognitive impairment with preserved first-order performance;
- confident errors and low-confidence correct performance;
- automatic action guidance without explicit report.

## Do not precommit

HF2 does not establish that:

- attention is consciousness;
- attention is necessary for all conscious experience;
- attention is sufficient for consciousness;
- working memory is necessary for all experience;
- conscious experience automatically enters durable working memory;
- above-chance performance proves metacognitive access;
- confidence is a direct consciousness scale;
- metacognition is one scalar trait;
- PFC activity equals access;
- no-report paradigms eliminate attention/task effects;
- one theory of access should own HF3.

## Stop rule

Do not schedule HF4 now. HF3 must expose a repeated neighboring distinction whose
absence creates explanatory failures across materially different Human cases.
