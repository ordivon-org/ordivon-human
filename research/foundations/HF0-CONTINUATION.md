# Human Foundations Continuation after HF0

## HF0 completed result

HF0 rejects a flat subsystem taxonomy as the complete Human foundation and
retains a question-relative projection architecture.

```text
HumanReality
+ Projection
+ Scale
+ Timescale
+ EvidencePosition
+ ModalRole
+ NormativeStatus
+ Boundary
```

The legacy H0 Atlas remains a useful functional view library, but its categories
are no longer presumed to be peer ontological primitives.

## Strongest retained reclassifications

```text
Body
→ indispensable organism/embodiment projection

Cognition
→ family of information/learning processes, split-capable

Emotion/Motivation
→ useful temporary cluster, not one primitive

Identity & Values
→ must split; self/persistence and value/commitment are different problems

Capability
→ relational ability under declared actor/state/task/support/context conditions

Behaviour
→ action/performance/observation surface

Relationships / Institutions / Technology
→ first-class causal projections when they change options, action or trajectory

Time / History
→ required coordinate and sometimes present causal structure
```

## HF0 durable anti-collapses

Preserve at minimum:

```text
Human != profile
Human != current state
Human != Person != Self != Agent as interchangeable terms
Experience != report != behaviour != physiology
Belief != knowledge != truth
Need != desire != preference != goal != commitment != value
Intention != action != effect
Objective control != sense of agency != autonomy
Capacity != performance
Independent skill != situated capability != joint-system capability
Resource != option != capability != effect != outcome
Physical possibility != institutional permission
Current adaptation != normative desirability
Population average != individual state/effect
Prediction != causal explanation
Description/prediction != normative or legal authority
```

## Exact next round

HF0 repeatedly fails to proceed without a clearer boundary among:

```text
Human
Organism
Body
Subject
Self
Person
Actor
Agent
```

and without asking what persists when body state, consciousness, memory, role,
tool coupling or agency changes.

Therefore the next foundation round should be:

# HF1 — Human Boundary, Organism, Body, Subject, Self, Person, Actor and Agent

HF1 should **not** become a generic philosophy chapter. It should use the same
foundation protocol:

1. separate biological Human membership from person/self/agent terminology;
2. distinguish organism boundary, body representation and experienced body
   ownership;
3. distinguish experiencing subject, reflective self, narrative/social identity
   and legal/normative personhood;
4. distinguish actor and agent roles from Human identity;
5. test persistence through sleep, anaesthesia, infancy, amnesia, major role
   change and tool/prosthetic/AI coupling;
6. test whether ordinary tool extension changes capability, control locus,
   embodiment, self-boundary, personal identity, or only the coupled task system;
7. audit descriptive versus normative personhood claims explicitly;
8. retain competing identity/persistence models if the evidence does not select
   one;
9. end by exposing HF2 rather than planning it in advance.

## Candidate falsifiers for HF1

- same organism, radically different conscious state;
- infant before mature narrative identity;
- amnesia or large autobiographical-memory disruption;
- body-ownership illusion without biological-body change;
- prosthetic/tool embodiment with variable felt ownership;
- remote/delegated action with control but no direct motor execution;
- software Agent with no biological humanity;
- legal person that is not a biological human;
- team/joint system whose capability exceeds one participant;
- persistent person under changed social role, institution or technology.

## Do not precommit

HF0 does not establish that:

- biological continuity alone resolves personal identity;
- psychological continuity alone resolves personal identity;
- first-person continuity is measurable by one test;
- body ownership defines body membership;
- tools become part of the person when they become part of capability;
- `person` should be defined only descriptively;
- Human and Agent will require the same foundations.

## Research stop rule

Do not create HF2 merely because HF1 is complete. HF1 must end by naming a
neighboring distinction whose absence causes repeated explanatory failure across
materially different Human cases.
