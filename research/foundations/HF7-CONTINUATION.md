# Human Foundations Continuation after HF7

## HF7 completed result

HF7 replaces one unitary memory variable with:

```text
History / Experience
       ↓
Encoding / Induction
       ↓
Persistent availability / retained change
       ↓
Consolidation / reorganization / updating
       ↓
Retrieval ecology
  ├─ cue
  ├─ context
  ├─ internal state
  ├─ goal
  ├─ competing histories
  ├─ retrieval policy
  └─ external support
       ↓
Retrieved / reconstructed content or policy
       ↓
Expression channel
       ↓
Confidence / source judgment / action
```

Retrieval feeds back into future memory state.

## Retrieval as intervention

HF7 preserves two opposite retrieval effects:

```text
RetrievalPractice
→ can strengthen later target retention

CompetitiveRetrieval
→ can reduce later accessibility of related competitors
```

Therefore memory testing is not always observationally neutral.

## Memory evidence asymmetry

```text
Successful retrieval
→ positive evidence for some retained history under current task

Failed retrieval
→ ambiguous among encoding, retention, cue, context, state, interference,
   strategy and response failure
```

Hence:

```text
NoRetrieval != NoMemory
```

without stronger evidence.

## Constructive retrieval

False-memory and reminder-updating evidence establishes:

```text
retrieval output
can reflect
retained history + cue + semantic/schema relations + source inference + current
context
```

without establishing that every memory is unreliable.

DRM word-list findings must not be generalized directly to autobiographical or
trauma-memory claims.

## External / joint memory

HF7 distinguishes:

```text
HumanInternalMemory
ExternalMemorySupport
JointMemoryCapability
```

External reminders can improve future action without proving stronger internal
retention. Tool/AI memory adds provenance, integrity, availability and dependency
failure modes.

## High-information falsifiers to preserve

- retrieval practice improving delayed retention;
- retrieval-induced forgetting of related competitors;
- amnesia with preserved mirror-reading/mirror-tracing skill;
- amnesia with preserved priming despite recognition impairment;
- recollection/familiarity differences in recognition;
- item recognition with poor source/temporal-order memory;
- context/state-sensitive retrieval plus the failed direct replication of the
  classic diver context effect;
- extinction followed by return of responding;
- reminder-dependent integration/intrusions plus temporal-context alternative
  models;
- high-confidence DRM false recall/recognition;
- prospective-memory failure despite knowing the intended action;
- implementation intentions as future retrieval-cue engineering;
- reminders/offloading improving situated success without equivalent internal
  retrospective-memory gain;
- aging effects differing across recall, recognition, recollection and order;
- savings/relearning after apparent loss of current performance.

## Exact next foundation

HF7 can explain why history persists or fails to express, but it repeatedly treats
retrieved `content` as an unexplained primitive.

The residual questions are:

```text
What is represented?
What does representation mean?
When is remembered content believed?
When is belief knowledge?
What makes a concept/schema support generalization?
How can memory be true/false/source-free?
What distinguishes memorization from understanding?
```

Therefore the exact next round is:

# HF8 — Representation, Knowledge, Belief, Concept, Schema, Mental Model and Understanding

## HF8 starting questions

1. What is a representation relative to its vehicle/implementation and its
   content/referent?
2. Must Human representation be symbolic, structural, predictive, action-oriented,
   or can these be different forms?
3. What is knowledge relative to memory, truth, belief, justification/reliability,
   skill and capability?
4. What is `knowing-that` relative to `knowing-how` after the HF7 amnesia
   dissociations?
5. What is belief relative to endorsement, expectation, confidence, memory and
   habitual action?
6. Can contradictory beliefs/models coexist without one being currently endorsed?
7. What is a concept relative to category membership, prototype, exemplar,
   feature relation and action policy?
8. What is a schema and how does it support compression/generalization while also
   producing reconstruction/bias?
9. What is a mental/world model relative to a belief set, transition model,
   simulator or prediction system?
10. What is understanding relative to recall, explanation, prediction,
    counterfactual simulation, transfer and intervention?
11. How should source/provenance and evidence strength constrain knowledge claims?
12. What is epistemic confidence relative to metacognitive confidence and actual
    truth/calibration?
13. How do external search/AI systems extend knowledge access without automatically
    internalizing Human understanding?
14. What next boundary is forced after representation/knowledge/understanding are
    separated?

## Candidate HF8 falsifiers

- knowledge without episodic source memory;
- procedural skill without declarative explanation;
- false memory with high confidence;
- source-monitoring errors;
- semantic priming and semantic generalization;
- prototype/exemplar/category-learning dissociations;
- schema-consistent memory distortion;
- memorization with weak novel transfer;
- explanatory-depth illusion;
- expert performance with incomplete explicit rule report;
- belief perseverance and evidence updating;
- misinformation correction/backfire boundary cases;
- calibrated versus miscalibrated epistemic confidence;
- external search/AI answer access followed by tool removal and explanation tests.

## Do not precommit

HF7 does not establish that:

- representation is one neural object;
- content is identical to implementation;
- knowledge is simply retained memory;
- knowledge is exhausted by justified-true-belief language;
- belief always requires conscious endorsement;
- confidence is belief strength;
- a concept is one prototype or one exemplar;
- schemas are always beneficial;
- mental models are always explicit or verbalizable;
- understanding is recall accuracy;
- understanding requires complete explanation;
- successful transfer alone proves understanding;
- external answer access is Human knowledge;
- AI assistance necessarily increases or decreases internal understanding.

## Stop rule

Do not schedule HF9 now. HF8 must expose a repeated neighboring distinction whose
absence creates failures across materially different representation/knowledge
cases.
