# HF16 External Evidence and Source Ledger

## Evidence rule

HF16 separates four evidence roles:

```text
Normative/philosophical primary argument
= candidate aggregation/population principle and counterexample

Formal social-welfare/population result
= theorem/axiomatic consequence conditional on stated assumptions

Empirical moral/social-choice evidence
= how people actually judge population, creation, future and extinction cases

Economic discounting model/evidence
= consequences of explicit discount/risk/growth assumptions
```

None is automatically normative truth.

```text
FormalTheorem != MoralTheoryWinner
EmpiricalPreference != PopulationEthicsTruth
EconomicDiscountRate != MoralWeightByDefinition
```

- DOI: 10.1093/019824908X.003.0016

- Use: primary formulation of identity-affecting future-person cases, including same

```text
SamePeopleComparison != DifferentPeopleComparison
```

# 42. Aggregation literature disagreement is substantive

The direct dispute between Voorhoeve's partial aggregation and Halstead's defense of
full aggregation shows:

```text
SameCanonicalCases can support competing normative interpretations
```

This is a primary reason HF16 does not collapse the question into arithmetic.

# 43. Formal population ethics does not converge on one paradox-free rule

Arrhenius's impossibility theorem and Spears/Budolfson's generalized repugnant-
conclusion result jointly support the methodological conclusion:

```text
AvoidingOneCounterexample != TheorySelectionProcedure
```

This is not a claim that all theories are equally good.
