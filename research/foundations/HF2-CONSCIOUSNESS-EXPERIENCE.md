# HF2 — Experience, Consciousness, Awareness, Wakefulness, Connectedness,
# Responsiveness, Reportability and Recall

## 0. Status and question

HF2 continues directly from HF1's unresolved `ExperientialSubject` boundary.

HF1 established:

```text
HumanIndividual
!= current consciousness
```

and retained:

```text
Wakefulness
!= ConsciousExperience
!= ConnectedConsciousness
!= WholeBodyResponsiveness
!= Reportability
!= LaterRecall
```

HF2 asks:

> **What minimum distinctions are needed to study conscious Human experience
> without defining it by wakefulness, behaviour, report, memory, one neural
> marker or one favoured theory?**

HF2 is not a solution to the philosophical hard problem, not a consciousness
meter, not a clinical diagnostic rule, and not a personhood test.

Its goal is narrower and more operational: stop the consciousness vocabulary
from collapsing distinct phenomena, capacities and evidence channels.

---

# 1. The first problem: `consciousness` names several questions

The word `consciousness` is commonly used for at least:

```text
whether any experience is present
what is being experienced
how awake/aroused the organism is
whether experience concerns the external environment
whether information guides behaviour
whether a command can be followed
whether content can be selected for report
whether the subject can judge/confidently evaluate the content
whether the content is encoded and later recalled
which neural mechanisms support any of the above
```

These are not equivalent.

HF2 therefore does **not** retain unqualified `Consciousness` as one scalar
foundation variable.

Instead it introduces a grammar that binds:

```text
ExperientialPresence
ConsciousContent
GlobalStateProfile
Connectedness
Availability
Responsiveness
Report
Memory
EvidenceChannel
Uncertainty
```

---

# 2. Working primitive: Experience

HF2 uses `Experience` as its least committal first-person phenomenon term.

Working definition:

```text
Experience(subject, content, t)
= some content is phenomenally present for that subject at time t
```

or more compactly:

```text
E(S, C, t)
```

HF2 does not derive this from report, behaviour or neural activity.

It also does not assert a metaphysical substance called `experience`.

The operator simply marks the phenomenon scientific evidence is trying to
constrain.

## 2.1 Why Experience is not defined by report

A report is a downstream action that can require:

- maintaining content;
- interpreting the question;
- selecting an answer;
- motor/language execution;
- memory;
- motivation/cooperation.

Therefore:

```text
Experience != Report
```

## 2.2 Why Experience is not defined by recall

An experience can fail to be durably encoded, retained or retrievable.
Anaesthesia and attribute-amnesia evidence show that later memory is not a
transparent record of all prior processing or experience.

Therefore:

```text
Experience != LaterRecall
```

## 2.3 Why Experience is not defined by behaviour

Behaviour can be:

- reflexive;
- habitual;
- unconscious/automatic;
- constrained by motor impairment;
- absent despite covert cognitive processing.

Therefore:

```text
Experience != BehaviouralResponsiveness
```

---

# 3. Experiential presence versus content

HF2 separates two basic questions.

## 3.1 Presence question

```text
Exists C such that E(S,C,t)?
```

Informally:

> Is there any experience present?

## 3.2 Content question

```text
What C satisfies E(S,C,t)?
```

Informally:

> What is experienced?

These questions can require different evidence.

A neural/behavioural measure might support that some organized conscious state
is present without revealing its exact content. Conversely, a content-specific
response can support one content inference without measuring the entire global
state.

Therefore:

```text
ConsciousPresence != ConsciousContent
```

as research claims.

---

# 4. `Awareness` is qualifier-required

HF2 does not retain `Awareness` as an additional primitive beside Experience.
The word is too overloaded.

Instead technical usage should say what kind of awareness is intended.

Examples:

```text
PerceptualAwarenessOf(stimulus)
EnvironmentalAwarenessOf(context)
BodyAwarenessOf(state)
SelfAwarenessOf(self-property)
MetaAwarenessOf(mental-state)
SituationAwarenessOf(task-world)
```

These can differ in mechanism, content and evidence.

Thus:

```text
Awareness
without qualifier
= vocabulary warning
```

not a foundation variable.

This avoids replacing one undefined word (`consciousness`) with another
(`awareness`).

---

# 5. Wakefulness / arousal

HF2 uses `Wakefulness` for a global organismic/behavioural state associated with
arousal and readiness for ordinary interaction.

It can be indexed by combinations of:

- sleep/wake physiology;
- spontaneous eye opening;
- motor tone/activity;
- behavioural state;
- arousal systems.

But wakefulness is not the experience itself.

Dreaming supplies the canonical falsifier:

```text
low ordinary environmental wakefulness
+ conscious experience
```

Disorders of consciousness supply the reverse pressure:

```text
eye opening / wake-like cycles
without reliable evidence of ordinary connected awareness
```

Therefore:

```text
Wakefulness != ExperientialPresence
```

and:

```text
Arousal != Content
```

---

# 6. Connectedness

HF2 retains the anaesthesia literature's useful distinction between experience
and **connectedness**.

Working definition:

```text
Connectedness(S, World, t)
= current experiential/cognitive contents are sufficiently coupled to the
  external environment to represent and potentially respond to relevant
  external events
```

The word `sufficiently` is task-relative and must be operationalized.

## 6.1 Disconnected conscious experience

Dreaming demonstrates:

```text
Experience = present
ExternalConnectedness = reduced/altered
```

So:

```text
Conscious != ExternallyConnected
```

## 6.2 Connected consciousness under anaesthesia

Isolated-forearm command following shows that intended general anaesthesia and
ordinary whole-body unresponsiveness can coexist with evidence of external
command processing and volitional response.

Therefore:

```text
WholeBodyUnresponsiveness
!= Disconnectedness
```

## 6.3 Connectedness is graded and content-specific

A subject may be connected to:

- speech but not pain;
- pain but not command meaning;
- one sensory stream but not another;
- a narrow task context but not ordinary situation understanding.

HF2 therefore rejects a universal binary `connected/disconnected` absent a
declared channel and criterion.

---

# 7. Responsiveness must be typed

`Responsive` is also overloaded.

HF2 separates at least:

```text
R_reflex
R_stimulus
R_goal-directed
R_command
R_volitional
R_communicative
```

## 7.1 Reflex responsiveness

A stimulus produces a reliable response without evidence of intentional
selection.

## 7.2 Stimulus-sensitive responsiveness

Behaviour changes systematically with a stimulus, possibly without report or
acknowledged awareness.

## 7.3 Goal-directed responsiveness

Action varies adaptively with task goals or consequences.

## 7.4 Command following

A response is contingent on understanding and following an instruction.

## 7.5 Volitional responsiveness

Behaviour or neural activity is intentionally modulated according to a selected
instruction or goal.

## 7.6 Communicative responsiveness

Responses are used to convey information such as yes/no answers.

These provide increasingly strong evidence for certain forms of connected
cognitive processing, but they are not a single scale and need not nest perfectly
in every pathological case.

Thus:

```text
Responsiveness(type A) != Responsiveness(type B)
```

---

# 8. Positive and negative evidence are asymmetric

HF2's strongest methodological result comes from disorders-of-consciousness and
anaesthesia studies.

Suppose a task requires:

```text
hearing / seeing instruction
+ comprehension
+ sustained attention
+ working memory
+ task set
+ imagery or motor planning
+ neural response production
+ measurement sensitivity
```

If a subject produces the highly specific instructed response, that can be
strong evidence for several upstream capacities.

If no response is detected, many different components could have failed.

Therefore:

```text
PositiveTaskEvidence
and
NegativeTaskEvidence
are not symmetric
```

A useful causal form is:

```text
Experience / connected processing
        ↓
[required capacities and channels]
        ↓
observable task evidence
```

Failure at any downstream node can erase the observation.

Thus:

```text
NoDetectedResponse
!= NoExperience
```

unless the measurement model justifies that inference.

This is not an argument that everyone is conscious. It is an argument for
**typed uncertainty**.

---

# 9. Disorders of consciousness falsify bedside behaviour as the whole state

The 2024 multicentre cognitive-motor-dissociation cohort is a high-information
case.

Among participants with no observable command response at bedside, a substantial
minority showed task-based fMRI/EEG command following. Conversely, many people
who did follow commands behaviourally did not yield positive imaging-task
responses.

The correct HF2 inference is not:

```text
fMRI/EEG = true consciousness
bedside = false consciousness
```

It is:

```text
BehaviouralChannel
and
NeuroimagingTaskChannel
have different sensitivity, prerequisites and failure modes
```

Therefore:

```text
EvidenceChannel_A != EvidenceChannel_B
```

and multimodal disagreement should remain represented rather than forced into
one bit prematurely.

---

# 10. Reportability

HF2 distinguishes an actual report from the **capacity to make a content
available for a report under specified conditions**.

Working operator:

```text
Reportable(C, S, channel, t, conditions)
```

A content can be experienced yet not successfully reported if:

- the question is unexpected;
- encoding is weak;
- the report channel is unavailable;
- motor/language execution fails;
- attention is reconfigured;
- the content decays before the query;
- metacognitive access is poor.

Thus:

```text
Experience != Reportability != ActualReport
```

---

# 11. Attribute amnesia falsifies awareness = immediate reportability

Attribute-amnesia paradigms provide a useful Human case because the target
attribute can guide successful behaviour and be attended, yet participants may
fail an unexpected immediate report of that attribute.

HF2 does not use this to prove unlimited phenomenal consciousness.

It uses it for the narrower deletion result:

```text
Successful conscious-use evidence
and
unexpected explicit report
can dissociate
```

Therefore:

```text
Experience/awareness evidence
!= guaranteed durable explicit representation
```

This forces a later distinction among attention, working memory, access and
metacognition.

---

# 12. Recall is a multi-stage relation

A later memory report depends on a chain:

```text
prior content/state
→ encoding
→ storage/consolidation
→ retention
→ retrieval cue
→ retrieval
→ report/action
```

A failure of `Recall` can therefore arise after an experience occurred.

HF2 defines:

```text
Recall(C, t2 | event at t1)
```

as evidence about a later retrieval relation, not an identity claim about the
state at `t1`.

Therefore:

```text
NoRecall(t2)
!= NoExperience(t1)
```

and:

```text
Recall != CompleteRecordOfExperience
```

---

# 13. The report problem

Traditional consciousness experiments often use:

```text
stimulus
→ experience
→ report
```

and then contrast brain activity on reported-seen versus reported-unseen trials.

But the observed signal can include:

```text
NCC-prerequisites
+ conscious processing
+ attention/task relevance
+ working memory
+ decision
+ confidence/metacognition
+ motor planning
+ report execution
```

HF2 therefore distinguishes:

```text
NCC-pr
NCC
NCC-co
```

as a useful methodological warning:

```text
prerequisites
correlates of experience itself
consequences/post-perceptual processes
```

HF2 does not claim these are always cleanly separable in biology.

---

# 14. No-report paradigms solve one problem and create another

No-report paradigms remove the need for an overt trial-by-trial report about the
critical percept.

This can reduce:

- explicit decision;
- working-memory maintenance for report;
- response selection;
- motor report;
- some task relevance.

But no-report must infer experience through another observable:

- eye movements;
- pupil response;
- optokinetic nystagmus;
- incidental memory;
- prevalidated neural/behavioural proxy.

Therefore:

```text
NoReport != NoInference
```

and:

```text
NoReport != NoCognition
```

The 2025 fixation-shift result in no-report binocular rivalry is especially
useful: the proxy/tracking procedure can itself alter perceptual dynamics.

Thus:

```text
MeasurementProtocol
may intervene on
MeasuredProcess
```

which reconnects directly to HF0's Human reflexivity principle.

---

# 15. No universal neural marker is earned

HF2 reviews candidate markers only to test epistemic structure.

P3b is the clearest historical example.

It was often associated with conscious perception, yet report/no-report designs
show it can strongly depend on report/post-perceptual processing.

Therefore:

```text
Reliable correlate in one paradigm
!= constitutive universal marker
```

Likewise:

```text
EEG pattern
fMRI decoding
perturbational complexity
late slow wave
posterior negativity
frontoparietal activation
```

may each provide evidence under declared designs without becoming `the
consciousness variable`.

HF2 retains:

```text
NeuralMarker(M)
= evidence relation with scope + sensitivity + specificity + prerequisites
```

not:

```text
M = Experience
```

---

# 16. Infant and nonverbal evidence

A verbal-report definition of consciousness would make infant research nearly
impossible by construction.

Kouider et al. found infant neural responses with temporal characteristics that
resemble adult late responses associated with perceptual consciousness, but with
age-dependent latency.

HF2's inference is deliberately bounded:

```text
nonverbal neural/behavioural evidence
can increase support for conscious perceptual processing
```

while:

```text
neural resemblance != direct first-person proof
```

Therefore nonverbal Humans require **convergent evidence**, not categorical
exclusion.

---

# 17. Blindsight falsifies performance = ordinary visual experience

Blindsight-like cases reveal that objective discrimination and subjective visual
experience can dissociate.

But HF2 also rejects the simplistic opposite claim:

```text
above-chance discrimination + no ordinary seeing report
= definitely zero experience
```

because:

- type-II blindsight includes some acknowledged feeling/awareness;
- response criteria can matter;
- patients differ;
- degraded visual experience can exist;
- different stimulus classes produce different awareness profiles.

Therefore the durable result is:

```text
ObjectiveSensitivity
!= SubjectiveVisualQuality
!= Confidence
!= MetacognitiveAccess
```

not a universal binary `conscious/unconscious` label.

---

# 18. Downstream availability

HF2 finds that the broad word `access` also risks becoming a hidden scalar.

Instead it introduces a typed operator:

```text
AvailableFor_D(C, S, t)
```

where `D` declares a downstream process.

Examples:

```text
AvailableFor_discrimination
AvailableFor_attention-guidance
AvailableFor_working-memory
AvailableFor_action-selection
AvailableFor_metacognitive-evaluation
AvailableFor_confidence-report
AvailableFor_verbal-report
AvailableFor_long-term-encoding
```

## 18.1 Main availability law

```text
AvailableFor_D
!= AvailableFor_E
```

without evidence linking `D` and `E`.

This is the cognitive analogue of HF1's extension law:

```text
Extension_D != Extension_E
```

## 18.2 Why this matters

A content may:

- influence forced-choice discrimination;
- fail explicit identification;
- be unavailable for confidence judgment;
- fail later recall;
- still alter action.

One global `access=yes/no` variable would erase those differences.

---

# 19. Conscious state is not one scalar by default

Clinical and ordinary language often uses `level of consciousness`.

This can be pragmatically useful.

HF2 rejects only the foundation assumption that all global conscious states must
lie on one total order:

```text
State A > State B > State C
```

across every relevant dimension.

Sleep, dreaming, anaesthesia and DoC provide cases where:

- arousal;
- environmental connectedness;
- content richness;
- responsiveness;
- reportability;
- memory;
- cognitive control

can vary differently.

Therefore HF2 adopts:

```text
ConsciousStateProfile(S,t) =
[
  Wakefulness,
  ExperientialEvidence,
  Connectedness,
  ContentProperties,
  AvailabilityProfile,
  ResponsivenessProfile,
  ReportChannelState,
  EncodingRecallProfile,
  MetacognitiveEvidence
]
```

This is a research coordinate set, **not a mandatory permanent Human schema**.

---

# 20. Contents and global state

HF2 distinguishes:

```text
GlobalStateProfile
```

from:

```text
ConsciousContent
```

The state constrains what contents can arise, persist, connect to the world and
be used downstream, but it is not the content itself.

Examples:

```text
Dream state
→ internally generated vivid visual/social content
→ reduced ordinary external connectedness

Focused wake state
→ externally connected narrow content
→ high reportability for task-relevant items

Anaesthetic transition
→ altered arousal/connectivity/access/memory
→ content may disappear, disconnect or persist in altered form
```

Therefore:

```text
State != Content
```

and:

```text
ContentRichness != WakefulnessLevel
```

---

# 21. Content properties are multidimensional too

HF2 does not define one canonical content vector but recognizes that experiments
may need properties such as:

```text
modality
spatial/temporal organization
valence
vividness/intensity
precision/clarity
self-relatedness
external/internal source character
stability/duration
complexity
integration with context
```

These are reportable/estimable dimensions with their own evidence limitations.

A vivid dream can score high on some content dimensions while environmental
connectedness is low.

---

# 22. First-person and third-person evidence

HF2 formalizes the asymmetry inherited from HF0/HF1.

## 22.1 First-person elicitation

Can provide information about:

- qualitative content;
- pain;
- vividness;
- uncertainty;
- mineness;
- perceived agency;
- subjective temporal structure.

But depends on:

- introspective discrimination;
- memory;
- concepts/language;
- willingness;
- response format.

## 22.2 Third-person evidence

Includes:

- behaviour;
- command following;
- psychophysics;
- physiology;
- EEG/fMRI;
- perturbational responses;
- eye movements;
- clinical observation.

It can constrain mechanisms and provide evidence where report is absent, but no
single channel is identical to the first-person phenomenon.

## 22.3 Retained relation

```text
FirstPersonEvidence
and
ThirdPersonEvidence
are partially independent, mutually constraining evidence channels
```

not competitors where one must eliminate the other.

---

# 23. Evidence bundle instead of consciousness bit

HF2 introduces a compact evidence representation:

```text
EvidenceBundle(Episode) = {
  elicited first-person evidence,
  spontaneous/command behaviour,
  objective discrimination,
  metacognitive evidence,
  neural/physiological evidence,
  later memory,
  protocol assumptions,
  known failure modes
}
```

The bundle can support different claims with different confidence.

Example:

```text
Claim: connected command processing occurred
Evidence: specific willful imagery response to instruction
Support: strong

Claim: all other conscious content absent when task response absent
Evidence: same negative task result
Support: weak / not licensed
```

This prevents evidence from being transported beyond its design.

---

# 24. Uncertainty representation

HF2 rejects forced binary classification where evidence is incomplete.

Minimum status vocabulary:

```text
Supported
Disfavoured
Unknown / Underdetermined
NotMeasured
Inapplicable
```

For consciousness-sensitive claims, `Unknown` is a substantive result.

Do not silently convert:

```text
NoPositiveEvidence
```

into:

```text
EvidenceOfAbsence
```

unless the test has sufficient sensitivity and scope for that exact claim.

---

# 25. Theory competition

HF2 does not choose a final theory of consciousness.

It treats major theories as **mechanism proposals** whose value depends partly on
whether they generate discriminating predictions.

Relevant families include:

```text
Global Neuronal Workspace / global broadcast
Integrated Information Theory
Recurrent Processing approaches
Higher-Order theories
predictive / active-inference-related models
```

HF2 avoids turning any preferred vocabulary into ontology.

## 25.1 2025 adversarial collaboration

The Cogitate Consortium's preregistered comparison of GNWT and IIT is especially
important as a research-method precedent.

It tested divergent predictions in a common experimental design using fMRI, MEG
and intracranial EEG across 256 participants.

Some predictions were supported, while key predictions of both theories were
challenged.

HF2 retains the meta-result:

```text
MatureTheory
+ ConfirmingLiterature
!= FinalOntology
```

and:

```text
Theory quality improves when rivals state divergent falsifiable predictions
before seeing the result
```

This is directly compatible with the Game/Media/Human foundation method.

# 26. HF2 competing models

HF2 explicitly tests several tempting models.

## M1 — report model

```text
conscious iff reportable/reported
```

### Failure

- nonverbal Humans;
- motor impairment;
- no-report paradigms;
- attribute amnesia;
- command-following dissociations.

**Disposition:** reject as ontology; retain report as one evidence/action channel.

## M2 — responsiveness model

```text
conscious iff behaviourally responsive
```

### Failure

- cognitive motor dissociation;
- anaesthesia isolated-forearm results;
- motor impairment;
- reflex/automatic responses.

**Disposition:** reject as ontology; type responsiveness.

## M3 — wakefulness model

```text
conscious iff awake
```

### Failure

Dreaming and sleep experience.

**Disposition:** reject; retain wakefulness as global state coordinate.

## M4 — memory model

```text
conscious iff later recalled
```

### Failure

Anaesthetic amnesia, ordinary forgetting, attribute amnesia.

**Disposition:** reject; model encoding/storage/retrieval separately.

## M5 — objective-performance model

```text
conscious iff information improves task performance
```

### Failure

Blindsight and other unconscious/weak-awareness performance phenomena.

**Disposition:** reject; performance is downstream evidence.

## M6 — one-neural-marker model

```text
conscious iff marker M is present
```

### Failure

Marker/report confounds, state/context sensitivity and multiple measurement
channels.

**Disposition:** reject universal form; allow scoped biomarkers.

## M7 — one-dimensional-level model

```text
all conscious states lie on one scalar level
```

### Failure

Cross-dimensional sleep, dream, anaesthesia and DoC profiles.

**Disposition:** reject as foundation primitive; allow domain-specific clinical
ordinal summaries.

## M8 — one-theory mechanism model

```text
a favoured mechanism defines consciousness
```

### Failure

Competing theories remain empirically underdetermined and recent adversarial
results challenge key predictions of multiple leading theories.

**Disposition:** retain theory competition.

# 27. Cross-context falsifier matrix

| Case | Naive equivalence attacked | HF2 surviving distinction |
|---|---|---|
| vivid dream | wakefulness = experience | experience can occur with low ordinary wake/environment coupling |
| NREM awakening with reported experience | NREM = unconscious | sleep stage != experience bit |
| awakening with no reported dream | no recall = no prior experience | report/recall is imperfect retrospective evidence |
| anaesthesia isolated-forearm command following | general anaesthesia = unconsciousness | intended state != connected responsiveness |
| command following without later recall | recall = prior consciousness | experience/connectedness != memory |
| frontal anaesthesia EEG pattern + response | marker = unconsciousness | neural state marker != definitive phenomenon |
| DoC bedside unresponsive + fMRI/EEG command response | no motor response = no cognition | output channel != covert task performance |
| DoC behavioural response + imaging task negative | imaging negative = no consciousness | negative complex-task evidence is weak/asymmetric |
| infant face ERP | verbal report required | nonverbal convergent evidence is possible |
| blindsight discrimination | performance = ordinary seeing | objective sensitivity != visual phenomenology |
| type-II blindsight | awareness is binary | subjective visual state can be graded/qualitatively altered |
| P3b report/no-report | P3b = consciousness | late marker can reflect post-perceptual/report processes |
| no-report binocular rivalry | no report = no confound | proxies/interventions carry their own causal assumptions |
| attribute amnesia | awareness = immediate reportability | awareness/use != durable explicit availability |
| rich experience but narrow task access | all conscious content = globally reportable | downstream availability is typed |
| same sensory content under different task demands | NCC = all condition differences | prerequisites/consequences must be separated |

# 28. HF2 anti-laws

HF2 retains these as high-value constraints.

## Experience / state

1. `Experience != Wakefulness`.
2. `Experience != ExternalConnectedness`.
3. `Experience != BehaviouralResponsiveness`.
4. `Experience != Reportability`.
5. `Experience != ActualReport`.
6. `Experience != LaterRecall`.
7. `ConsciousPresence != ConsciousContent` as claim types.
8. `GlobalStateProfile != ConsciousContent`.
9. `ContentRichness != WakefulnessLevel`.

## Awareness

10. `Awareness` without qualifier is not a foundation primitive.
11. `PerceptualAwareness != SelfAwareness != MetaAwareness` by default.

## Connectedness / responsiveness

12. `Connectedness != Wakefulness`.
13. `Connectedness != WholeBodyResponsiveness`.
14. `ReflexResponse != VolitionalResponse`.
15. `CommandFollowing != CompleteConsciousState`.
16. `CommunicativeResponse != all conscious content`.

## Access / availability

17. `AvailableFor_D != AvailableFor_E` without evidence.
18. `ObjectiveDiscrimination != Reportability`.
19. `WorkingMemoryAvailability != LongTermRecall`.
20. `ActionGuidance != MetacognitiveAccess`.
21. `Reportability != ActualReport`.

## Memory

22. `Encoding != Experience`.
23. `Recall != complete record of experience`.
24. `NoRecall != NoPriorExperience`.

## Evidence

25. `Report != phenomenon`.
26. `Behaviour != phenomenon`.
27. `NeuralMarker != phenomenon`.
28. `NoReport != NoInference`.
29. `NoReport != NoCognition`.
30. `PositiveEvidence != NegativeEvidence` in inferential strength.
31. `NoDetectedResponse != NoExperience` without validated sensitivity/scope.
32. `EvidenceChannel_A != EvidenceChannel_B`.
33. `AbsenceOfPositiveEvidence != EvidenceOfAbsence` by default.

## Models

34. `Conscious state != one scalar level by default`.
35. `Clinical shorthand != foundation ontology`.
36. `TheoryPrediction != ontology authority`.
37. `Reliable correlation != causal necessity`.
38. `Decodability != causal role`.
39. `One paradigm's NCC != universal NCC`.

## Normative boundary

40. `Consciousness uncertainty != absence of personhood/rights`.
41. `Measurement failure != authorization for high-consequence exclusion`.

# 29. Minimum retained HF2 grammar

HF2's minimum useful model is:

```text
HumanIndividual H at time t
        │
        ├─ GlobalStateProfile(H,t)
        │    ├─ wakefulness/arousal
        │    ├─ connectedness profile
        │    ├─ responsiveness profile
        │    ├─ availability profile
        │    └─ encoding/recall conditions
        │
        └─ possible ExperientialSubject role
             └─ Experience(H, Content, t)
                  │
                  ├─ may be connected/disconnected from external world
                  ├─ may be AvailableFor_D to different downstream systems
                  ├─ may or may not yield report
                  └─ may or may not be later recalled
```

Evidence arrives through:

```text
first-person elicitation
behaviour
objective performance
metacognitive judgment
physiology/neural measurement
later memory
```

and must be interpreted through its protocol and failure modes.

# 30. The HF2 inference graph

A reusable local causal skeleton is:

```text
World / Internal Generator
        ↓
Sensory / internal processing
        ↓
Possible conscious content
        ↓
+ state-dependent gating / integration / availability
        ↓
Downstream use
  ├─ discrimination
  ├─ attention / selection
  ├─ working memory
  ├─ decision
  ├─ metacognition / confidence
  ├─ action
  ├─ report
  └─ memory encoding
        ↓
Observable evidence later
```

This graph deliberately includes several branches because different experiments

# 38. HF2 synthesis

HF2 began with eight apparently neighboring words:

```text
Experience
Consciousness
Awareness
Wakefulness
Connectedness
Responsiveness
Reportability
Recall
```

and found that the right move is not to rank them on one consciousness ladder.

The minimum durable structure is:

```text
Experience
→ first-person phenomenal content/presence

GlobalStateProfile
→ multidimensional enabling/constraint condition

Connectedness
→ relation between current processing/experience and external world

Responsiveness
→ typed input-output relation

AvailableFor_D
→ content availability to one declared downstream system

Reportability
→ conditional capacity to produce a report

Report
→ actual communicative/action output

Recall
→ later retrieval relation through encoding/storage/retrieval chain

EvidenceBundle
→ multiple imperfect channels + assumptions + uncertainty
```

The deepest compression is:

```text
Consciousness science does not observe Experience directly from outside.
It triangulates it through imperfect, task-dependent, asymmetric evidence.
```

and therefore:

```text
Phenomenon
!= Evidence
!= Inference
!= Theory
```

HF2 is complete when those boundaries are explicit enough that the next round can
study **attention and downstream access mechanisms** without treating them as
synonyms for consciousness.
