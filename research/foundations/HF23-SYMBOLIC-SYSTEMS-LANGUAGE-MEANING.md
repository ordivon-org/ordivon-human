# HF23 — Generative Symbolic Systems, Language, Reference, Meaning and Compositional Use

## 0. Admission history

HF23 was not created from numbering pressure.

HD4 completed without HF23 and deliberately decoupled HD/HF numbering.
HD5 then tested the residual linking:

```text
HF8  generic representation
HF12 communication/reference events
HF13 convention/persistent social order
HD4  cultural transmission
```

The residual survived as a distinct persistent object:

```text
GenerativeSymbolicSystem
```

which provides reusable sign types, stabilized mappings and combinatorial constructions
across many use events.

Therefore:

```text
NextFoundationAdmissionCondition(HF23) = true
FoundationReopenCondition(HF0–HF22) = false
```

---

# 1. The missing middle object

HF23 establishes:

```text
GenericRepresentation
!= GenerativeSymbolicSystem
!= CommunicationUseEvent
```

A concept/representation can exist without a public symbol system.
A language/symbolic system persists beyond one utterance.
A communication event consumes a system but is not the system.

---

# 2. Signal is not symbol

```text
Signal != Symbol
```

Signals can causally affect receivers without participating in a reusable socially learned
sign system.

---

# 3. Symbol is not intrinsic mark property

```text
PhysicalMark != SymbolByDefinition
```

Symbolic status depends on a learned/stabilized interpretation relation under a system and
context.

---

# 4. Symbol is not referent

```text
Symbol != Referent
```

A word, sign or numeral is not the entity/state/quantity it is used to represent or refer
to.

---

# 5. Symbol is not concept

HF8 remains authoritative:

```text
LexicalLabel != Concept
```

```text
SymbolType != Concept
```

# 6. Vehicle, content, referent and truth remain distinct

A symbolic system does not collapse these coordinates.
