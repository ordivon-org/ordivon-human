# HF23 — Evidence Bridge

Canonical deep evidence owner:

[`../deep-foundations/HD5-SOURCES.md`](../deep-foundations/HD5-SOURCES.md)

Evidence classes justifying HF23:

1. **modality independence with modality-specific realization** — signed languages show
   language-level structure/neurobiology outside speech/audition;
2. **system emergence** — homesign and Nicaraguan Sign Language show language-like and
   community-stabilized generative structure cannot be reduced to a fixed inherited lexicon
   or one communication event;
3. **representation/use scale gap** — reference and partner-specific conceptual pacts show
   communication events consume and locally update persistent conventional resources;
4. **semantics/pragmatics separation** — scalar implicature and visual-world evidence show
   conventional content, contextual interpretation and nonlinguistic context are not one
   process;
5. **language/thought dissociation** — severe aphasia can spare selected causal,
   mental-state, quantitative and algebraic reasoning;
6. **comparative composition** — nonhuman call systems can show limited compositional/order-
   sensitive meaning, so HF23 cannot define Human language by one property;
7. **writing/literacy** — external symbolic systems can transform cognition/brain while
   remaining distinct from natural language competence;
8. **AI grounding** — text-only LLMs recover substantial non-sensorimotor concept structure
   but show systematic sensorimotor divergence; multimodality improves some grounding
   dimensions without settling experience/understanding.
