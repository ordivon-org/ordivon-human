# H0 P0 Relation Seed

## Purpose

This is the first cross-system relation map for Body, Cognition, Emotion/Motivation, and Capability. It is deliberately smaller than a comprehensive graph.

Each relation is a research proposition with a scope and evidence burden, not an immutable edge.

## Relation classes

- **enables** — supplies a necessary or major supporting condition;
- **constrains** — limits available state or action;
- **modulates** — changes magnitude, threshold, or direction;
- **learns through** — changes through repeated action and feedback;
- **expresses through** — becomes observable through action or performance;
- **feeds back** — an output changes a prior input;
- **is measured by** — observation relation, not identity.

## Seed feedback loops

### Recovery loop

```text
body strain
→ reduced cognition and capability
→ rest, treatment, support, or accommodation
→ recovery
→ restored action
```

Failure mode: resource shortage or continued exposure prevents recovery.

### Learning loop

```text
cognition + motivation + opportunity
→ practice and feedback
→ capability
→ successful outcomes and confidence
→ greater future opportunity and practice
```

Failure mode: narrow test gains are mistaken for transfer.

### Chronic stress loop

```text
threat or low control
→ arousal and stress
→ sleep and cognitive disruption
→ errors and reduced capability
→ more threat, workload, or loss of control
```

Failure mode: the loop is attributed entirely to personality.

### Tool-leverage loop

```text
capability
→ better tool selection and direction
→ higher joint-system output
→ more resources and harder tasks
→ further capability or growing dependence
```

The final branch cannot be inferred from output alone.

## Admission rule

A relation enters the durable Atlas only when it:

1. prevents a concrete explanatory error;
2. has a defined direction and scope;
3. names plausible mediators or conditions;
4. can be revised or falsified;
5. does not merely restate that “everything affects everything.”

P0 retains these as seeds. R3 will test and reduce them using complete human cases.
