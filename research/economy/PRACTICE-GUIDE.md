# Practical Guide to the Economic-Autonomy Framework

This guide turns the `HUMAN-ECON-001` framework into one bounded decision cycle.
It is not a life score, financial plan, or instruction to complete E0–E9 in order.

## 1. State the decision

Write one decision that can change within a bounded period.

```text
I am deciding whether to ________________________________.
The decision matters because it may change ______________.
The people or obligations affected are ___________________.
```

Reject questions such as “How do I optimize my whole life?” or “How do I become
wealthy?” until they are reduced to a concrete transition.

## 2. Protect the floor first

State what ordinary failure must not destroy:

- essential functioning, housing, food, or treatment;
- current income required for basic obligations;
- a critical relationship or care responsibility;
- future learning capacity or legal status;
- the ability to try again.

This is the continuity boundary. It is not a guarantee against every loss.

## 3. Find the unsupported transition

Choose the first important “no”:

- If functioning and learning are unreliable, use E1 and E5.
- If directions have not met real work, use E2.
- If capability has not produced an reviewable result, use E3.
- If another party cannot yet trust and use the result, use E3–E4.
- If work does not create recurring surplus and portable power, use E4–E5.
- If repeated work is not becoming controlled reusable production, use E6.
- If delivery cannot persist without proportional owner burden, use E7.
- If capital has no declared function, use E8.
- If evidence, stop, and recovery rules are unclear, use E9.

When several answers are no, identify the **smallest binding set**. Do not create
a total plan. Choose one action that can distinguish which constraint dominates.

## 4. Choose the engine

### Work and exchange

Use E1–E4 when the main problem is capability, direction, proof, trusted use,
work returns, or recurring surplus.

### Ownership and operation

Use E6–E7 when repeated useful work exists and the question is whether value can
persist, be controlled, or operate with less owner dependence.

### Capital and optionality

Use E8 when resources already exist and need explicit jobs: continuity, options,
controlled production, independent claims, protection, or deliberate life use.

E0 diagnoses. E5 protects life and obligations. E9 governs evidence and action.
They apply across all three engines.

## 5. Design one bounded action

Complete this record before acting:

```text
Current bottleneck:

Bounded action:

Maximum acceptable loss of money, time, attention, trust, or optionality:

External evidence that would support continuing:

Evidence that would require redesign or stopping:

Value retained if the action fails:

Review trigger: date or evidence event
```

Good actions are small enough to survive failure and real enough to produce
external evidence.

## 6. Select a comparison case

Use cases to inspect reasoning, not to copy a recommendation. The full evidence
boundary is in the [case index](cases/README.md).

- [early capability and assisted output](cases/CASE-001-EARLY-STAGE-TECHNICAL-BUILDER.md);
- [unstable labour and continuity](cases/CASE-002-PRECARIOUS-WORKER.md);
- [stable salary and shrinking options](cases/CASE-003-STABLE-SALARIED-SPECIALIST.md);
- [independent professional work](cases/CASE-004-INDEPENDENT-PROFESSIONAL.md);
- [founder-dependent ownership](cases/CASE-005-FOUNDER-DEPENDENT-SMALL-BUSINESS.md);
- [complex wealth and weak usable autonomy](cases/CASE-006-ASSET-RICH-AUTONOMY-POOR.md).

A case is useful when it shares the same **production relation or failure mode**,
not merely the same occupation, age, or asset label.

## 7. Review the evidence

Choose one disposition:

- **continue** — evidence supports another bounded iteration;
- **scale** — repeated evidence supports larger exposure;
- **separate** — coupled constraints require different tests;
- **redesign** — the mechanism may be right but the action was wrong;
- **hold** — the current path works and no better evidence exists;
- **recover** — restore continuity before further growth;
- **stop** — cost, infeasibility, or contradictory evidence crosses the boundary.

A positive result does not automatically justify permanent commitment. Test
whether demand, income, operation, control, and life value persist.

## 8. When this guide is insufficient

Stop using the generic framework as authority when the decision depends on
current local law, tax, migration rules, medical condition, educational
admission, labour-market access, credit, investment products, or household
consent. Obtain appropriate current evidence and professional judgment.

The framework helps structure the question and failure boundary. It does not
replace domain authority or the affected person's decision.
