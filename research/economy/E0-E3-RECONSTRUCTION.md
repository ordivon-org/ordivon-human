# HUMAN-ECON-001 E0–E3 Reconstruction

## Decision

The original E0–E2 sequence was structurally mis-prioritized.

- E0 contained useful outcomes but flattened terminal goals and support constraints into one list.
- E1 described household state and risk more thoroughly than it explained wealth creation.
- E2 followed available CHFS/CFPS data into a technically valid but strategically secondary liquidity study.

The sequence has been rebuilt from first principles.

## Correct research order

```text
E0  define what success means
E1  derive how wealth can form
E2  identify which mechanism dominates by stage
E3  compare mechanism magnitude using identities and public averages
```

Risk, liquidity, commitments, and recovery remain support constraints. They are no longer the main research spine.

## E0 result — terminal outcomes

The program now optimizes three terminal outcomes:

1. present life quality;
2. durable economic power;
3. economic autonomy.

The following are instruments or constraints rather than parallel outcomes:

- income;
- saving;
- liquidity;
- capability;
- ownership;
- leverage;
- commitments;
- recovery;
- risk.

The objective ordering is:

```text
avoid unrecoverable failure
→ preserve the declared life-quality floor
→ increase durable command over resources and production
→ expand the feasible action set
```

## E1 result — wealth formation chain

The minimum internally generated chain is:

```text
capability
→ value creation
→ value capture
→ quality-preserving surplus
→ productive ownership
→ leverage
→ compounding
→ autonomy
```

This corrects several previous confusions:

- skill is not wealth unless it converts into valued exchange;
- creating value is not capturing value;
- high income is not surplus;
- saving is not ownership;
- ownership is not scalability;
- leverage is not necessarily productive;
- capital return has limited absolute force when the base is small.

## E2 result — stage and path model

The binding constraint changes across six states:

```text
dependence
→ labour-dominant independent income
→ stable surplus
→ scalable ownership
→ capital- and system-dominant wealth
→ high economic autonomy
```

No age band or universal wealth threshold defines a stage.

A stage changes when the mechanism limiting further economic power changes.

The principal path families are:

- professional capability compounding;
- tool-leveraged independent production;
- entrepreneurship and organization;
- income-led diversified capital accumulation;
- external transfer;
- concentrated speculation as a contingent high-variance path.

## E3 result — magnitude comparison

The central identity is:

```text
capital required for return to equal recurring income change
=
annual income change / return rate
```

For illustration, a recurring 12,000-yuan annual income increase has the same one-year magnitude as:

- 240,000 yuan at 5%;
- 150,000 yuan at 8%;
- 120,000 yuan at 10%.

A ten-year simplified comparison with 10,000 yuan initial capital shows that doubling annual surplus from 12,000 to 24,000 yuan changes end wealth far more than raising assumed return from 8% to 10%.

This establishes a stage-dependent default:

```text
low capital
→ capability, market access, income capture, and ownership formation dominate

stable surplus
→ conversion into scalable ownership and diversified productive claims dominates

large productive base
→ capital allocation and compounding dominate
```

The calculation is a scale check, not a return forecast or causal proof.

Git history preserves the implementation at revision `ec8142020f207f0f053e7db974d5cb47b80dbc3f`.

The deletion is intentional. The work was not technically invalid; it lacked sufficient present value for the core question.

## Retained support boundary

[`RISK-AND-CONTINUITY-BOUNDARY.md`](RISK-AND-CONTINUITY-BOUNDARY.md) preserves only what the growth model consumes:

- usable liquidity differs from net worth;
- commitments reduce waiting and exit capacity;
- leverage can erase prior gains;
- ordinary failure must not terminate the path;
- control matters more than nominal possession.

## Method correction

The active method is now:

```text
first-principles structure
→ public-average magnitude check
→ explicit assumptions
→ competing path comparison
→ counterexample and failure analysis
→ conditional conclusion
```

Data may calibrate scale. Data availability may not select the question.

## Subsequent execution

The corrected spine supported two further first-principles rounds in the same reconstruction:

- E4 classified money and time by present-life effect, future productive effect, and future commitment;
- E5 derived how competence converts through demand, proof, access, reliability, bargaining, and ownership.

The next admitted research is E6: the transition from selling time and results toward owning replicable products, systems, organizations, distribution, and diversified productive claims.
