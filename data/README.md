# Data

No human research data is stored in this repository.

Future public data must be one of:

- synthetic data generated from an explicit model;
- aggregate public statistics with compatible licensing and provenance;
- openly licensed research data whose terms permit redistribution;
- small non-identifying fixtures created solely to reproduce a method.

A dataset is admitted only with:

- a named research question;
- source and licence;
- population and sampling description;
- variable definitions and measurement methods;
- missingness and known bias notes;
- privacy and re-identification assessment;
- retention and deletion condition.

Large or sensitive source data should remain outside Git even when access is lawful.
